## 1. 전략 포트폴리오의 역할

현재 게임은 연구, 조립식 시설, 생산·서비스·의료·방어 계통을 문제별 대체 해법으로 묶는다. 연구 180개, 플레이어 조립 파츠 325개, 생산식 355개, 일반·원료 물품 1,074개는 각각 안정 ID별 선택·대체재·가동 영수증·회복 계약을 갖는다.

- 한 런에서 무엇을 주력으로 삼고 무엇을 포기하거나 늦추는가?
- 같은 생존 문제를 서로 다른 생산망·공간·인력·외교 방식으로 해결할 수 있는가?
- 먼저 선택한 계통을 나중에 바꿀 수는 있지만, 그 선택이 충분한 기간 동안 운영 방식과 약점을 만드는가?
- 시작 종족, 합류 문화, 계절, 지형, 세력 관계가 최적해를 바꾸는가?
- 첫 이정표를 달성할 때 상당수 연구와 시설을 사용하지 않아도 되는가?

이 문서는 전수 계약을 **문제별 대체 해법 포트폴리오**로 조립하는 상위 설계다. 안정 ID별 근거와 수치 검증 범위는 `content-plans`의 분리된 계약이 소유한다.

## 2. 엄격한 현재 판정

### 2.1 확정된 설계 기반

- 연구 180개는 문제·해법 계열·자유 서술 역할·매몰비용·늦어지는 대안·압력·가동 영수증·회복을 기록한다.
- 연구 해금 180개는 연구를 실제 제작·장비·작물·시술의 필요 연구와 연결한다.
- BuildingSO 419개는 권위 유형으로 분류되고, 플레이어가 조립하는 파츠 325개는 방 기능·공간 투자·동시대 후보·전환 경로를 기록한다.
- 생산식 355개와 일반·원료 물품 1,074개는 원료·출력·가동·재고·대체·회복을 기록한다.
- 여섯 포트폴리오는 식량·물류·동력·방어·의료·대외경제·문명 목표를 실제 연구·방·물품·계약·이력으로 조립한다.
- 10개 문화·종족과 5개 기후의 50개 조합, 6개 세력의 외부 경로가 주력·보조·압력·회복을 바꾼다.

### 2.2 구현·검증이 필요한 부분


- 가동 영수증에서 포트폴리오 상태를 계산하고, 연구·건설·생산·계약·장비·역사 기록을 추천 화면과 사건 후보에 투영하는 런타임 경로가 필요하다.
- 수동 분산 위생·중앙 급배수·재이용·룬 정화, 수공업·증기·수차·마나 전력, 제작·계약·원정 조달의 실제 처리량과 고장 범위를 공식 검증해야 한다.
- 전환 기간, 미완료 연구 비율, 미건설 시설 비율, 건설 순서 유사도는 수치 설계 권위에 고정했으며 결정론적 다중 시드와 실제 플레이가 결과를 확인한다.
- 문화·기후·세력 조합의 비용과 회복은 50개 맥락 행으로 설계됐다. 욕구·환경·관계·화물·사건·저장 경로의 실제 소비와 결과를 실행 검증해야 한다.
- 세력 자산 중복 정리, 실행 카탈로그, 계약 화물의 중복 수령 방지와 복원은 별도 구현 권위에서 닫는다.

현재 상태는 **전략 포트폴리오 설계·핵심 수치 원장·여섯 경로의 연구·시설 조립 대조 확정 / 반복 생산·전투·사건·인구의 전수 결속, 실행·시뮬레이션·실전 보정 진행 전**이다.

## 3. 핵심 원칙

### 3.1 빌드: 문제 해결 조합

플레이어가 시작할 때 `상인`, `요새`, `마법사` 중 하나를 고르고 나머지를 잠그는 구조로 만들지 않는다. 빌드는 다음 세 축에서 선택한 해법의 조합으로 나타난다.

1. **생존·경제 기반**: 무엇으로 먹이고, 물자를 만들고, 부족분을 조달하는가
2. **안보·대외 교리**: 침입과 외부 위협을 어디서, 누구와, 어떤 물자로 막는가
3. **문명 목표**: 축적한 사회를 어떤 이정표로 증명하는가

예를 들어 같은 `봉인된 낙원` 목표도 외부 경작 중심, 지하 균사 생태 중심, 축산과 순환 농업 혼합형으로 달성할 수 있어야 한다. 같은 `던전 주권국`도 교역 연방, 요새 국가, 산업 공동체로 달성할 수 있어야 한다.

### 3.2 영구 잠금보다 실제 매몰비용을 사용한다

한 계열을 선택했을 때 다른 계열을 메뉴에서 숨기지 않는다. 대신 다음 실제 자원이 먼저 선택한 계열에 묶인다.

- 연구원과 연구 작업량
- 공용 전략재와 제작 설비
- 방 면적, 통로, 수직 공간, 외부 노출 면적
- 배관·전력·환기·물류망의 토폴로지
- 숙련 인력과 멘토 계보
- 비축품과 반복 생산 주문
- 세력 계약, 공급 의무, 문화적 약속
- 시설 진화와 고유 장비 계보

새로운 `전략 포인트` 통화를 추가하지 않는다. 실제 투자와 운영 기록이 선택의 증거다.

### 3.3 선택은 약점까지 만든다

유효한 해법은 항상 다음 중 적어도 두 항목에서 다른 해법과 달라야 한다.

- 초기 건설비와 연구비
- 상시 노동과 전문 숙련
- 공간과 동선
- 전력·물·연료·정비
- 계절·지형·오염·질병 위험
- 외부 세력과 카라반 의존
- 처리량 상한과 확장 방식
- 장애 시 공통 고장 범위

한 해법이 모든 항목에서 우수하면 상위 티어가 된다.

### 3.4 후기 수렴은 허용하되 첫 문명 선택을 지우지 않는다

- 첫 문명 시대에 들어서기 전에는 주력과 비주력의 차이가 가장 커야 한다.
- 240~400일에는 약점을 보완하는 보조 계열 또는 두 번째 주력 계열을 열 수 있다.
- 400~960일에는 복합 문명으로 수렴할 수 있지만, 기존 시설 진화·숙련 계보·세력 의무·공간 구조는 남는다.
- 엔드리스 시대에서는 전 연구·전 이정표 수집을 허용한다. 이 시점의 수렴은 완성한 문명의 장기 운영 보상이다.

## 4. 전략 포트폴리오 모델

### 4.1 세 축

| 축 | 선택 계열 | 플레이어가 실제로 결정하는 것 |
|---|---|---|
| 생존·경제 기반 | 외부 경작, 지하 생태, 축산, 교역·서비스, 채굴·제조, 원정 조달 | 식량·원료·현금·노동을 어떤 망에서 얻는가 |
| 안보·대외 교리 | 복도 요새, 기동 전력, 동맹 방위, 선제 원정 | 위협을 던전 내부·국경·외교·외부 지역 중 어디서 줄이는가 |
| 문명 목표 | 진실, 대협약, 패권, 주권, 낙원, 계보, 시간, 비전, 강철 | 어떤 장기 성취를 위해 현재 자원을 묶는가 |

각 런은 축마다 하나만 고르는 것이 아니다. **주력 1개 + 보조 0~1개**가 자연스럽게 형성되는 것이 기본이다. 세 번째 주력을 동시에 유지하려면 그만큼 인구, 기반 시설, 정비와 연구를 실제로 감당해야 한다.

### 4.2 포트폴리오 역할

연구·시설·조합식·정책은 다음 역할 중 하나 이상을 가진다.

| 역할 | 의미 |
|---|---|
| 공통 기반 | 모든 런이 요구하는 최소 생존·조작 기반 |
| 입문 | 한 해법을 시험할 수 있는 저비용 입구 |
| 주력 정착 | 공간·전략재·인력·의무를 묶어 주력 선택을 만드는 단계 |
| 확장 | 같은 해법의 처리량과 안정성을 키우는 단계 |
| 전환 연결 | 다른 포트폴리오와 혼합하거나 약점을 보완하는 연결 |
| 종착 | 이정표 또는 문명 운영 규칙을 바꾸는 종착점 |
| 비상 유지 | 주력망이 무너졌을 때 낮은 효율로 생존을 유지하는 경로 |

공통 기반을 과도하게 지정하면 다시 체크리스트가 된다. 단지 편리하다는 이유로 모든 런의 필수 요소로 지정하지 않는다.

### 4.3 선택 단계

| 단계 | 판정 | 예상 시기 | 허용되는 변화 |
|---|---|---:|---|
| 탐색 | 입문 연구나 시설을 시험하지만 2단계 운영망은 없음 | 1~30일 | 철거·전환 손실이 작아야 함 |
| 첫 약속 | 같은 해법의 연구 패키지 2개 이상, 작동하는 2단계 공급/서비스망, 반복 정책 또는 주문이 함께 존재 | 30~120일 | 주력 1개를 형성, 경쟁 계열은 의미 있게 지연 |
| 전문화 | 주력 정착 시설과 전문 인력 또는 외부 의무가 생기고 계열 약점이 사건에 노출 | 120~240일 | 첫 이정표를 향한 강점과 취약점 확정 |
| 혼합·전환 | 두 번째 계열의 전환 연결을 열거나 기존 계열을 축소 | 240~400일 | 보완 가능하나 이중 유지비 또는 전환비 지불 |
| 문명화 | 시설 진화·세대 숙련·세력망·랜드마크가 결합 | 400~960일 | 여러 계열 수렴 가능, 과거 선택의 흔적 유지 |
| 완전 수렴 | 전 연구·전 이정표 수집 가능 | 엔드리스 시대 | 수집 허용, 복합 위기로 운영 능력 시험 |

단계는 날짜로 강제하지 않는다. 표의 시기는 현존 캠페인 호흡에 맞춘 관찰 목표다.

## 5. 선택을 묶는 실제 영수증

전략 상태는 플레이어가 선택창에서 선언한 이름으로 판정하지 않는다. 다음 영수증을 문제 영역과 해법 계열별로 집계한다.

| 영수증 | 근거 | 전략적 의미 |
|---|---|---|
| 연구 기록 | 완료 연구와 실제 투입 작업량 | 다른 연구를 미룬 시간 |
| 기반 시설 기록 | 건설·가동 중인 시설, 방, 전력·배관·물류 접속 | 공간과 연결 구조의 매몰비용 |
| 생산 기록 | 최근 생산량, 반복 주문, 비축 목표, 실제 소비처 | 단순 건설이 아닌 운영 의존 |
| 인력 기록 | 기여 작업량, 숙련 등급, 멘토·직책·교대 정책 | 다른 분야에 즉시 옮길 수 없는 전문성 |
| 외부 의무 기록 | 계약, 지원, 통행권, 납품, 보호 약속 | 외교 경로의 혜택과 책임 |
| 역사 기록 | 시설 진화, 고유 장비, 위기 극복, 계보 기록 | 전환으로 사라지지 않는 문명 흔적 |

초기 구현에서는 이를 별도의 저장 상태로 만들지 않는다. 기존 상태에서 일관되게 계산해 감사와 화면 표시에 사용한다. 별도 저장이 필요해져도 원래 상태를 복제하지 않고 근거가 된 기록만 참조한다.

## 6. 대체 해법 작성 계약

모든 주요 문제 영역은 최소 3개의 해법을 가져야 한다. 각 해법 기록은 다음 열을 가진다.

- 해법 계열과 해결하려는 문제
- 입문, 주력 정착과 전환에 필요한 연구
- 필요한 시설 기능과 대표 시설
- 투입 물자 계열과 인력 구성
- 공간 구조와 전력·물·연료 부담
- 처리량이 규모에 따라 변하는 방식
- 실패 방식과 이를 견제하는 압력
- 유리하거나 불리한 환경과 문화 조건
- 외부 세력과 교역에 대한 의존
- 다른 해법으로 전환하는 단계
- 비상 유지 경로
- 이정표와의 관계
- 이 계열을 택하지 않아도 되는 콘텐츠
- 감사 상태

해법 이름만 다르고 같은 시설·같은 입력·같은 노동·같은 위험을 사용하면 별도 해법으로 세지 않는다.

## 7. 문제 영역별 구체 설계

### 7.1 식량과 생물 원료

| 해법 | 현존 연구·시설 기반 | 강점 | 비용·약점 | 유효한 환경·사회 | 주로 늦추는 것 |
|---|---|---|---|---|---|
| 외부 순환 농업 | `research:agriculture:field`, `compost`, `irrigation`, `phenology`, `soil-cycles`; 외부 경작지, 퇴비, 중력 수로, 계절력 기록대, 토양 시험대 | 저전력 대량 생산, 부산물 순환, 봉인된 낙원과 직접 연결 | 외부 면적·계절·날씨·수질·운반에 취약 | 넓은 외부 접근, 공동 노동, 장기 비축 | 지하 공간 투자, 조기 산업 자동화 |
| 지하·실내 생태 | `research:agriculture:indoor`, `subterranean`, `research:forestry:fungal`; 실내 재배조, 동굴 재배 선반, 균사 재배대 | 외부 공격과 계절 변동을 줄이고 던전 내부 동선에 결합 | 습도·환기·조명·배양재·오염 관리, 공간 경쟁 | 균사체·슬라임 생활권과 결합 가능하나 청결 시설과 충돌 가능 | 대규모 외부 농지, 초기 상업 공간 |
| 통제 온실 | `research:agriculture:greenhouse-horticulture`, `cultivar-breeding`, `research:climate:environment-control`; 온실, 품종 육종 온실, 기후 제어실 | 계절 독립성과 품종 특화, 고가 작물·약재에 강함 | 높은 건설비, 물·열·전력, 공통 고장 위험 | 좁은 표면 면적, 고급 의약·서비스 경제 | 군수·방어용 정밀재와 전력 여유 |
| 축산·동물성 순환 | `research:husbandry:capture`, `stable`, `feed`, `taming`, `breeding`, `selective`; 우리, 마구간, 사료, 번식 장부 | 고기·가죽·털·운반·번식 자산을 함께 생산 | 사료·공간·질병·개체 관리, 느린 회전 | 오크·수인 식량 수요와 섬유·가죽 산업 | 작물 직접 소비, 의료·위생 인력 |
| 교역·서비스 조달 | `research:commerce:logistics`, `retail`, `secure-trade`, `research:service-flow`; 창고, 가격표, 보안 거래 금고, 접수·결제 시설 | 토지와 생물 생산을 현금·평판·계약으로 대체, 부족품 신속 조달 | 카라반·세력·치안·시장 가격·서비스 인력 의존 | 다문화 손님을 수용할 공간과 외부 접근 | 완전 자급, 봉쇄 내성 |

설계 판정:

- 외부 농업, 지하 생태, 축산, 교역 조달 중 최소 3개가 30~120일에 실제 생존 가능한 주력이어야 한다.
- 온실은 좁은 공간·고정 기반 시설·고가 생산을 교환하는 별도의 주력 정착·확장 계열로 둔다.
- 식량 보존과 계절 저장은 어느 계열에도 붙는 전환 연결이다. 보존을 모든 식량 해법의 필수 종착점으로 만들지 않는다.
- 교역 조달로 `봉인된 낙원`의 120일 외부 조달 금지를 우회할 수 없다. 대신 다른 일반 이정표로 가는 유효한 주력이 되어야 한다.

### 7.3 동력과 산업화

| 해법 | 현존 기반 | 강점 | 비용·약점 | 지위 |
|---|---|---|---|---|
| 수공업·분산 생산 | 전력 이전 작업대와 수동 가공 | 연료·전력망 없이 유연, 고장 범위가 작음 | 노동 집약, 처리량·자동화 상한 | 초중반 주력 또는 영구 비상 유지 |
| 증기 중앙망 | `research:industry:steam-power`; 증기 발전기, 전력선 | 초기 산업의 범용 동력, 어느 장소에서나 구축 가능 | 숯·물·열·배전·정비, 중앙 고장 | 공통 전기화의 입문과 중추 |
| 수차 보조망 | `research:industry:waterwheel`; 수차 발전기·구동축 | 연료 없는 완만한 상시 전력 | 외부 수원과 입지, 계절·파손, 송전 거리 | 증기 연구 뒤 운전 연료를 대체하는 전환 연결과 확장 |
| 마나 전력망 | `research:industry:mana-power`; 마나 발전기, 룬 도체·결합기 | 고밀도 룬 설비와 정밀 제어, 비전·의료 종착점과 결합 | 마나 합금·룬 정비·공명 위험, 비전 계통 선행 | 후기의 별도 주력 정착과 종착 |

중요한 교정:

- 현존 선행 구조에서 수차와 마나는 독립적인 초입이 아니다. 문서와 화면에서 이를 같은 시점의 세 선택처럼 표시하지 않는다.
- 증기 연구는 `전기화 문해력`의 공통 선행으로 유지할 수 있다. 다만 수차 주력 던전이 증기 발전기를 계속 돌릴 필요는 없어야 하며, 마나 주력도 연료 경제를 실질적으로 대체해야 한다.
- 자동화는 무료 노동 삭제가 아니다. 컨베이어, 자동 주문, 정밀 자동화, 자동 위생는 전력·정비·부품·공통 고장 위험으로 노동을 교환한다.

요새 연구가 기동군·동맹의 기술 선행 일부를 제공해도 운영 결과는 달라야 한다. 방어력 하나로 합산하지 않고 다음을 별도 측정한다.

- 고정 방어가 버티는 접근 방향과 재장전 시간
- 즉시 출동 가능한 건강한 전투 인구와 장비 세트
- 동맹 지원의 도착 시간·경로·의무 이행 상태
- 원정으로 제거한 외부 위협 자산과 내부에 남은 공백

한 경로가 다른 경로를 삭제하지 않는다. 다만 120일까지 필요한 성인 노동을 어떻게 확보했는지에 따라 문화 구성, 세력 관계, 부양비, 전력 부하와 숙련 계보가 달라져야 한다.

| 환대·상업 | 식사, 숙박, 목욕, 진열, 안전 거래 | 다문화 공간, 서비스 동선, 위생, 치안 | 사고·금기·감염·경기 변동 |
| 제조·수출 | 무기, 직물, 가공품, 정밀 부품 | 원료, 제작 숙련, 품질·물류 | 재고 체류, 원료 가격, 산업 사고 |
| 원정·회수 | 지역 자원, 유물, 전리품, 위협 제거 보상 | 전투 인구, 보급, 정보, 운반 | 부상·사망·공백·불확실한 수익 |
| 세력 계약 | 납품, 호위, 기술 협력, 통행·지원 | 신뢰, 기한, 물리 이행 능력 | 의무 충돌, 경쟁 세력 원한, 봉쇄 |
| 자급·절약 | 수입 자체를 줄이고 순환망으로 손실 억제 | 농업·보존·재이용·수리 | 성장 속도와 희귀 기술 접근 제한 |

경제 빌드는 돈 수치가 높은 빌드가 아니다. 어떤 상품과 서비스를 누구에게 제공하고, 그 관계 때문에 어떤 의무와 위험을 떠안는지가 빌드의 일부다.

## 8. 대표 빌드 조합

아래 여섯 개는 위 포트폴리오를 조합한 **QA와 콘텐츠 작성용 기준 빌드**다.

| 기준 빌드 | 생존·경제 주력 | 안보 주력 | 문명 목표 | 강점 | 구조적 약점 | 끝까지 생략 가능한 대표 계통 |
|---|---|---|---|---|---|---|
| 봉인 생태 공동체 | 외부 순환 농업 + 축산 또는 지하 생태 | 복도 요새 | 봉인된 낙원, 영원한 계보 | 봉쇄 내성, 부산물 순환, 장기 가족 사회 | 토지·노동·질병·계절 또는 습도 관리 | 고급 상업 자동화, 대규모 화기, 유물 복원 |
| 지하 균사 도시 | 지하 생태 + 재이용 순환 | 기동 방어 또는 소형 요새 | 주권국, 낙원 | 외부 면적이 작고 내부 동선이 짧음 | 환기·오염·밝은 문화와 충돌, 전력 상승 | 대규모 외부 농업, 수차, 중화기 일부 |
| 환대 교역 연방 | 교역·서비스 + 외부 공급망 | 동맹 방위 | 괴물 대협약, 주권국 | 희귀품 접근, 빠른 성인 영입, 외교 완충 | 카라반·치안·위생·문화 사고, 봉쇄 취약 | 깊은 자급 농업, 공성 요새 일부, 시간 고정 |
| 요새 산업국 | 채굴·제조 + 중앙 물류 | 복도 요새 | 주권국, 강철 신격화 | 높은 처리량과 정면 방어, 자동 보급 | 연료·전력·정비·연쇄 고장, 내부 침투 | 고급 환대, 외부 작물 다양화, 일부 생명공학 |
| 원정 병기국 | 제조·원정 조달 | 기동 민병대 + 선제 원정 | 지상 패권, 진실의 폭로 | 위협 근원 제거, 전리품과 지역 자원 | 성인 전투 인구·부상·탄약·내부 공백 | 대형 고정 함정망, 완전 자급, 서비스 자동화 |
| 비전 계보 성역 | 마나 산업 + 고급 의료 | 룬 방어 + 제한 동맹 | 비전 승천, 시간 없는 성역, 영원한 계보 | 희귀 문제 해결, 고밀도 후기 시설 | 연구·마나·냉각·무균재·정전 공통 위험 | 화약 대량생산, 대규모 축산, 일반 상업 확장 |

기존의 상업/물류, 요새/방어, 비전/연구 세 빌드는 각각 `환대 교역 연방`, `요새 산업국`, `비전 계보 성역`의 축약형으로 보존한다. 새 설계는 여기에 자급, 지하 생태, 원정 중심 조합을 추가해 세 이름이 모든 전략을 독점하지 않게 한다.

## 9. 종족·문화·환경이 최적해를 바꾸는 방식

### 9.1 종족이 만드는 운영 압력

현존 문화 정의는 생산량 `+10%` 같은 직접 보너스를 갖지 않는다. 대신 음식, 금기, 온도, 환기, 조도, 청결, 공동·개인 공간, 시설 역할 선호를 가진다. 이 구조를 유지한다.

| 문화·종족 | 현존 압력 | 자연스럽게 유리해질 수 있는 조합 | 반드시 남겨야 할 반대 비용 |
|---|---|---|---|
| 슬라임 | 깨끗한 물, 높은 청결, 습한 공동 공간, 수분·온도 민감 | 재이용·정화, 수질 관리, 지하 수경 | 소금 금기, 오염 돌파와 물 부족에 큰 운영 부담 |
| 오크 | 높은 식량 수요, 공동 홀, 육체 노동·전투 | 축산·대량 조리, 요새·기동 전력 | 식량·회복·장비 유지비가 커야 함 |
| 뱀파이어 | 혈액 식단, 어둡고 개인적인 방, 긴 생애 | 통제 실내, 고급 의료, 외교·환대 | 개인 공간·혈액 공급·밝은 공용 시설과 충돌 |
| 수인 | 따뜻한 공동 공간, 고기 선호, 무리 관계 | 축산, 공동 식당, 기동 민병대 | 냄새·위생·개인 공간 문화와 갈등 |
| 악마 | 따뜻하고 건조한 개인 공간, 계약 문화, 비전 적성 | 마나·계약 경제, 고온 산업 | 냉각·습윤 생태와 공간·유틸리티 충돌 |
| 코볼트 | 작고 따뜻한 공동 작업장, 제작·굴착 | 채굴·제조, 밀집 공장 | 환기·도구 정비·과밀 사고 |
| 균사체 | 어둡고 습한 공동 정원, 버섯 선호 | 지하 생태, 재배·재생 의학 | 불·살균·밝은 서비스 공간과 충돌 |
| 하피 | 높고 환기·채광이 좋은 공동 공간, 비행·고저차 | 수직 물류, 관측, 원정·외부 농업 | 저천장·밀폐 공장·지하 습윤 구역의 비용 |
| 골렘 | 건조하고 청결한 룬 동력 개인 공간, 정비 키트, 충전·마모 | 산업·마나 전력, 자동화 | 전력·정비 부품·핵 공학의 지속 의존 |
| 모험가 문화 | 밝은 공동 공간, 보존 식량, 원정 실용주의 | 환대·원정·교역 | 생고기 금기, 장기 정착 특화가 약함 |

표는 친화도이지 잠금이 아니다. 균사체가 요새 산업국을 만들거나 골렘이 농업 공동체에 사는 것을 금지하지 않는다. 다만 그 선택이 환기·습도·전력·식사·공간 비용으로 드러나야 한다.

### 9.2 환경 프로필

전략 검증은 최소 다음 환경 프로필을 사용한다.

| 프로필 | 유리한 해법 | 불리한 해법 | 검증 목적 |
|---|---|---|---|
| 넓은 표면·안정 수원 | 외부 농업, 수차 | 밀집 지하 생태의 공간 장점 감소 | 토지와 무연료 전력의 가치 |
| 좁은 표면·넓은 지하 | 지하 생태, 중앙 물류 | 대규모 외부 농업 | 내부 공간 최적화 |
| 건조·수원 불안정 | 교역 조달, 재이용·룬 순환 | 수차, 물 집약 농업 | 물 비축과 조달 리스크 |
| 혹한·긴 운반 | 실내·온실, 보존, 지하 물류 | 외부 작물, 카라반 의존 | 열·전력·비축 선택 |
| 세력 봉쇄·높은 침입 | 자급, 요새 | 환대 교역 단독 | 외부 의존의 약점 |
| 마나 불안정·룬 교란 | 수공업·증기·물리 방어 | 마나 전력·시간 성역 | 후기 단일망 지배 방지 |

어떤 기준 빌드도 모든 프로필에서 생산 안정성·생존·첫 이정표 시간이 동시에 1위여서는 안 된다.

## 10. 전환·혼합·회복

### 10.1 주력 계열 전환 절차

주력 변경은 연구 완료 버튼 하나로 끝나지 않는다.

1. 기존 외부 계약과 반복 주문의 종료·축소 조건을 처리한다.
2. 새 계열이 안정될 때까지 최소 생존 비축 목표를 채운다.
3. 공간을 철거·개조하거나 새 구역을 확보한다.
4. 배관·전력·환기·물류 토폴로지를 새 부하에 맞춘다.
5. 필요한 전환 연결 연구와 설비를 완성한다.
6. 작업자를 재배치하고 숙련 공백을 멘토링·영입·저효율 운전으로 메운다.
7. 첫 안정 생산·서비스 영수증이 나오기 전까지 기존 망 일부를 병행한다.
8. 시설 진화·고유 장비·세력 의무 중 포기할 수 없는 흔적은 새 계열에 승계하거나 매몰비용으로 남긴다.

계획된 대형 전환은 결정부터 새 주력의 안정 처리량 도달까지 **최소 한 계절(30일)의 운영 문제**가 되는 것을 목표로 한다. 30일은 시뮬레이션 승인 전 목표값이다.

### 10.2 혼합 제한

두 계열을 섞는 것을 금지하지 않는다. 대신 다음 중 하나 이상을 실제로 지불해야 한다.

- 서로 다른 전력·환경 조건을 위한 구역 분리
- 두 종류의 비축과 정비 부품
- 추가 전문 인력과 교대
- 외부 계약과 자급 비축의 동시 유지
- 공용 전략재 경쟁
- 서로 다른 문화의 공간·음식·예절 요구

혼합형이 순수형의 약점을 모두 없애면서 처리량도 유지하면 실패다.

### 10.3 비상 회복과 전환의 분리

주력망이 무너졌을 때 사용할 비상 유지 경로는 항상 하나 이상 남긴다.

- 배급·수동 운반·수공업 임시 재개
- 긴급 수입·세력 원조·계약 재협상
- 부품 회수와 임시 수리
- 비핵심 서비스·산업 정지와 생존 부하 우선 공급
- 원정 철수와 내부 경비 복귀
- 격리·구역 차단·오염된 망 우회

비상 경로는 런을 살리되 장기 주력보다 싸거나 효율적이면 안 된다.

## 11. 이정표와 포트폴리오 연결

| 이정표 | 강한 관련 계열 | 허용해야 할 대체 접근 | 금지할 체크리스트 조건 |
|---|---|---|---|
| 진실의 폭로 | 기록·원정·기후 항법 | 세력 정보망, 유물 복원, 선제 원정 | 모든 연구 분야 완료 요구 |
| 괴물 대협약 | 환대·계약·동맹 방위 | 공동 방어, 공급망 지원, 문화 화합 | 요새·산업·의료의 최고 티어 동시 요구 |
| 지상 패권 | 기동군·원정·병기 제조 | 동맹군, 교란·보급 차단 | 던전 내부 고정 방어 전부 요구 |
| 던전 주권국 | 어떤 경제 주력 + 어떤 안보 주력 | 자급국, 교역국, 산업국, 비전국 | 특정 생산망 하나를 정답으로 고정 |
| 봉인된 낙원 | 외부 농업·지하 생태·축산·순환 위생 | 이들 중 2개 이상의 자급 조합 | 교역 조달을 120일 자급으로 계산 |
| 영원한 계보 | 출생·교육·멘토·장비 계승 | 다양한 생존·경제 기반 | 최고 의료·최고 산업을 필수화 |
| 시간 없는 성역 | 재생·시간 + 마나·냉각·정화 | 작은 대상 집중망 또는 광역망 | 다른 대이정표 전부 선행 요구 |
| 비전 승천 | 마나 전력·공명·룬 생산 | 교역 마나 조달 또는 자체 마나 채굴 | 증기·수차를 끝까지 운전하도록 강제 |
| 강철 신격화 | 공장·자동화·정비·통합 방어 | 자원 수입형 공장 또는 자급 광업형 공장 | 농업·의료·외교 최고 티어 요구 |

각 이정표는 관련 계열을 강하게 보상하되, 하나의 완성 순서를 요구하지 않는다. 첫 이정표 달성 시 선택한 포트폴리오의 강점만 보상하지 말고 그 규모에 맞는 반작용을 활성화한다.

## 12. 체크리스트 방지 합격 기준

다음은 구현 전 설계 목표이며, 자동 감사와 다중 시드 시뮬레이션으로 승인해야 한다.

### 12.1 콘텐츠 구조 기준

- 주요 문제 영역 8개 각각에 최소 3개의 실질 해법이 있다.
- 각 해법은 다른 해법과 비용·노동·공간·유틸리티·위험·외부 의존 중 2개 이상이 다르다.
- 각 문제 영역에는 적어도 하나의 비상 유지 경로와 하나의 전환 연결이 있다.
- 모든 주력 정착 연구는 직접 해금 외에 어떤 운영 방식과 경쟁하는지 기록한다.
- 모든 포트폴리오 전용 시설은 `왜 다른 포트폴리오에서는 생략 가능한가`를 기록한다.
- 어떤 일반 이정표도 180개 연구 전 분야의 상위 노드를 요구하지 않는다.

### 12.2 런 결과 목표

| 지표 | 문서 단계 목표 | 의미 |
|---|---:|---|
| 첫 문명 시대 진입 시 미완료 연구 | **54개 이상(180개의 30%)** | 첫 이정표 전에 전 연구 수집 금지 |
| 첫 문명 시대 진입 시 미건설 포트폴리오 시설 | **분류 대상의 35% 이상** | 시설 전수 건설을 정상 플레이로 만들지 않음 |
| 120일까지 주력 문제 영역 | **2개 이상, 4개 이하** | 선택은 보이되 모든 분야 전문화 방지 |
| 같은 문제의 유효 해법 | **최소 3개** | 단일 정답 방지 |
| 120일 핵심 건설 순서 유사도 | 서로 다른 환경·시작 조건 간 **Jaccard 0.75 이하** | 런마다 같은 체크리스트 순서 방지 |
| 기준 빌드 지배 | 모든 환경에서 동시 1위인 빌드 **0개** | 보편적 정답 방지 |
| 대형 전환 안정화 | 목표 **30일 이상**, 비상 회복 제외 | 선택의 지속성 확보 |

`미건설 포트폴리오 시설`의 분모는 [건물 자산 분류](content-plans/facilities/building-asset-classification.csv)와 [플레이어 건물 기능 계약](content-plans/facilities/player-building-functional-contract.csv)의 플레이어 기능 파츠를 사용한다. 장식 변형·동일 기능 외형 변형·이정표 랜드마크는 분모에서 제외한다.

30%·35%·0.75·30일은 문서 수치 기준이다. 변경에는 이전값·최종값·대체안·영향 포트폴리오·검증 범위를 함께 기록한다.

### 12.3 실패 판정

다음 중 하나라도 발생하면 전략 분기 완료가 아니다.

- 세 기준 런에서 첫 120일 연구 순서가 사실상 동일하다.
- 한 해법이 같은 입력과 시설을 쓰면서 생산량만 더 높다.
- 모든 일반 이정표를 위해 같은 20~30개 시설이 항상 필요하다.
- 연구하지 않은 시설도 다른 경로의 숨은 선행 때문에 결국 모두 필요하다.
- 교역·원정·세력 보상이 물리 생산을 무상으로 대체한다.
- 자동화가 전력·정비·부품·고장 위험 없이 노동만 삭제한다.
- 종족 선택이 특정 빌드를 강제하거나 반대로 아무 비용 차이도 만들지 않는다.
- 전환 버튼이 기존 계약·인력·공간 구조·진화 기록을 즉시 초기화한다.

## 13. 플레이어에게 선택을 보여 주는 방법

### 13.1 연구 화면

각 연구 카드에 다음을 표시한다.

- 직접 물리 해금
- 해결하는 문제 영역
- 포트폴리오 역할(입문, 주력 정착, 전환 연결, 확장, 종착)
- 필요한 기존망과 새로 생기는 상시 부하
- 현재 주력 계열과 공유하는 시설·전략재·숙련
- 이 연구를 먼저 하면 늦어지는 대표 대안 1~2개
- 관련 이정표와 현재 충족 기여

`추천 연구`는 현재 부족, 환경, 인구 구성, 계약과 선택한 주력에 맞춘 설명을 제공해야 한다.

### 13.2 건설 화면

시설 카드는 다음을 비교한다.

```text
이 시설이 해결하는 문제
현재망에 연결했을 때 추가 처리량
추가 노동·전력·물·연료·정비
필요한 방·접근·환기·저장 조건
공통 고장 범위
같은 문제의 대체 시설
철거·전환 시 회수와 잃는 진화 기록
```

### 13.3 전략 현황판

다음 질문에 답하는 읽기 모델이다.

- 우리 식량의 70%는 어디에서 오는가?
- 물·전력·방어의 단일 고장점은 어디인가?
- 어떤 전문 인력과 계약이 현재 운영을 지탱하는가?
- 한 계절 동안 외부 조달이 끊기면 무엇부터 멈추는가?
- 첫 이정표까지 가장 부족한 실제 능력은 무엇인가?
- 다른 계열로 전환할 때 필요한 연구·공간·인력·비축은 무엇인가?

전략 현황판은 최근 30일의 물리 입출고를 집계하며, 단일 공급망 비중 70%부터 해당 공급망을 주력 의존으로 표시한다.

## 14. 콘텐츠 작성과 자동 감사

### 14.1 전수 분류 대상

- 연구 180개
- 현재 게임에서 사용되는 시설 전수
- 핵심 생산 조합식과 시설 기능
- 9개 이정표와 랜드마크
- 10개 문화의 선호·금기·환경 요구
- 세력 계약·원정 보상 중 생산망을 대체하거나 보완하는 항목

### 14.2 감사 항목

- 콘텐츠 식별자와 종류
- 해결하는 문제와 해법 계열
- 포트폴리오 역할과 공통 필수 여부
- 필요 재료, 직접 작업량과 내재 작업량
- 공간, 기반 시설과 인력 부담
- 외부 의존과 실패 방식
- 약점을 시험하는 사건과 압력
- 연결할 다른 계열과 전환 경로
- 비상 유지 경로
- 관련 이정표
- 첫 문명 시대 전에 생략 가능한지 여부
- 원본 자료와 저장 권위
- 실제 실행 경로와 감사 상태

필수 감사:

- ID 누락·중복·미분류
- 공통 기반 과다 지정
- 해법별 비용 차원 2개 미만
- 대안이 없는 주력 정착 연구
- 소비처 없는 전략재 또는 무료 외부 보상
- 첫 이정표의 숨은 전체 연구 폐쇄
- 시설을 건설만 하고 운영하지 않아도 전략으로 집계되는 오류
- 저장/복원 뒤 주력 투영 결과 변화
- 콘텐츠 정의 순서에 따른 분류·추천·사건 후보 변화

### 14.3 전략 사건 연결

사건은 현재 주력에 맞춰 보상만 주지 않는다. 강점과 약점을 모두 시험한다.

| 주력 | 강점을 확인하는 사건 | 약점을 찌르는 사건 |
|---|---|---|
| 외부 농업 | 풍작·종자 교환·퇴비 순환 | 서리·가뭄·외부 운반 차단 |
| 지하 생태 | 외부 봉쇄·겨울 | 포자 오염·환기 고장·밝은 문화 갈등 |
| 교역·환대 | 희귀 물자 계약·성인 영입 | 카라반 지연·감염·금기 서비스 사고 |
| 요새 | 대규모 정면 침입 | 내부 파괴 공작·다지점 침투·탄약 단절 |
| 기동군 | 우회 침투·선제 타격 | 부상 누적·원정 중 내부 공백 |
| 마나 산업 | 고밀도 룬 생산·시간 기술 | 룬 교란·정전·마나 촉매 부족 |
| 자동화 공장 | 대량 주문·통합 보급 | 연쇄 고장·정비 부품 부족·오염 |

사건 연결의 실행 계약은 `systemic-content-integration-design.md`의 C4 이상 규칙을 따른다.

## 17. 설계 권위와 실행 대기 항목

확정한 것:

- 전략은 문제별 해법 조합으로 설계한다.
- 첫 문명 시대 진입 전의 기회비용이 핵심이며 후기·엔드리스 시대 수렴은 허용한다.
- 선택 비용은 실제 연구·물리 자원·공간 구조·인력·의무·역사에서 나온다.
- 식량·물/위생·전력·물류·방어·의료·인구·대외경제 8개 문제 영역은 연구 180개와 생산·시설·물품 계약을 묶는 분류 축이다.
- 여섯 기준 포트폴리오는 연구·방·생산·물품·계약·사건·이정표의 조립 규칙을 갖는다.
- 종족·문화·기후는 50개 조합에서 주력·보조·압력·회복을 바꾸고, 세력 6개는 외부 화물·증원·의무로 별도 경로를 만든다.
- 33개 직접 수치 유형은 비용 기록·비교 대상·악용 감사·결정론 검증 범위에 결속된다.

실행 대기 항목:

- 수동 분산 급수·중앙 급배수·재이용·룬 정화의 처리량과 회복성 비교
- 수차·마나 전력의 증기 보조·대체 범위, 자동화의 정비·전력·고장 비용 검증
- 전환 기간, 미완료 연구 비율, 미건설 시설 비율, 건설 순서 유사도의 실행 결과
- 여섯 포트폴리오·50개 맥락 행·세 난도의 다중 시드와 실제 플레이 분포
- 전략 화면, 가동 영수증 집계, 저장·복원, 사건 후보 편성, 세력 중복 정리와 계약 화물 실행
