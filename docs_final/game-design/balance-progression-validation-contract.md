# 밸런스·진행 검증 계약

## 권위와 상태

이 문서는 콘텐츠 설계가 도달해야 할 수치 검증 상태를 고정한다. 개별 아이템·시설·조합식의 현재 값은 ScriptableObject와 루트 콘텐츠 카탈로그가 소유하며, 공통 단위와 목표 밴드는 [전역 밸런스 기준서](whole-game-balance-baseline.md)가 소유한다. 이 문서는 값 변경 권한을 갖지 않는다.

수치 판단은 다음 순서로 승격한다.

| 상태 | 필요한 증거 |
|---|---|
| 기준 배정 | 정의별 BOM, WU, EWU, 공간, 위험, 대안, 저장 권위와 자동 감사 위치가 기록됨 |
| 공식 검증 | 수식, 물리 보존, 도달 가능성, 순환, 처리량, 정적 분포가 재현 가능함 |
| 시뮬레이션 검증 | 결정론적 다중 시드가 목표 밴드와 회복 조건을 통과함 |
| 실전 보정 | 장시간 플레이, UX, 성능, 플레이어 선택 자료로 밴드를 조정함 |

전수 콘텐츠의 현재 authored 값과 정적 목표 밴드는 [수치 설계 권위](numeric-balance-authority.md)와 [콘텐츠 수치 인덱스](content-plans/balance-numeric-authority.csv)에 고정한다. V27 Ship P0는 물리 질량·시장·6인 생존·공간의 제한된 묶음에서 완료 증거가 있다. 전체 경제, 시설, 연구, 사건, 전투, 인구와 엔드리스는 정적 설계 뒤 시뮬레이션과 실전 보정 단계로 이어진다.

## 공통 단위

| 단위 | 사용 | 금지되는 사용 |
|---|---|---|
| WU | 실제 주문·운반·수리·연구·훈련의 노동 시간 | 99 WU 고정 Worker Day로 새 기간을 산정 |
| actual WU | 실제 수행량 기록 | 일정·계약·생산량의 계획 용량 |
| effective WU | 일정·계약·생산량의 계획 용량 | 실제 수행량을 대체하는 성과 기록 |
| EWU | BOM, 운반, 유지, 실패 손실을 포함한 개발용 비교 원가 | 플레이어 재화 또는 무료 보상 근거 |
| kg / g | 운반, 창고, 시설 버퍼, WIP, 전리품의 물리 보존 | 수량·공간·운반 비용을 삭제하는 추상 재고 |
| gold | 외부 조달과 계약의 회계 자원 | 내부 물리 생산을 무시하는 만능 자원 |

V27의 중립 건강 성인 기준은 actual `50 WU/인·일`, effective `45 WU/인·일`이다. 시작 3인은 actual `150 WU/일`, effective `135 WU/일`을 사용한다. 모든 신규 계산은 actual 또는 effective 중 어느 값을 사용했는지 함께 적는다.

EWU는 아래 비용을 유효 출력으로 나눈 그림자 원가다.

```text
입력 EWU
+ 직접 제작 WU
+ 예상 운반 WU
+ 배부된 전력·정비 WU
+ 부패·실패·오염 기대 손실
÷ 기대 유효 출력
```

사망, 관계 파탄, 세대 단절, 고유 유물 소실, 영구 외교 결렬은 EWU에 환산하지 않는다. 발생 확률, 회복 가능성, 후속 세대와 사건에 남기는 흔적으로 따로 기록한다.

## 경제 판정선

### 노동과 회복

| 지표 | 정상 운영 | 위반이 뜻하는 운영 문제 |
|---|---:|---|
| 생존·청소·수리·생활 유지 | 총 계획 노동의 25~35% | 40% 초과는 성장 불능, 20% 미만은 생존 장식화 조사 |
| 운반·재고 정리 | 12~20% | 경로·창고·생산 배치 재설계 필요 |
| 건설·생산·연구·교육 | 35~50% | 장기 성장 부족 또는 유지비 과소 산정 |
| 비상 대응 여유 | 10~20% | 장애·사건 복구 불능 |
| 정상 작업 차단 | 5% 미만 | 재료, 작업자, 경로, 위험, 출력 공간, 정책 중 원인 분리 |

인구 단계별 비축과 일반 위기 회복은 다음 밴드를 사용한다.

| 절대일 | 필수 유지비 | 목표 비축 | 보통 위기 회복 |
|---:|---:|---:|---:|
| 1~10 | 35~45% | 5~7일분 | 2~3일 |
| 10~30 | 30~40% | 7~12일분 | 5일 이내 |
| 30~120 | 25~35% | 15~30일분 | 10일 이내 |
| 120~400 | 25~40% | 한 계절분 | 15일 이내 |
| 400~960 | 30~45% | 핵심 물자 30~60일분 | 30일 이내 |
| 960 이후 | 문명 구조별 | 복합 위기 1회분 | 다음 보스 주기 전 |

3인 기본 거처는 3일 총노동 `891 WU`의 55~65% 안에 완료되어야 한다. 식량, 물, 운반, 수리, 비상 대응을 위한 나머지 노동은 건설 비용으로 전용하지 않는다.

### 물리 경제

| 영역 | 판정선 | 감사할 실패 |
|---|---|---|
| 식량 | 평균 소비의 125%, 종자·사료·평균 부패 뒤 110% 이상 | 단일 작물의 전 기후 지배, 겨울 전 30일 비축 부재 |
| 제작 | 원료 뒤 연속 제작 깊이 최대 4단계 | 하류 수요 없는 중간재, 입력 부족과 출력 포화의 혼동 |
| 공용 중간재 | 실제 소비처 2개 이상 | 한 레시피 전용 중간재를 공용 가치로 계산 |
| 전략 재료 | 실제 소비처 3개 이상 | 희귀 재료가 단일 수치 보너스만 제공 |
| 가역 순환 | 투입 EWU의 95% 미만 | 구매·제작·판매·해체의 순이익 |
| 해체·재건·품질 재굴림 | 투입 EWU의 85% 미만 | 실패품과 회수품을 새 자원처럼 반복 생산 |
| 출력 포화 | 정상 상태에서 생산망 정지 5% 미만 | 창고·버퍼·운반 부족을 무료 삭제로 처리 |
| 저장 | 정상 70%, 장애·containment 포함 90%, headroom 30% 이상 | 통로·접근칸·egress를 바닥 창고로 사용 |

모든 kg와 g는 source, WIP, FacilityBuffer, 창고, 운반, 장착, 소비, 폐기, 반환의 경계를 통과할 때 보존된다. 질량 차이는 외부 입력, 부산물, 반환 포장, 폐기물, 공정 손실처럼 typed disposition으로 설명한다.

### 시장·계약·세력

| 지표 | 기준 |
|---|---:|
| 내부 비교 | `1 gold = 3 EWU` |
| 외부 구매 | EWU 환산 원가보다 25~50% 높음 |
| 외부 판매 | EWU 환산 원가보다 30~50% 낮음 |
| 일반 영업 순이익 | 10~20% |
| 고급 서비스 순이익 | 20~35%, 사고·재고·숙련·공간 부담 포함 |
| 정기 세력 계약 | 해당 기간 총생산의 1~3% |
| 위기 계약 | 3~8% |
| 전략 계약 | 희귀 자산 또는 총생산의 5~15% |
| 장기 계약 손익분기 | 평균 2~4회 이행 뒤 |

세력 교역은 정확한 quote를 먼저 지불하고, 보급은 전역 alliance-benefit EWU 예산에서 차감한다. 화물은 Ready, Publishing, Delivered의 전체 벡터 영수증을 거친다. 부분 생성, 취소·복원 뒤 중복 수령, 즉시 재판매 차익, 세력 수 증가에 따른 무료 보급 증식은 실패로 처리한다.

### 자동화와 환경 장비

자동화 뒤 운반 노동은 5~10%까지 내려갈 수 있다. 전력·정비는 총노동의 5~10%를 소비하고, 자동화의 순노동 회수는 20~35%를 목표로 한다. 수동 시설과 비상 운반은 자동화 정지 중에도 핵심 생존을 유지한다.

의복은 생물 주민당 속옷 완전 세트 3벌, 세탁·건조 처리량은 평균 오염의 125% 이상, 최악 환경의 실내 건조는 24시간 안이라는 기준을 따른다. 일상 세탁·수선은 총노동의 5%를 넘지 않는다. 방한복은 해당 환경의 질병·작업 손실 10~30일분보다 낮은 비용을 가져야 하며, 특수 개조복은 범용복보다 비싸고 대상 신체·환경에서 15~25%의 분명한 이점을 제공한다.

## 진행과 난이도

### 연구와 시설의 투자 회수

| 투자 | 회수 또는 체감 시점 |
|---|---:|
| 초반 생활·저장 시설 | 3~10일 |
| 중세 작업대·서비스 | 10~30일 |
| 환경·의료 시설 | 15~45일 |
| 산업·자동화 시설 | 30~90일 |
| 룬·비전 시설 | 60~180일 |
| 초반 연구 보상 | 5~20일 |
| 중반 연구 보상 | 20~60일 |
| 후반 연구 보상 | 60~180일 |

기준 연구원은 effective `45 WU/일`을 사용한다. 연구권 중앙 기간과 허용 범위는 중세 기반 30일(25~40), 초기 산업 90일(70~120), 성숙 산업 220일(180~280), 후기 룬 산업 360일(300~480), 시간 고정 선행 964일(850~1,100)이다.

연구는 날짜로 잠기지 않는다. 집중 연구는 식량, 의료, 방어 가운데 최소 두 영역에서 실물 기회비용을 만들어야 한다. 완료 영수증 뒤 실제 시설·생산식·아이템·장비를 가동한 날까지 측정한다.

### 런 단계

| 구간 | 운영 과제 | 진행 검증 |
|---|---|---|
| 1~10일 | 생존·수동 복구·기초 비축 | 5~7일 비축, 기본 거처, 강제 침입 없음 |
| 10~30일 | 첫 약속과 예행 압력 | 연구·시설·교역 중 한 주력에 매몰비용, 25·50·75% 예행 침입 |
| 30~120일 | 전문화와 첫 Legacy 준비 | 15~30일 비축, 첫 산업 연구·생산망, 성인 영입·부양 인구 분리 |
| 120~240일 | 전문화와 첫 Legacy | 첫 일반 이정표 p10 120일 이후, 중앙 180~220일 |
| 240~400일 | 혼합·전환·후기 룬 산업 | 후기 룬 산업 중앙 360~400일, 혼합 생산망의 전환 비용 유지 |
| 400~960일 | 문명화·대이정표 준비 | 30~60일 핵심 비축, 전투·의료·세력·자동화 복합 운영 |
| 960일 이후 | 이정표와 엔드리스 | 복합 위기 1회분, 다음 보스 주기 전 회복 |

이정표는 날짜 잠금이 아니라 실제 조건으로 달성한다. 첫 일반 이정표는 p10 120일 이후·중앙 180~220일·p90 300일 이내, 후기 룬 산업은 p10 280일 이후·중앙 360~400일·p90 500일 이내다. 첫 대이정표는 p10 900일 이후·중앙 1,020~1,100일·p90 1,250일 이내, 9개 전체는 p10 1,050일 이후·중앙 1,250~1,400일·p90 1,650일 이내다.

엔드리스는 10일마다 기후, 세력, 질병, 물류, 전투 중 한두 축을 강화한다. 복합 위기 뒤 회복 창은 최소 5일을 목표로 한다. 체력만 누적시키는 방식은 사용하지 않는다.

### 난도와 맥락

보통 난도가 공통 수치 권위다. 쉬움은 경고·회복 창·시작 비축을 늘리고 외부 압력을 낮춘다. 어려움은 외부 압력과 복합 사건 가능성을 높이고 회복 창을 줄인다. 배고픔, 물리 생산, kg 저장, 처방된 BOM, 저장 권위 같은 기본 인과는 모든 난도에서 동일하다.

종족은 최소 두 영역의 강점과 하나 이상의 실제 운영 비용을 가진다. 합리적 종족 전략의 표준 난도 장기 생존율 차이는 10%p 이내를 목표로 한다. 시작 종족은 다른 해답을 만들지만 필수 연구와 이정표를 영구적으로 봉쇄하지 않는다.

## 전투·의료·사회 압력

| 전투 조우 | 승률 | 중증·영구 부상 |
|---|---:|---:|
| 일상 | 85~95% | 5% 미만 |
| 표준 | 65~80% | 10~20% |
| 위험 | 45~65% | 20~35% |
| 보스 초견 | 25~45% | 30~50% |
| 보스 정보·대응 준비 뒤 | 55~70% | 20~40% |

하나의 장비 조합이 전체 조우 절반 이상에서 최적 조합과 5%p 이내면 지배 전략 후보로 올린다. 대응 장비는 대상 조우에서 15%p 이상 유리할 수 있고, 다른 전장에서 10%p 이상의 기회비용을 남긴다.

장비 기여는 캐릭터 전투력의 60%를 넘지 않는다. 무기 35%, 방어구 30%, 방패 15% 상한을 적용하며, 탄약이 비면 무기 기여는 절반이다. 품질 한 단계는 평균 8~12%, 재료 특화는 10~25%, 역사 노드는 범용 5~10% 또는 조건부 15~25%의 범위를 따른다.

생존·질병·사회·문화는 전투 보정과 분리된 비용 축이다. 같은 질병 확진 3명이 10일 안에 발생하면 유행을 선언한다. 일반 특성의 평시 생산 영향은 대체로 ±3~8%, 강한 특성은 단독 ±12% 안을 사용한다. 문화 적응은 방·시설·음식·행사·생활 참여 비용과 장기 통합 효율을 교환한다.

## 적용 순서

밸런스 변경은 공통 시간·노동·EWU, 원료·BOM, 제작·건설, 물류·저장·전력·정비, 생존·농업·의복·기후·의료, 연구, 장비·전투, 시장·계약, 사건·문화, 이정표·엔드리스, 난도 순으로 진행한다. 하류의 날짜·보상만 조정해 상류 생산망 문제를 감추지 않는다.

개별 콘텐츠 수치를 바꾸기 전에는 기준서의 `콘텐츠 추가·수정 필수 기록`을 작성한다. BOM, 작업량, EWU, 공간, 기반망, 위험, 사회·비가역 비용, 대안, 지배 전략 방지, 저장 권위, 자동 감사, 검증 보고서 위치를 모두 채운다.

전수 콘텐츠 분모별 비용 기록, 비교 대상, 순환·지배 감사와 결정론 검증 범위는 [수치 검증 결속](content-plans/balance-validation-binding.csv)에서 관리한다.

여섯 포트폴리오의 인구·압력 정적 판정은 [포트폴리오 압력 단계 매트릭스](content-plans/portfolio-pressure-stage-model.md)에 고정한다. 실행 시드와 플레이 세션의 표본·수용 조건·재조정 기록은 [실행 검증 수용 기준](balance-execution-acceptance.md)을 따른다.
