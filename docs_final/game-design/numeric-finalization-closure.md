# 수치 설계 완결성 기록

현재 수치 인덱스는 33개 콘텐츠 유형, 합계 2,834개 정의를 직접 수치 원장으로 연결한다. 콘텐츠 DB는 stable ID·관계·원본 경로를 찾는 용도만 맡는다. 수치 인덱스에서 콘텐츠 DB만을 최종값 위치로 쓰는 행은 0개다.

합계는 연구 번들과 연구 프로젝트처럼 서로 다른 정의 유형을 각각 포함한다. 동일 stable ID가 다른 원장에서 수치 권위를 중복 소유하지 않는다.

## 값의 경계

- 생산·시설·전투 장비·의료 시술은 해당 BOM과 직접 WU를 직접 소유한다.
- 의복과 환경 작업복의 제작 WU와 BOM은 산출 아이템을 가진 생산식에서 소유한다. 의복 정의는 신체 점유·소재·기준 질량을, 물리 아이템은 운반 kg·가격을 소유한다.
- 사건의 물자 제작 WU는 생산·시술 원장에 남고, 사건 원장은 대응·파견·조정·복구 WU를 소유한다.
- 시설 합성과 진화는 독립 재료 가격을 중복 기입하지 않는다. 투입 건물과 해당 시설 BOM을 이어 받아 계승률, 방 조건, 이력 문턱을 추가 비용으로 가진다.
- 연구 해금 번들은 독립 WU나 가격을 갖지 않는다. 같은 `researchId`의 ResearchProjectSO가 WU를 소유하고 번들은 보상 배열의 구조를 소유한다.

## 정적 조정 결과

여섯 포트폴리오의 연구 75개와 시설 71개를 30·120·400·960일의 실제 선행·BOM·공간·WU 경로로 묶었다. 24개 조립 행의 예산 초과·선행 누락·시설 BOM 누락은 모두 0이다. [운영 약속 원장](content-plans/portfolio-operating-commitments.csv)은 10·30·120·400·960일의 30개 운영 행에 연구 72개·시설 70개·가동 콘텐츠 47개·조우 5개·압력 11개·계약 12개를 직접 연결했고, 해석되지 않는 참조는 0개다.

기후 대조는 5기후 × 4축 × 포트폴리오 6개, 쌍별 대조는 15쌍 × 20셀로 완료했다. 모든 쌍에 역전 맥락이 있다. 인구·압력 대조는 30단계 행 × 5압력으로 확장했다. 산업 경로에서 발견한 세 부족분은 물류에서 예비로 재배치했고, 이후 150개 압력 조건은 정적 기준을 통과한다.

정적 수치 설계는 여기까지 확정한다. 실행·플레이 검증은 [실행 검증 수용 기준](balance-execution-acceptance.md)의 표본과 수용 조건으로 진행한다.
