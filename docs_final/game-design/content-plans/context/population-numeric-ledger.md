# 종족·특성 수치 원장

이 원장은 인구 선택이 설정 문구가 아니라 식량·환경·노동·전투·사회 운영의 수치 차이를 만드는지 확인한다.

| 원장 | 범위 | 행 수 |
|---|---|---:|
| [특성](trait-numeric-ledger.csv) | 출현도·극성·경험·환경 보정·효과 계수·행동·욕구 수치 | 113 |
| [종족](species-numeric-ledger.csv) | 욕구 소비·온도 안전 구간·환경 노출·체류·범죄·기능 역량 계수 | 10 |

특성의 `effect_values`는 해당 특성이 참조하는 실제 효과 정의와 수치를 연결한다. 113개 특성의 효과 정의 참조는 모두 해석된다. 같은 특성이 소비, 작업 속도, 사고 확률을 함께 바꾸면 각 효과를 분리해 포트폴리오와 환경에서 합성한다.

종족의 수치는 하루 소비, 온도·환경 위험, 장기 체류, 노동 적성의 비용과 이득을 동시에 만든다. 종족 하나가 식량·산업·전투·서비스를 모두 앞서는 결과는 정적 지배 결함으로 처리한다. 기후별 비교에서는 종족의 안전 온도, 욕구 배율, 기능 역량과 작업복·시설·비축 비용을 같은 행에서 대조한다.
