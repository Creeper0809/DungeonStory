# 조우 수치 원장

36개 `OffenseEncounterSO`의 실제 적 편성, 현장 강도, 적 수, 능력치 배율, 목표 규칙, 전장 조건, 대응 태그와 보상 아이템을 현재 에셋에서 다시 읽었다. [조우 수치 원장](encounter-numeric-ledger.csv)은 전투력 하나로 조우를 서열화하지 않는다. 같은 적 수라도 목표·전장·대응 태그가 준비 비용과 회복 비용을 바꾸기 때문이다. [적 수치 원장](enemy-numeric-ledger.csv)은 각 조우가 호출하는 36개 적의 체력·공격·이동·전술 가중치·장비·능력·보상 단가를 제공한다.

`enemy_count_min`과 `enemy_count_max`는 각 적 편성의 최소·최대 수와 `additionalEnemyCount`를 합친 값이다. `reward_item_unit_value`는 보상 아이템의 현재 단가 합계이며, 실제 전투 수익은 이 값에서 탄약·수리·치료·전투 인력 공백을 뺀 뒤에만 비교한다.

원장 36행은 조우 에셋 36개와 일치한다. 적 최소 수가 1 미만인 조우는 없고, 보상 아이템을 가진 행의 단가 누락도 없다. 전투 결과 곡선에서는 이 원장의 적 수·배율·목표와 [전투·사건 판정선](../combat-and-event-bands.csv)을 결합한다.
