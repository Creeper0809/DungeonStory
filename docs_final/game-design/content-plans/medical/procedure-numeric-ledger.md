# 의료 시술 수치 원장

[의료 시술 수치 원장](procedure-numeric-ledger.csv)은 47개 `SurgicalProcedureSO`의 직접 WU, 필수 연구·시설 조건, 감염·출혈 위험, 마취·구속 요구, 재료 BOM·kg·단가를 현재 에셋에서 다시 읽는다.

재료 중 `[optional]`은 선택 보조재다. `material_market_value`에는 필수·선택 재료가 모두 들어가므로, 실제 시술 선택의 비교는 필수 재료만으로 가능한 경로와 선택 보조재를 쓰는 안전 경로를 구분해야 한다. 모든 시술은 하나 이상의 재료 BOM을 가지며, 가격을 읽지 못한 재료는 없다.

시술은 치료 효과만으로 비교하지 않는다. 직접 WU, 재료 kg, 감염·출혈 위험, 마취·구속, 의료 시설 점유가 동시에 비용이다. 고위험 시술은 같은 결과를 더 빠르게 내거나 장기 손실을 줄이는 보상을 가져야 하며, 낮은 위험·낮은 비용 시술이 모든 신체·종족·상태를 덮지 못하게 한다.

[질병 수치 원장](disease-numeric-ledger.csv)은 16개 질병의 잠복·전염일, 감염 확률, 중증도, 백신 가능 여부, 만성화와 현장 대응 경로를 기록한다. 시술·약품·격리·환경 대응은 이 질병 위험과 함께 의료 대기열·재고·시설 점유를 비교한다.
