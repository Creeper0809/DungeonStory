# 의복·작업복·장비 모듈 수치 원장

세 원장은 각 정의 에셋의 직렬화 수치를 보존한다. 물리 아이템의 무게와 가격은 `item-numeric-ledger.csv`에서 같은 ID로 결합했다.

`physical_unit_weight_g`는 재고·운반·거래에 쓰이는 물리 아이템 질량이다. `base_weight_kg`는 의복 정의가 소재량·재단 계수 계산에 쓰는 기준 질량이다. 두 값이 같은 행도 있고, 환경 작업복처럼 의도적으로 다른 행도 있다. 서로 대체하거나 평균내지 않는다.

의복과 작업복의 제작 작업량·재료 BOM은 생산식 원장에만 존재한다. 이 세 정의에는 독립 제작 WU가 없으므로, 같은 물리 아이템을 산출하는 `ProductionRecipeSO`의 `required_work`와 물리 BOM을 사용한다. 모듈은 원정 보상 정의이며 제작 BOM과 WU를 직렬화하지 않는다. `power_per_grade`와 `utility_per_grade`가 등급별 전투 효과의 직접 수치다.

전략 판정에서 의복은 연구 해금, 신체 점유, 소재 태그, 운반 질량과 거래가를 함께 소비한다. 작업복은 온도 범위와 노출 배율을 통해 노동 손실을 막는다. 장비 모듈은 무기·방어구·방패 계보와 최소 시대가 달라 동일 슬롯에서 전부를 취할 수 없게 만든다.
