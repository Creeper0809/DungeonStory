# 사건 대응 노동 원장

172개 사건은 요구 물자만 가진 텍스트 선택지가 아니다. 각 사건은 대응·조정·인계·복구에 드는 노동 범위를 가진다. 이 원장은 모든 사건 stable ID에 대응 WU를 부여한다. 제작·요리·치료·장비 생산에 이미 기록된 WU는 다시 더하지 않는다. 사건 대응 WU는 준비된 물자를 현장에 배치하고, 사람·공간·서비스·관계를 조정하며, 결과를 복구하는 노동이다.

| 원장 | 행 수 | 기준값 |
|---|---:|---|
| [생애 사건](life-event-response-labor-ledger.csv) | 32 | 선택지·긴급도·기한·요구 물자의 대응 WU |
| [서비스 사고](service-incident-response-labor-ledger.csv) | 8 | 격리·중재·체포 같은 대응 갈래의 WU |
| [계절 사건](seasonal-event-response-labor-ledger.csv) | 28 | 현재 가용 WU의 배정 비율과 기간별 WU |
| [세력 계약](faction-contract-response-labor-ledger.csv) | 18 | 화물·기한·시설·계약 등급의 파견 WU |
| [세력 장](faction-chapter-response-labor-ledger.csv) | 36 | 장 선택·화물·시설의 대응 WU 범위 |
| [손님 요청](guest-request-response-labor-ledger.csv) | 14 | 예약·서비스·인계 WU |
| [축제](festival-response-labor-ledger.csv) | 16 | 준비·참가·정리 WU |
| [문화 관습](cultural-practice-response-labor-ledger.csv) | 20 | 반복 수용·유지 WU |

## 계산 규칙

`kg`와 `market`은 선택지 또는 사건 정의가 요구하는 실물 투입의 현재 수치다. `시설`은 요구 시설 개수, `기한`은 남은 대응 일수, `갈래`는 선택지 수다. `ceil`은 올림이다.

| 사건군 | 대응 WU |
|---|---|
| 생애 사건 | `8 + 6×갈래 + 18×긴급도 + ceil(24/기한) + ceil(3×선택 물자 kg) + ceil(선택 물자 시장가/100)`; 자동 기록은 `0 WU` |
| 서비스 사고 | `24 + 8×갈래 + ceil(3×선택 물자 kg) + ceil(선택 물자 시장가/100)` |
| 계절 기회 | `ceil(현재 가용 WU/일 × 배정 bps/10,000) × 사건 지속일`, 배정 비율 `7.5~10%` |
| 계절 압력 | `ceil(현재 가용 WU/일 × 배정 bps/10,000) × 사건 지속일`, 배정 비율 `11.5~15%` |
| 세력 계약 | `16 + 12×계약 등급 + 8×시설 + ceil(24/기한) + ceil(3×화물 kg) + ceil(화물 시장가/100)` |
| 세력 장 | `12 + 8×갈래 + 8×최대 시설 요구 + ceil(3×선택 물자 kg) + ceil(선택 물자 시장가/100)` |
| 손님 요청 | `16 + 8×시설 + ceil(24/기한) + ceil(3×서비스 물자 kg) + ceil(서비스 물자 시장가/100)` |
| 축제 | `12 + 6×최소 참가자 + 8×요구 시설 + ceil(3×준비 물자 kg) + ceil(준비 물자 시장가/100)` |
| 문화 관습 | `12 + 8×시설 + ceil(3×유지 물자 kg) + ceil(유지 물자 시장가/100)` |

선택지가 둘 이상인 사건은 `planned_min_response_wu`와 `planned_max_response_wu`를 함께 가진다. 물자·시설·관계 손실이 작은 선택이 자동으로 노동까지 가장 싸지는 않는다. 세력 장과 생애 사건처럼 선택지별 물자 요구가 달라지는 경우, 실제 선택지는 이 범위 안의 해당 계산값을 사용한다.

계절 사건은 인구와 시점에 따라 같은 비율이 다른 절대 WU가 된다. 원장에는 12인 운영 기준인 `540 effective WU/day`에서의 최소·표준·최대 WU와 실제 배정 비율을 함께 기록한다. 예를 들어 2~4일짜리 가을 카라반 기회는 7.5% 배정으로 82·123·164 WU가 필요하고, 같은 기간의 이른 서리 압력은 11.5% 배정으로 126·189·252 WU가 필요하다.

## 선택의 후폭풍

- 생애 사건은 관계·기억·직책을 보존하는 길, 물자를 보존하는 길, 즉시 문제를 끝내는 길이 서로 다른 WU·물자·후속 상태를 가진다.
- 서비스 사고는 안전·서비스 연속성·관계 회복을 한 번에 최대로 만들 수 없다. 격리와 치료, 중재와 체포는 각자 다른 인력·공간·외교 비용을 쓴다.
- 계절 압력은 주력망을 멈추지 않고 감산으로 유지하는 대응을 기본값으로 둔다. 기회 사건은 핵심 생존선을 빼앗지 않으며, 투자하지 않았을 때 보상 창만 닫힌다.
- 계약과 손님 요청은 화물 제작 WU 외에 실제 파견·보관·인계·기한 조정 노동을 요구한다. 시장 구매가 제작을 대체해도 그 노동과 공간은 사라지지 않는다.
- 축제와 문화 관습은 일회성 보상으로 관계를 무한 증식시키지 않는다. 준비 물자·참여 인력·공간 슬롯을 계속 점유하고, 거절은 미래 관계·통합 압력으로 남는다.

각 행의 `runtime_work_binding`은 이 노동이 실제로 어떤 작업 주문으로 물질화되어야 하는지 적는다. 현재 상태는 `document-final-runtime-unbound`다. 이벤트 원장·작업 주문·저장·복원·UI·AI를 연결한 뒤에만 이 값을 실행 수치로 사용한다.
