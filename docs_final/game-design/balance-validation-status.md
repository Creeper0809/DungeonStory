현재 Editor.log는 `ProductionEconomyDebugScenarios.cs`와 두 Economy Editor scenario 파일에서 `inputOwners` 생성자 인자가 빠진 `CS7036` 오류 17건을 기록한다. `Assembly-CSharp.dll`은 남아 있지만 `Assembly-CSharp-Editor.dll`은 생성되지 않았다. 이 문서 작업에서는 오류를 수정하지 않는다. 기존 `PASS` 파일은 현재 물리 BOM 변경 뒤의 결과로 사용하지 않는다.

완료 조건은 현재 소스 컴파일 후 다음 순서로 실행한다.

1. 256-seed 경제, market authority, labor/facility authority, strategic content calibration, 6인 생존 loop와 output/haul/restore를 재생성한다.
2. 최소 식량·보존·섬유·의료·군수 빌드별로 같은 seed·인구 단계·사건 압력에서 자본, WU, 물류량, 생존, 전투 결과, 보상을 비교한다.
3. 지배 빌드, 도달 불가 빌드, 선택해도 결과가 달라지지 않는 빌드를 수치와 실제 플레이 로그로 제거하거나 보정한다.
