# 반복 플레이 메타 검증

## 검증 대상

반복 플레이는 연구를 전부 빠르게 해금하는 효율 경쟁이 아니라, 같은 생존 문제에 서로 다른 물리 경로를 세우고 그 선택이 인구·기후·세력·사건·전투에 남기는 차이를 확인하는 과정이다.

기준 전략은 다음 여섯 포트폴리오다.

| 포트폴리오 | 초반에 묶는 자원 | 늦어지는 투자 | 장기 회수 |
|---|---|---|---|
| 봉인 생태 공동체 | 지하 생태, 물, 습윤 공간, 보존 | 외부 농업과 교역 확장 | 환경 저항과 안정적 자급 |
| 지하 균사 도시 | 균사 생산, 저조도, 습윤, 밀집 작업 | 건조·개방형 생산과 고급 서비스 | 공간 효율과 특수 재료 |
| 환대 교역 연방 | 객실, 서비스, 재고, 교역 관계 | 군수·중공업 집중 | 외부 조달과 관계 자본 |
| 요새 산업국 | 복도, 방어, 증기·전력, 저장, 정비 | 환대와 경량 기동 | 안정 생산과 거점 방어 |
| 원정 병기국 | 훈련, 장비, 탄약, 의약품, 원정 보급 | 민수 확장과 일부 자동화 | 전리품·정찰·대외 영향력 |
| 비전 계보 성역 | 룬, 기록, 계보, 의료, 고유 장비 | 저비용 대량생산과 즉시 회수 | 후기 문명 능력과 역사 진화 |

각 포트폴리오는 실제 연구, 가동 시설, 물리 재고, 작업 분배, 계약, 장비, 세대, 진화 영수증으로 판정한다.

## 한 런에서 확인할 선택의 흔적

| 구간 | 기록할 선택 | 다른 런과 갈라져야 하는 결과 |
|---|---|---|
| 1~30일 | 식량·물·위생·방어·교역 중 첫 주력 | 연구 순서, 첫 방 구성, 비축 구성, 노동 분배 |
| 30~120일 | 생산망·서비스·자동화·원정 중 첫 전문화 | 필요한 중간재, 창고·동선, 인력·숙련, 외부 의존 |
| 120~240일 | 첫 Legacy와 전환 여부 | 시설의 조립·해체·재사용, 장비·세력·문화의 후속 압력 |
| 240~400일 | 혼합 또는 주력 교체 | 기존 투자 회수, 전환 중 생산 손실, 새 병목 |
| 400일 이후 | 문명 구조와 엔드리스 대응 | 복합 위기 회복, 고유 장비·계보·세력 의무, 이정표 압력 |

전략 판정은 완료 연구 수가 아니라 실제 가동 영수증으로 한다. 연구 완료 뒤에도 시설·재료·전력·물·운반·인력·공간이 없어 가동하지 못한 항목은 전략 기여로 계산하지 않는다.

## 지배 전략 판정

다음 중 하나라도 성립하면 지배 전략 후보로 올린다.

- 한 빌드가 모든 기후에서 생산 안정성, 생존, 첫 이정표 시간을 동시에 1위로 유지한다.
- 하나의 장비 조합이 전체 조우 절반 이상에서 최적 조합과 5%p 이내 성능을 낸다.
- 사건의 균형 상태 선택지 기대가치 차이가 15%를 넘고, 준비 상태가 없는데도 한 선택이 반복적으로 우세하다.
- 한 종족이 농업, 산업, 전투, 서비스, 세대 운영을 함께 지배한다.
- 자동화가 전력·정비·버퍼·오버플로 없이 운반 노동만 지운다.
- 교역·보급·원정이 물리 화물, quote, 경로, 위험, 쿨다운 없이 내부 생산을 대체한다.

대응 장비, 특정 준비, 종족 환경 적합성, 세력 계약은 국지적으로 강해질 수 있다. 그 이득은 다른 조우·환경·관계·공간·노동에서 실제 비용을 남긴다.

## 결정론적 검증 매트릭스

| 축 | 필수 표본 |
|---|---|
| 날짜 | 1, 3, 10, 30, 60, 120, 240, 400, 960, 1,200 |
| 인구 | 3, 10, 30, 100, 500, 2,000 |
| 기후 | 온대 동굴, 서리 균열, 잿불 황무지, 균사 심층, 마나 폭풍지 |
| 종족 | 던전 종족 9개와 인간 |
| 정책 | 균형, 연구집중, 군사집중, 서비스집중, 자동화집중, 계보집중 |
| 난도 | 쉬움, 보통, 어려움 |
| 시드 | 경제·진행 256개 이상, 전투 조합당 1,000회 이상 |

모든 축을 하나의 거대한 전수 곱으로 즉시 실행하지 않는다. 정적 카탈로그 감사는 모든 정의를 대상으로 하고, 다중 시드는 다음 층으로 나눈다.

1. 같은 시드·입력·저장 복원이 같은 결과를 내는지 확인한다.
2. 여섯 포트폴리오와 기후·종족·난도의 대표 조합에서 경제·진행 256시드를 실행한다.
3. 조우·장비·숙련·탄약·부상 조합마다 1,000회 전투 표본을 실행한다.
4. 지배 전략 후보와 종족 편차 후보는 인접한 대체 빌드·대체 기후·대체 세력 경로를 추가해 비교한다.
5. 수치 변경 뒤에는 영향 콘텐츠와 상류 경제 경로를 다시 감사한다.

## 런 보고서

자동 보고서는 아래 값을 한 시드의 평균만으로 숨기지 않고 중앙값, p10, p90, 실패 원인, 복구 소요와 전략별 분포로 남긴다.

- 노동 배분, 작업 차단 원인, 운반 비중, 정비·전력 노동
- 재고 일수, kg/g 흐름, EWU 흐름, 생산 병목, 출력 포화
- 연구 완료와 실제 가동 사이의 시간, 시설 회수 기간, 이정표 도달 분포
- 전투 승률, 라운드, 탄약·약품·식량·내구 소모, 부상과 회복 비용
- 사망, 붕괴, 이탈, 계약 실패, 세력 관계 악화의 원인
- 사용률이 낮은 연구·시설·아이템·장비와 그 원인
- 최적 전략과 차선 전략의 격차, 종족·기후·난도별 장기 생존 편차
- 중요 사건·경보·자동 소사건의 동시 수와 예상 입력량

기준선은 동일 시드·동일 입력·동일 저장 복원에서 같은 결과를 내야 한다. 프레임률, UI 재개방, 로드 순서, 무관 인구의 추가 tick이 경제·전투·사건 결과를 바꾸면 해당 결과는 무효다.

## 승인 문턱

각 수치 변경은 다음을 모두 통과해야 한다.

1. 대상 정의 전부에 BOM, WU, EWU, 공간, 위험, 대안, 저장 권위, 자동 감사가 있다.
2. 물리 질량, 수량, custody와 production WIP가 보존된다.
3. 구매·제작·판매·해체·반환·세력 화물의 순환 이익이 기준을 넘지 않는다.
4. 목표 시점에 필요한 연구·시설·인력·장비·비축이 물리적으로 도달 가능하다.
5. 지배 전략, 종족 편차, 장비 상성, 사건 선택지, 문화·세력 우회 경로의 감사가 통과한다.
6. 다중 시드 분포와 저장 복원이 목표 밴드 안에 있다.
7. UI가 재료, 작업자, 경로, 위험, 출력 공간, 정책 중 실제 실패 원인을 설명한다.

최종 밸런스 승인은 실제 플레이테스트의 분포·선택·회복 증거까지 갖춘 뒤에 부여한다. 이 문서는 그 전 단계에서 빠진 증거를 드러내는 검증 계약이다.
