# 01. 제품 범위와 독자

## 목표

이 위키는 개발 문서를 웹으로 복사하는 프로젝트가 아니다. 플레이어가 게임의 규칙과 콘텐츠 관계를 빠르게 이해하고, 개발팀은 동일한 사실을 중복 입력하지 않도록 하는 공개용 투영물이다.

## 핵심 독자

| 독자 | 대표 질문 | 우선 경험 |
|---|---|---|
| 처음 시작한 플레이어 | 무엇을 먼저 만들고 왜 필요한가? | 쉬운 요약, 용어 링크, 스포일러 보호 |
| 숙련 플레이어 | 이 재료의 모든 사용처와 대체 경로는? | 밀도 높은 표, 역참조, 비교, 생산 관계 |
| 복귀 플레이어 | 이전 게임 버전에서 무엇이 달라졌나? | 게임 버전, source snapshot digest, 업데이트 기록, 리디렉션 |
| 공략 작성자 | 수치와 조건을 믿고 인용할 수 있는가? | 출처 revision, 정확한 필드, 영구 URL |
| 개발·QA | 공개 페이지가 현재 자산과 일치하는가? | 내부 프리뷰 근거, 예외 보고서, 결정론 검증 |

## 사용자 과업

위키 V1은 다음 과업을 짧은 경로로 해결해야 한다.

1. 이름·별칭·안정 ID 일부로 콘텐츠를 찾는다.
2. 한 페이지에서 획득법, 생산법, 사용처, 선행 연구, 관련 시설로 이동한다.
3. 시스템 안내에서 개별 콘텐츠 예시로 내려가고 다시 상위 규칙으로 돌아간다.
4. 표를 필터·정렬해 후보를 비교한다.
5. 스포일러를 의도적으로 열기 전에는 제목·검색 결과·링크 미리보기에서도 보지 않는다.
6. 현재 게임 버전, 페이지의 source snapshot digest, 자동 생성 여부와 게임 버전별 변경점을 확인한다.
7. 게임 버전 선택기로 같은 문서의 과거 snapshot을 보고 당시 검색·관계·수치를 함께 탐색한다.
8. 아이템·제작식·시설·연구를 중심으로 필요한 관계만 그래프로 열고, 필터·깊이·방향을 바꿔 목표까지의 경로를 찾는다.

## V1 포함 범위

- 홈, 전체 검색, 카테고리 탐색, 최근 데이터 갱신 안내
- 핸드북 기반 게임 소개와 시스템 가이드
- 공개 허용된 아이템, 원료, 중간재, 시설, 생산식, 연구, 장비, 인물·특성, 농업·축산, 의료·질병, 사건·세력·원정·전투 콘텐츠
- 자동 역참조: 생산 재료, 생산 결과, 필요 시설, 연구 해금, 사용처, 관련 시스템
- 유형별 목록과 비교 가능한 데이터 표
- 아이템·제작식·시설·연구의 작은 관계 그래프, 방향·유형·깊이·스포일러 필터와 표 fallback
- 문서 목차, 내부 링크, 관련 문서, 무엇이 이 문서를 가리키는지 보여 주는 역링크
- 게임 버전과 `/updates/`, source snapshot digest, 자동 생성 경고, 리디렉션, 404 복구 탐색
- current와 모든 retained 게임 버전의 문서 snapshot, 게임 버전별 검색·관계 탐색
- 한국어 UI와 한국어 검색; 영문·내부 별칭은 검색 보조어로만 지원

## 명시적 제외

- 공개 사용자 회원가입, 직접 편집, 토론, 댓글, 추천·비추천
- 런타임 게임 서버, 로그인, 데이터베이스, 공개 사용자 편집 기능
- AI가 사실이나 공략을 임의로 생성해 즉시 공개하는 기능
- 세이브 파일 업로드, 빌드 계산기, 인터랙티브 맵, 모드 데이터베이스
- C# 클래스 목록, 내부 파일 경로, 저장 권위 등 개발자 전용 정보의 공개
- 커뮤니티 위키 미러링이나 다른 위키의 문장·HTML·스타일 복제
- 게임 콘텐츠·밸런스 수정

## 제품 원칙

- 사실은 한 번만 소유한다. 위키의 수치는 원천에서 생성하고 손으로 복사하지 않는다.
- 공개는 허용 목록 방식이다. 분류가 불분명하면 노출하지 않는다.
- 읽기 흐름은 사람 중심, 근거 흐름은 기계 검증 가능하게 유지한다.
- 검색 없는 탐색과 링크 없는 검색 결과를 모두 피한다.
- 모바일을 축소판으로 만들지 않는다. 좁은 화면에서는 표·목차·인포박스를 재배치한다.
- 페이지 수보다 신뢰 가능한 연결과 예외 처리의 완성도를 우선한다.

## 성공 지표

V1 승인 시 다음을 측정한다.

- 대표 30개 질문 중 90% 이상을 검색 또는 세 번 이하의 내부 이동으로 해결
- 공개 대상 엔터티 100%에 고유 canonical URL과 제목 존재
- 생성된 공개 링크 오류 0건, 고아 공개 페이지 0건
- 검색 대표어 세트의 top-5 적중률 90% 이상
- 수치 필드의 수기 복제 0건
- 차단 등급 콘텐츠의 HTML·검색 색인·사이트맵 누출 0건
- 키보드 전용 핵심 과업 완료와 WCAG 2.2 AA 자동 검사 중대 오류 0건

## 출시 정의

로컬에서 페이지가 보이는 상태는 출시가 아니다. 데이터 freshness, 공개 필터, 검색, 링크, 접근성, 성능, 보안, 배포 롤백 조건을 모두 통과하고 소유자가 공개 게이트를 승인해야 V1로 부른다.
