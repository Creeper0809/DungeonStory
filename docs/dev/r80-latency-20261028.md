# R80 응답 지연과 말풍선 만료 개선

2026-10-28. 같은 R80 단일 8B 모델의 처리 순서와 요청 수명을 수정하고 실제 Gameplay에서 30분 연속 실행했다. 짧은 응답의 분 단위 대기는 해소됐지만, 모든 AI 기능이 수초 안에 끝나는 상태는 아니다.

## 변경

- 말풍선 전용 처리 자리 하나, 일반 짧은 응답 하나, 후보 생성 두 개를 분리했다. 긴 후보 생성이 말풍선 자리를 차지하지 않는다. 모델은 하나이며 가중치를 복제하거나 교체하지 않았다.
- 화면 밖 말풍선과 인물별 중복 요청을 접수 전에 막는다. 처리 자리가 없으면 새 말을 줄세우지 않는다. 인물 퇴장, 풀 반환, 월드 복원으로 원래 소유자가 사라지면 요청을 취소하고 실제 추론 연결도 닫는다. 늦게 도착한 이전 인물의 응답은 표시하지 않는다.
- 원래 대기 만료 3초와 말풍선 생성 제한 4초를 유지한다. 표시가 끝나기 전에 같은 인물의 다음 생성을 반복하지 않는다.
- 공개 입력의 반복 부분은 기존 무손실 인코딩으로 압축한다. 원래 사실, 참가자, 사건과 값의 왕복 동일성을 검사했다. 입력 잘라내기, 효과 선택 코드, 출력 수선은 추가하지 않았다.
- 내용 검사에서 거절된 동일 입력의 무한 재시도를 막고 실제 실패 상태를 남긴다. 일시적 통신 실패는 기존 재시도 경계를 유지한다. 완료된 성격 설명은 공식 저장과 복원에 보존한다.
- 이력 설명도 짧은 응답 자리에서 처리한다. 접수 전 용량 거절은 모델 시도 횟수로 세지 않는다. 실제 접수 후 시간 초과의 원래 재시도와 10초 제한은 유지한다.

## 최종 실제 시험

권위는 `Artifacts/QA/R80Latency-20261028-r1/soak-r13`이다. 이전 실패나 부분 실행 시간은 합산하지 않았다.

- 연속 실제 시간 1,800.295초, 시뮬레이션 7,020프레임, 게임 시간 782.084초.
- 공식 중간 저장과 복원 5회, 최종 저장과 복원 1회. Unity 오류 0, 응답 주입 0.
- 서로 다른 완료 인물의 최종 성격 설명 24개를 보존했다. 6회 복원별 보존 수의 합은 119이며 서로 다른 119명이라는 뜻이 아니다. 설명과 생성 근거 및 기존 게임 수치를 대조했다.
- 현 소스 컴파일과 표적 회귀 PASS, Python 계약 검사 28개 PASS. 실행 중 소스 90개 변경 0.
- R80 가중치, 지원 파일 129개, 기존 모델 3개를 포함한 133파일의 독립 전체 해시 PASS. 실제 입력 예산 784개에서 잘림 0.
- 별도 비대화형 OS 데스크톱과 창 생성 프로브 PASS. 사용자 데스크톱으로 전환하지 않았다. 종료 후 이 시험의 Unity와 모델 프로세스는 남지 않았다.

### 응답 시간

시간은 접수부터 실제 소비자 콜백까지다. 중앙값과 P95는 성공한 응답만의 분포이며 실패를 성공 분모에 넣지 않았다. P95는 성공 응답 95%가 해당 시간 이내라는 뜻이다.

|---|---:|---:|---:|---:|---:|---:|
| 말풍선 | 231 | 16 | 3 | 13 | 3.47초 | 4.97초 |
| 성격 설명 | 34 | 0 | 0 | 0 | 9.89초 | 17.67초 |
| 큰 행동 목표 | 3 | 0 | 0 | 0 | 5.13초 | 10.38초 |
| 감정 반응 | 11 | 0 | 1 | 0 | 5.16초 | 8.36초 |
| 소문 | 105 | 22 | 3 | 0 | 6.98초 | 8.96초 |
| 인물 기록 | 6 | 0 | 0 | 0 | 4.83초 | 7.32초 |

30분 안에 접수된 종결 요청은 627건으로 성공 437, 실패 79, 취소 98, 만료 13이다. 표의 실패 중 말풍선 16, 소문 22, 이력 12는 원래 시간 제한에 걸렸다. 습득 특성 29건은 모델이 낸 근거 또는 인물 표현이 기존 내용 검사를 통과하지 못했다. 결과를 임의 특성이나 가짜 설명으로 바꾸지 않았다.

말풍선 성공 231건의 대기는 중앙값 0.36초, P95 1.11초, 최대 1.57초였다. 응답 전체 최대는 7.17초였다. 231건의 표시 관측은 실제 소비자의 텍스트 일치에 기반하므로 인물별 유일 상관관계 증명으로 확대하지 않는다.

원래 여섯 짧은 프로필 전체는 종결 448건 중 성공 390, 실패 38, 취소 7, 만료 13이다. 성공 응답의 중앙값 4.19초, P95 9.67초, 최대 20.15초이며 대기 P95는 3.24초다. 이 묶음에는 진화 이력을 포함하지 않았다. 접수 전 말풍선 용량 억제 333건과 큐 전체 구간 용량 거절 4,000건은 생성 성공이 아니다.

### 이전 관측과 비교

이전 실제 30분 시험 `R80ExtendedPlay-20261027-r1/soak-r11`에는 말풍선 성공 30건, 대기 만료 641건과 대기 중 232.5초 관측이 있었다. 이번 시험에서는 말풍선 성공 231건, 만료 13건이며 대기 중 스냅샷의 최대는 21.7초다. 전체 완료 요청 대기의 최대는 별도 지표로 59.04초다.

접수 정책과 실제 인물 및 사건이 달라 같은 부하의 속도 배율이나 성공률 개선으로 단정하지 않는다. 필요 없는 요청을 보내지 않은 효과와 실제 추론 지연을 구분한다. 수치 출처와 집계 경계는 `latency-comparison-r1.json`에 남겼다.

## 남은 한계

- 기술 후보 세 개는 선택과 서술을 순서대로 생성하므로 여전히 오래 걸린다. 플레이 중 말풍선과 별도 자리에서 처리하지만 기술 창의 결과 대기가 즉시 응답으로 바뀐 것은 아니다.
- 진화 이력은 실제 시설 3개 모두 최종 적용 미완료다. 전달에 성공한 응답도 고정된 근거 8개 중 1개만 반환해 기존 검사를 통과하지 못했다. 최종 저장의 `instanceEvolution.narrativeRequests`는 `completed=false`, 대응 이력의 이름과 설명은 빈 값이며 `playerVisible=false`다. 기존 `narrativeReady=true` 값이나 HTTP 성공만으로 적용 PASS를 주장하지 않는다. 원래 검사와 미완료 요청을 그대로 남겼다.
- 특성의 모델 응답에도 내용 거절이 남는다. HTTP 성공을 게임 상태 적용이나 문장 품질 승인으로 세지 않는다.
- 인물 기록의 실제 소비자 검사에는 원문 거절도 있었다. 위 성공 수만으로 모든 설명이 자연스럽고 사실에 맞는다고 주장하지 않는다.
- 최종 공식 전체 저장과 복원은 게임 스레드를 69.64초 막았다. 이는 이 시험에서 명시 실행한 월드 저장과 복원이며 성공한 AI 응답 분포와 별도로 남겼다. 저장 성능 전체를 이번 수정으로 해결했다고 보지 않는다.
- 이번 실행은 실제 게임 코드와 실제 모델을 이용한 그래픽 없는 자동 Gameplay다. 수동 플레이의 화면 프레임률이나 모든 콘텐츠 조합의 품질 인증은 아니다.
