# DungeonStory 50 WU 전역 밸런스 재조정 인벤토리

> 상태: 재조정 대상 전수 목록
>
> 기준일: 2026-08-16
>
> 기준 노동: `50 actual WU/성인·일`, `45 output-equivalent WU/성인·일`
>
> 목적: 개별 수치를 바로 고치는 문서가 아니라, 전역 재조정에서 빠뜨리면 안 되는 정의·수치·순환·검증 항목을 고정한다.

## 1. 이번 재조정의 기준

현재 5일 3-seed 실측은 성인 1명당 하루 실제 승인 노동 `44.418 / 48.882 / 53.126 WU`, 평균 `48.809 WU`를 기록했다. 프로젝트에 실제 반영된 산출 등가 노동은 평균 `44.971 WU`다. 따라서 다음 두 값을 분리해 사용한다.

| 기준 | 값 | 사용처 |
|---|---:|---|
| 실제 노동 용량 | 50 WU/성인·일 | 주민 시간, 작업 배분, 욕구·이동 기회비용, 작업 중단, 숙련 XP |
| 프로젝트 산출 용량 | 45 WU/성인·일 | 건설·생산·연구·대형 프로젝트의 실제 완료 속도와 ROI |
| 과거 일정 상한 | 99 WU/성인·일 | 역사 비교만 허용. 신규 비용·기간 계산 금지 |

모든 기존 `20 WU`와 `99 WU` 파생값을 같은 비율로 일괄 곱하거나 나누면 안 된다.

- 주민의 하루 시간비용과 자기관리 기회비용은 `50 actual WU`를 사용한다.
- 시설·연구·생산 완료 기간은 `45 output-equivalent WU`와 실제 동시 작업 한계효율을 사용한다.
- 식량·물·약품처럼 물리 수량이 핵심인 항목은 인구당 실제 소비량에서 다시 푼다.
- 전투·질병·사건은 WU 환산만으로 정하지 않고 승률, 사망, 부상, 회복, 재고 소모를 별도 유지한다.
- 금화·기분·관계·고유 유물·플레이어 입력은 노동으로 흡수하지 않고 독립 비용축으로 남긴다.

## 4. 전역 상수와 노동 경제

### 4.1 시간표와 노동 용량

- 하루 길이 180초, 배속별 체감 시간, 일 경계 처리.
- 수면·식사·음수·위생·유흥·배변의 발생 간격과 행동 시간.
- 작업 중 이동, 욕구 이동, 큐 대기, 기타 이동, 유휴 시간의 목표 비율.
- 실제 승인 WU와 산출 등가 WU의 구분 및 손실 원인.
- 작업 전환 효율, 경로 탐색 지연, 예약·시설 대기, 교대 길이.
- 정상 노동 배분: 유지 25~35%, 운반 12~20%, 성장 35~50%, 비상 여유 10~20%.
- 1·3·10·30·60·120·240·400·960·1,200일의 성인당 실측 처리량.
- 기술 단계별 생산성 목표는 새 실측 뒤 다시 작성하며, 기존 `20→40` 지수 표는 폐기 대상이다.

### 4.2 31개 작업 타입

각 작업은 작업 발생량, 목표 수, 기본 WU, 이동거리, 시설 슬롯, 우선순위, 숙련, 사고, 중단 가능 체크포인트, 비상 선점, 완료 보상을 각각 검토한다.

`Operate`, `Restock`, `Construct`, `Repair`, `Clean`, `Research`, `Guard`, `Reception`, `Rescue`, `Rest`, `Craft`, `Haul`, `Hunt`, `Butcher`, `DrawWater`, `Cook`, `Treat`, `Surgery`, `Refuel`, `Warden`, `Perform`, `Gather`, `Sow`, `Harvest`, `Logging`, `Quarry`, `AnimalCare`, `GrandProject`, `ThreatMitigation`, `Plumbing`, `Dismantle`.

### 4.3 작업자 성능

- 9개 숙련의 속도·품질·사고 배율과 `XP/WU`.
- 14개 신체 기능의 작업·이동·전투·의료 병목.
- 종족, 특성, 나이, 건강, 부상, 질병, 기분, 피로, 환경, 장비 효과.
- 직접 작업·멘토링·훈련·전투 XP의 상한과 반복 감쇠.
- 전문가·대가 쇠퇴와 복귀 비용.
- 다중 작업자 기여 곡선: 건설, 연구, 대형 프로젝트, 수술 보조.
- 야간·비상·장기 교대의 속도, 사고, 피로, 기분 비용.

## 5. 시작 상태와 초반 생존

- 시작 주민 3명의 종족·숙련·특성·나이·건강 분포.
- 시작 금화, 음식, 물, 의약품, 장비, 원료, 청사진, 저장 용량.
- 첫 1·3·10일에 필요한 거처·물·식량·수면·위생·배변 시설의 설치 BOM과 WU.
- true-start 대체 행동: 야전식, 바닥 수면, 간이 변소, 양동이 세척의 시간·물리 소비·페널티.
- 초기 시설이 완성되기 전 primitive 사용 횟수와 작업 손실.
- 첫 재배·조리·저장·의료·방어·연구 루프를 여는 최소 물리 재고.
- 초기 실패 뒤 복구 가능한 비축 일수와 soft-lock 방지.

## 6. 욕구·생활 서비스·기분

각 욕구는 감소율, 일반·긴급 임계값, 회복량, 행동 시간, 시설 역할, 시설 용량, 물리 소비, 경로 거리, 큐 허용시간, 기분 효과, 붕괴 효과를 한 세트로 맞춘다.

- 허기: 식사 빈도, 1회 섭취량, 영양, 품질, 간식, 과식, 부패.
- 갈증: 물 소비량, 안전 수원, 용기, 수동 급수, 긴급 음수.
- 수면: 수면 시간, 침상 품질, 바닥 수면, 교대·야간 페널티.
- 위생: 감소율, 세척 회복량, 물·하수, 오염, 의복·질병 연동.
- 배설: 빈도, 변소 용량, 물 사용, 오수·오물 출력, 기분·위생.
- 재미: 시설별 회복, 이용 시간, 음료·행사 소비, 중독·과다복용.
- 기분·스트레스: 임계값, 기억 지속시간, stack cap, 관계·붕괴·이탈.
- deprivation: routine, emergency, imminent harm, breakdown의 전환선과 회복 우선순위.
- 생활시설별 좌석·동시 이용·서비스 시간·재고 버퍼·회복량.
