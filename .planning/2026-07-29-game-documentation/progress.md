# DungeonStory 게임 전체 문서화 진행 기록

## 2026-07-29

- `planning-with-files`, `unity-csharp-scripting` 지침을 확인했다.
- 저장소 루트와 기존 계획 목록, 프로젝트 지침을 확인했다.
- 기존 활성 계획을 보존하고 요청 전용 계획 디렉터리를 생성했다.
- 현재 단계: 기존 기록 복구 및 코드 인벤토리 준비.
- 루트 계획 전체를 읽어 V1~V17에서 구현되었다고 기록된 게임 루프와 기능 축을 요약했다.
- 기존 발견 기록에서 시스템 통합 경계, 과거 결함의 원인, 성능/저장/물리 자원 소유권 결정을 추출했다.
- 현재 활성 계획의 시설/장비 무한 진화 범위와 구현 진행 상태를 확인했다.
- 활성 진화 계획의 발견/진행 기록 전체를 읽어 실제 추가된 모델·작업·저장 연결을 반영했다.
- `Assets`와 `Assets/Scripts` 규모 및 도메인 파일 구조를 인벤토리화했다.
- Unity/패키지 버전, 빌드 씬 순서, asmdef 경계, 기존 기획/구현 보고서 목록을 확인했다.
- 기존 게임 디자인 개요/플레이어 경험/진행 범위 문서에서 장르 정체성, 핵심 판타지, 루프 원칙, 장기 TODO를 추출했다.
- 구현 근거 매트릭스와 QA 기록에서 실제 씬/포인터/상태 변화/저장 검증 범위를 확인하고, 남은 인간 첫 플레이 게이트를 기록했다.
- 광범위 타입 인벤토리 1차 시도는 출력 과다로 일부 실패했지만, 외부 사건·서커스·축산·출입문·런 변수·시설 능력 콘텐츠를 추가 확인했다.
- Gameplay composition root를 읽어 주요 시스템 등록 순서와 씬 런타임 연결을 확인했다.
- DI 등록과 저장 섹션 목록을 통해 현재 실제 런타임 기능 및 영속화 범위를 확정했다.
- Resources/SO 에셋을 전수 목록화해 건물·캐릭터·장비·연구·경제·합성·진화·야생동물 콘텐츠 규모를 집계했다.
- 런 흐름과 원정 모델 코드를 읽어 날짜별 phase, 반복 보스, 승패 조건, 난이도, 6단계 적 구성, 전투 핵심 규칙을 재구성했다.
- 운영일 정산, 생산 bill, 연구 queue 코드를 읽어 일일 경제/물류/작업 상태 전이를 정리했다.
- 작업 주문과 AI 결정 pipeline을 읽어 27개 작업 유형, 건설 상태 머신, AI 계층/실패/예약/재경로 구조를 정리했다.
- 생존, 서커스/포획, 외부 활동, 방 환경 모델을 읽어 하위 루프와 상태 전이를 정리했다.
- 진화 파일 경로 일부를 잘못 추정했으나 실제 module registry를 읽어 시설/장비 진화 방향과 이득-부담 구조를 확인했다.
- 실제 진화 모델, 런 변수, 메타 카탈로그를 읽어 숙련/작업/이전/조율/서사 저장 규칙과 콘텐츠 수를 확정했다.
- Unity MCP로 현재 에디터가 idle이며 Console Error/Warning 0임을 확인했다.
- 활성 `GameplayScene` hierarchy를 확인해 실제 씬 조립 상태를 문서 근거에 반영했다.
- 기능, 게임 루프, 콘텐츠 규모, 현재 개발 중인 인스턴스 진화, 장기 후보, 기술 구조와 검증 상태를 단일 Markdown 문서로 작성했다.
- 문서 845줄, 15개 대단원, 코드 블록 짝, 금칙 placeholder와 주요 근거 경로 존재 여부를 검증했다.
