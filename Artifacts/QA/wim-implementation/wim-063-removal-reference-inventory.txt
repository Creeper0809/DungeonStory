## Current production reference seams

1. **Runtime catalog / lookup.**  `GameDomainContentCatalog.asset` contains
   all 21 `BuildingSO` references.  `DungeonStoryGridBuildingController`
   `TryResolveBuildingDataById` reads `IDataCatalog.GetData<BuildingSO>()` by
   the same numeric ID.  Removal without catalog transition makes that lookup
   fail.
2. **Item catalog / installation kits.**  All 21 `facility_kit_<id>.asset`
   definitions remain directly referenced by
   `Assets/Resources/SO/Content/ItemDefinitionCatalog.asset`; each has
   `itemId: facility-kit:<id>` and `buildingDefinitionId: <id>`.  The current
   builder, `GameContentCatalogAssetBuilder.EnsurePhysicalOfferDefinitions`,
   only ensures kits for positive, non-deprecated buildings.  It does not by
   itself prove removal of the already-indexed legacy kits.
3. **Initial placement.**
   `ModularFacilityInitialPlacementMigrator` has an explicit recipe keyed by
   every one of the 21 retired asset names.  `GridBuildingRuntime`
   `PlaceInitialBuildings` always calls `ExpandInitialRooms`; the controller
   calls `NormalizeInitialPlacementForCurrentGrid` before both startup initial
   placement and public `TryPlaceInitialBuildings`.  The minimal structural
   transition is to replace the nine direct scene `InitialBuildInfo.Building`
   references with the corresponding active modular placements, then remove
   the now-unneeded recipes only after no supported initial-placement caller
   supplies any retired BuildingSO.
4. **Persisted facility world.**
   `ModularFacilityWorldSaveData` stores numeric `buildingId`.
   `ModularFacilityWorldSaveService.TryResolveBuildingRestore` calls
   `findBuildingData(entry.buildingId)` and reports an error when no asset is
   found; it does not call the initial-placement migrator.  Per the active
   WIM063 decision, old saves are excluded and are not migrated: current new
   runs must use active numeric IDs.  A removed, unsupported old ID remains an
   explicit restore failure and must never silently substitute a module.
5. **Current supply guard (already PASS).**
   `FacilityBuildingOffer.IsValid`, `CanEnterBasicPurchase`, and
   `IsDailyShopBuildingCandidate` reject `IsDeprecatedCompatibilityAsset`.
   This prevents new deprecated shop exposure while retaining active locked
   buildings; it does not remove any reference above.
