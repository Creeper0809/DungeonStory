# 수술 절차·위험·실패 후속 감사

기준 main `c03d2e0a`. 정적 호출·작성 자산·공개 도감 대조이며 Unity 실행이나 저장 왕복 증거가 아니다. 게임 코드·수치·자산·공개 위키는 변경하지 않았다.

## 모집단과 공개 노출

- `SurgicalProcedureSO` 작성 자산 47개와 `entry/medical/procedure-*` 도감 47개를 안정 ID로 조인했다.
- 필요 작업47값과 공개 효과 개수47값은 모두 일치한다. 상세 행과 원본/도감 SHA는 `surgery-projection-followup-review.json`에 있다.
- 도감 facts는 필요 작업·필요 연구·효과 개수만 제공한다. 작성된 위험·대상·마취·구속·시설·재료·실제 효과는 노출하지 않는다.
- 작성 분포는 마취필수11/47, 비동의 구속필수9/47, 생존자 허용46, 사체 허용1, 야생동물 허용7이다. 작업10~180 WU, 기본 출혈0~0.30, 감염0~0.18, 난도0.03~0.32다.
- typed 효과는 노드치유28, 노화치료5, 골렘부품정비5, 부위제거3, 부품설치2, 설치+부담3, 치유+부담감소1이다.

## 예약과 물리 입력

예약은 환자 종류, 해부계통·종족, 연구, 시술자 자격, 자가수술 금지, 같은 환자의 활성 주문, 시설, 대상 노드와 부품 종류를 검사한다. 절차 기본 재료에 다음 조건부 입력을 합친다.

- 마취필수 또는 비동의 환자: 마취제1
- 구속필수인 비동의 환자가 현재 구속되지 않음: 구속구1
- 멸균 지원: 작성된 깨끗한 물과 소독제
- 이식 지원: 작성된 혈액팩과 면역억제제
- 비전 수술 지원: 작성된 마나결정

## 성공과 합병증

```text
성공률 = clamp(
  0.30 + 의료기여(최대0.45) + 시설성공 + 멸균×0.08
  + 재료있음0.04 + 마취/무마취 기여
  - 절차난도 - 환자불안정×0.30 - 호환성,
  0.05, 0.98)
```

감염·출혈은 작성 기본위험과 실패율, 환자 불안정, 호환성, 시설 멸균·마취와 의사의 합병증 성능을 사용한다. 장기손상은 `실패율×0.30×합병증배율`, 사망은 `실패율×0.10×합병증배율`이다. 실제 수술 창은 Work/Success/Infection/Bleeding을 표시한다.

## 환경과 단계

- 정상: 16~28°C, 공기질70 이상, 조명70 이상
- 극한: 8°C 미만 또는35°C 초과, 공기질40 미만, 조명40 미만
- 비응급은 극한에서 임상 단계 경계에 대기하고 정상 환경이5초 유지돼야 재개한다.
- 응급은 계속하며 마취·절개·시술·봉합 각 단계의 환경 위험을0.25 가중으로 누적한다.
- 주문 WU 비중은 마취15%·절개20%·시술50%·봉합15%다.

## 실패와 회복

- 열린 절개 중 의사 이탈: 대상 노드1피해·출혈0.08
- 일반 실패 강도: 경미60%·중대30%·치명10%
- 경미: 노드3피해·출혈0.08·감염부담 `감염확률×20`
- 중대: 노드10피해·출혈0.25·거부5·감염부담 `감염확률×35`
- 치명: 의료 시술 실패 사망
- 성공: 기본10초×후유증 지속 배율의 회복 관찰

## 도감 내용 오류

24개 절차 요약이 `을(를)` 조사 자리표시자를 그대로 노출한다. 수혈은 “급격한 혈액 손실을 완화”한다고 설명하지만 작성 효과는 `HealSurgicalNodeEffect(health=14, infectionReduction=2)`이며 handler는 대상 노드 체력과 감염만 바꾼다. `bloodLoss`와 `bleedingPerSecond`를 직접 낮추지 않는다.
