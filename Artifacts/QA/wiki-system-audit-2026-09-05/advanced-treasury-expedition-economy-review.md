# 고급 금고·장비 강화·원정 자금 위키 대조

## 판정 범위

- 공개 위키 `0.0.1v`의 전투·장비, 경제·거래, 원정, 침입·방어 가이드와 관련 시설 엔티티를 현재 코드·작성 에셋에 대조했다.
- 정의만 있는 API는 구현된 플레이 기능으로 세지 않았다. UI/게임플레이 호출자, 실제 효과 소비자, 저장 경로까지 연결된 경우만 문서 누락으로 확정했다.
- 이 문서는 정적 감사 결과다. Unity Play Mode를 실행하거나 공개 위키를 수정하지 않았다.

## 1. 장비·시설 오버클럭

장비 UI는 실제 인스턴스에 통제/공격적/임계 단계를 선택할 수 있다. 각각 성능 `+10%/+20%/+35%`, 비용은 현재 장비 가치의 `15%/35%/70%`를 올림한 금화이며, 180 game seconds(현재 UI 표기 24시간) 동안 유지된다. 시작 시 과부하는 `+10/+25/+50`이고, 이미 활성 중이면 연장할 수 없으며 과부하 100에서는 새 활성화가 거부된다.

공격적·임계 단계는 행동마다 각각 `3%/8%` 고장 판정을 한다. 고장 시 과부하가 10 증가하고 해당 행동 효과가 무효가 된다. 방어구·방패 장비 고장은 내구도 0.08 손상을 추가한다. 장비 공격의 실제 전투 계산은 고장 판정 뒤 오버클럭 성능 배율을 읽는다. 활성 상태의 대상·단계·남은 시간·과부하·지불액은 저장된다.

시설 오버클럭 UI와 상태 저장도 존재하지만 현재 작성된 일반 `BuildingOverclockableAbility` 에셋은 금고각인 쇠뇌대 한 곳뿐이고, 확인한 비Editor 성능 소비자는 금고 연동 방어 사격이다. 따라서 모든 생산 시설에 범용 오버클럭 효과가 연결됐다고 문서화하면 안 된다.

공개 전투 가이드는 피해 공식의 오버클럭 배율과 가치 배율이 비용에 쓰인다는 점만 말한다. 단계·지속시간·비용률·과부하·고장·연장 불가·저장·현재 시설 적용 범위가 빠져 있다.

## 2. 유료 정밀 재단조

재단조 UI는 정밀 교정, 부담 억제, 외부 지원 가운데 최대 두 개를 선택한다. 기본 재료와 촉매는 그대로 필요하다.

- 정밀 교정: 결과 분산을 `±12%`에서 `±4%`로 줄인다. 비용은 장비 가치의 20%를 올림한다.
- 부담 억제: 선택한 부담 효과를 억제한다. 현재 완성 노드에서는 빈 부담 또는 `equipment:risky`를 억제하면 위험 부담을 제거한다. 비용은 가치의 30%를 올림한다.
- 외부 지원: 필요 작업량을 25% 줄인다. 비용은 가치의 15%를 올림한다.

장비 가치는 item unit price × 품질 배율 × 파생 소재 가치 배율을 반올림해 최소 1로 계산한다. 선택 비용은 비율 합계에 대해 한 번 올림한다. 먼저 물리 재단조 주문을 만들고 금화를 차감한 뒤 정밀 설정을 주문에 저장한다. 설정 실패 시 주문을 취소하고 금화를 반환한다. 공개 위키에는 이 선택·효과·최대 두 개·비용 산식·실패 복구가 없다.

## 3. 금고각인 쇠뇌대의 금고 연동 방어

작성 에셋 `P1_TreasuryBoltThrower`는 발사당 30골드, 기본 침공 예산 300골드, 최소 위협 0, 보스 전용 꺼짐이다. 시설 패널에서 다음 정책을 실제로 바꿀 수 있다.

- 자동 발사: 켬/끔
- 대상: 모든 침입자/보스 전용
- 최소 위협: 0/25/50/100/200
- 침공당 예산: 0/150/300/600/1200골드
- 보호 자금: 자동/0/500/1000/2500골드

사격 전 자동 발사, 보스 조건, 최소 위협, 침공별 누적 예산, 사격 후 남을 보호 자금을 검사한다. 통과하면 `TreasuryDefenseShot`으로 금화를 차감하고 침공·시설별 누적 지출을 저장한다. 오버클럭 고장이 나면 금화는 이미 지출되지만 사격 효과는 0이고, 성공하면 시설 오버클럭 배율이 적용된다. 정책과 침공별 지출은 저장되며 최근 침공 ID 32개만 보존한다.

시설 엔티티 페이지는 2×1, 특수, 방어 역할과 건설 비용만 노출한다. 침입·방어 가이드에도 발사 비용과 정책이 없다.

## 4. 전략 원정 현장 자금

전략 월드맵 준비 UI는 현장 자금을 100골드 단위로 증감한다. 전략 거점 원정 시작 시 선택액 전부를 중앙 계정에서 `ExpeditionFieldFundAllocation`으로 선차감한다. 출정 준비가 실패하면 같은 금액을 즉시 반환한다.

월드 이동 원정의 현장 선택에서 음수 골드 효과는 중앙 금고가 아니라 원정의 현장 자금에서 빠지고, 양수 효과는 현장 자금에 더해진다. 남은 현장 자금은 원정 저장 상태에 포함된다. 생존자가 있는 정상 귀환에서 한 번만 `ExpeditionFieldFundReturn`으로 중앙 계정에 돌아온다. 생존자가 없으면 현재 귀환 포트가 보급을 포기하고 즉시 반환 경로를 타지 않으므로, 현장 자금의 손실 가능성을 위키에서 명시해야 한다.

공개 원정 가이드는 보급품·현장 결정·귀환 상태를 설명하지만 현장 자금의 선차감, 사용 권위, 실패 환불, 생존자 귀환 반환을 말하지 않는다.

## 5. 적대 소문·공포 방어·원정지 정보 결제

서커스 패널은 적대 소문을 최대 15 줄일 때 명성 최대 10 또는 골드 최대 200을 비례 올림해 소비한다. 공포 15를 예약하면 다음 침입 시작 시 한 번 소비하여 일반 침입의 이동·공격을 10% 낮추고 집결을 10초 늦추며, 보스는 5%와 5초만 적용한다.

월드맵의 숨은 원정지 정보는 명성 10, 골드 200, 정찰 노동 60, 길잡이 부적 1 중 하나로 연다. UI는 같은 결제 버튼을 두 번 눌러 확정하며, 거점 만료를 다시 확인한다. 정보가 열린 뒤에는 전력과 압력 축이 표시된다. 금화 결제는 `Bribe` 거래 종류로 기록된다.

위키는 적대 소문과 정찰·정보를 정성적으로 언급하지만 이 선택지·비용·효과·확정 절차를 설명하지 않는다.

## 구현 불확실성 — 공개 누락과 분리

- `EvolutionCatalystEconomyRuntime`의 촉매 분해·잔여물 3개 정제·잔여물 5개 상위 변환·동일 단계 계열 교환(촉매 가치의 1.5배 금화)은 서비스 구현과 원자적 물리 변환·환불 계약이 있다. 그러나 비Editor 호출자를 찾지 못했다. 위키도 이 변환을 플레이 가능 기능으로 안내하지 않으므로 문서 누락으로 집계하지 않고 **게임플레이 진입점 미확인**으로 보류한다.
- `BribeOffer`는 통행/적대 지연/위험 감소/정보 구매와 수락 확률을 지원하지만 현재 작성 `19_negotiation_gate_captain.asset`에는 bribe 객체가 저장돼 있지 않고 단순 `-125골드`, 노출 `-14` 효과만 있다. Editor builder의 85% 통행 뇌물 설정을 현재 콘텐츠로 간주하지 않는다.
- 위 금화 경로도 물리 금고 접근 없이 세션 계정을 직접 사용한다. 이는 기존 `DIFF-031`과 같은 근본 차이이므로 새 DIFF로 중복 집계하지 않는다.
