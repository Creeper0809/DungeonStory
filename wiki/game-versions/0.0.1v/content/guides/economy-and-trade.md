정착의 경제는 물건을 만드는 일과 바깥에서 가져오는 일을 함께 다룬다. 내부 생산은 재료, 작업자, 시설과 시간을 쓰고, 거래는 화폐, 물건, 운반과 관계를 쓴다. 어느 쪽을 택해도 보관 공간과 귀환 경로가 필요하다.

## 금고와 화폐

화폐와 귀중품은 금고에 보관한다. 금고는 거래 대금, 계약 보상, 세력 의무와 손실을 다루는 보관 공간이다. 금고 접근과 운반이 막히면 거래에 쓸 자산이 있어도 실제 결제가 지연될 수 있다.

## 가격과 교역

아이템의 가격은 외부 거래와 보상의 기준이 된다. 가격만 보고 거래를 고르기보다 필요한 물건이 언제, 어느 경로로 들어오는지와 보관할 장소가 있는지를 함께 본다. 식량과 약품처럼 바로 쓰는 물건은 도착 시점이 중요하고, 무거운 원료는 운반 부담이 크다.

| 거래 전 확인할 것 | 운영에 미치는 영향 |
| --- | --- |
| 줄 물건과 받을 물건 | 현재 생산, 생활, 치료와 방어에 생길 공백을 확인한다. |
| 대금과 금고 접근 | 결제할 화폐와 운반 경로를 준비한다. |
| 납품 기한과 이동 경로 | 예약된 재료, 호송과 기지 인력의 공백을 확인한다. |
| 도착 뒤 보관 | 출력 공간, 냉장·격리·보안 조건을 마련한다. |
| 세력 관계 | 통행, 교역 품목, 지원과 이후 의무가 달라진다. |

## 가격 기준과 실제 정산

내부 가격 감사는 `1 gold = 3 EWU`로 비교한다. 현재 중앙값은 외부 구매 0.45 gold/EWU, 자동 판매 0.20 gold/EWU, 일반 소매 내부 가치 ×1.20, 프리미엄 서비스 순마진 25%다.

| 항목 | 밸런스 범위 |
| --- | ---: |
| 외부 구매가 | EWU 환산 원가보다 25~50% 높음 |
| 외부 판매가 | EWU 환산 원가보다 30~50% 낮음 |
| 일반 영업 순이익률 | 10~20% |
| 고급 서비스 순이익률 | 20~35% |

외부 구매는 금화를 먼저 차감하고 실제 납품된 수량만 물리 아이템으로 만든다. 일부만 도착하면 `ceil(총비용 × 실제수량 ÷ 요청수량)`만 정산하고 나머지를 환불한다. 생성 수량이 0이면 전액을 돌려준다.

자동 판매는 판매 버퍼의 물리 수량을 먼저 소비한 뒤 수입을 지급한다. 판매 지정만으로 금화가 생기지 않는다. 판매 금지 물품, 장착·휴대·원정·정비 중인 장비와 부품이 달린 장비는 정산에서 제외하고 이유를 표시한다.

품질 미달 완제품의 판매가는 다음 식을 쓴다.

```text
판매가 = floor(기본 단가 × 판매율 × 품질 계수)
```

품질 계수는 형편없음 0.70, 저급 0.82, 보통 1.00, 양호 1.08, 우수 1.16, 명품 1.26, 전설 1.40이다. 일반 전투 장비의 판매율은 0.60이며 콘텐츠 허용 범위는 0.50~0.70이다. 한 번의 품질 미달 정산은 최대 4개를 처리한다.

## 계약 보상

계약은 보상만 주지 않는다. 납품, 호송, 통행, 방어와 관계 변화가 뒤따른다. 계약의 조건과 처리는 [세력, 계약과 포로](/guide/factions-contracts-and-prisoners/)에서, 원정으로 얻은 전리품과 귀환 처리는 [원정](/guide/expeditions/)에서 확인한다.

## 내부 생산과 거래의 선택

빠르게 필요한 물건은 거래로 확보할 수 있고, 자주 쓰는 물건은 생산망을 갖추는 편이 안정적이다. 다만 생산망도 연료, 사료, 시설 정비와 운반을 계속 요구한다. [재고·생산·물류](/guide/production/)에서 현재 병목이 대금인지, 원료인지, 작업 시간인지 구분한다.
