의료는 발견, 구조, 치료와 회복을 잇는 일이다. 구조 인력이 접근해 병상으로 옮기고, 의료진과 약품, 적절한 시설과 청결한 환경이 갖춰져야 치료가 이어진다. 부상과 질병은 동시에 있을 수 있으므로 우선순위를 정해야 한다.

## 치료 흐름

:::flow
위험 구역과 환자의 신체 상태를 확인한다.
구조 인력이 안전한 경로로 환자를 병상까지 옮긴다.
출혈, 호흡, 의식과 감염 위험을 먼저 안정화한다.
의료진이 진단과 치료를 진행하고, 필요한 경우 수술을 준비한다.
회복 중인 환자의 식사, 물, 위생, 수면과 재활을 관리한다.
:::

## 진단과 안정화

진단은 신체 부위와 장기, 증상, 출혈·감염·결손, 질병과 현재 기능을 읽는 일이다. 안정화는 생명에 직접 영향을 주는 상태를 먼저 낮추고 치료 시간을 만드는 단계다. [신체 구조](/health/)와 [부상 상태와 처치](/health/injury-states/)에서 부위별 기준을 확인한다.

## 치료와 수술

치료는 약품, 병상, 의료진과 환경을 사용한다. 수술은 더 높은 준비가 필요하며, 환자의 신체 상태와 수술 시설, 의료 도구, 담당자와 회복 공간을 함께 확인한다. 수술 뒤에는 감염 감시, 통증과 피로, 영양과 휴식, 보조 장비와 재활이 남는다.

수술 주문은 환자와 대상 부위, 현재 단계, 예약한 재료·도구, 작업량과 적출물 처리를 저장한다. 환자 이송이 실패하면 반환 대기 상태로 남고 안전한 경로가 생길 때 다시 시도한다. 단계가 끝날 때 치료, 부위 제거, 인공 부위 설치와 부담 변화 가운데 절차가 정한 효과를 적용한다.

적출 부위와 인공 장기는 물리 아이템이다. 부위 상태와 아이템 인계가 모두 확인된 뒤 수술 단계를 완료한다. 저장·불러오기와 재시도로 같은 적출물이 두 번 생기거나 같은 인공 부품이 두 번 설치되지 않는다.

| 상황 | 먼저 준비할 것 |
| --- | --- |
| 전투 부상 | 구조 경로, 출혈 대응, 병상, 약품과 전투선 밖 대피 |
| 질병 환자 | 격리, 진단, 물·음식·환기 관리와 접촉자 확인 |
| 수술 | 의료진, 도구, 청결한 수술 공간과 회복 병상 |
| 장기 회복 | 식사·물·수면, 위생, 재활과 대체 인력 |

## 회복과 수용 기준

| 항목 | 운영 기준 |
| --- | ---: |
| 평시 병상 | 인구 10명당 1개 |
| 유행 대응 격리·회복 자리 | 인구 5명당 1개 |
| 일반 부상의 노동 공백 | 1~3일 |
| 중상의 노동 공백 | 5~20일 |
| 장기 재생 비용 | 같은 역할의 대가급 주민 양성비의 40~70% |

이 표는 정착지 의료 용량과 회복 밸런스의 목표다. 환자별 실제 회복 시간은 부위 체력, 출혈, 감염, 결손, 질병, 치료 효과와 기능 저하가 정한다.

## 의료 공간

병동은 전선이나 작업장과 너무 멀면 구조와 보급이 늦고, 너무 가까우면 소음·오염·위험이 들어온다. 약품 저장, 침상, 격리 공간과 폐기물 처리 경로를 묶어 두되, 생활권과 감염 경로는 구분한다.

[질병, 격리와 공중보건](/guide/disease-and-public-health/)은 전파와 예방을, [주민과 노동](/guide/residents-and-work/)은 구조·치료·수술 업무를, [침입과 방어](/guide/invasions-and-defence/)는 전투 뒤 의료 복구를 설명한다.
