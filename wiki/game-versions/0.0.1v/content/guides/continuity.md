저장은 완료된 건물과 재고, 운반 중인 물건, 건설 현장과 생산 주문에 들어간 재료, 진행 중인 치료와 원정, 사건의 선택과 아직 지급되지 않은 결과를 함께 보관한다. 불러온 세계는 같은 위치와 진행 단계에서 이어진다.

## 저장 범위

| 진행 중인 일 | 이어지는 정보 | 불러온 뒤 확인할 곳 |
| --- | --- | --- |
| 운반·입고 | 예약, 운반자 화물, 남은 배송량과 목적지 | 재료 위치, 통로와 목적지 공간 |
| 건설·생산 | 현장 재료, 작업량, 공정 중 재료와 출력 | 주문 진행, 시설 입력·출력과 작업자 |
| 치료 | 환자, 약품, 수술 단계와 남은 의료 작업 | 병상, 의료 인력과 신체 상태 |
| 원정 | 인원, 장비, 보급, 조우·전리품과 귀환 단계 | 기지 인력 공백, 귀환과 재보급 |
| 사건·계약 | 선택, 비용, 기한, 진행 작업과 전달 결과 | 남은 조건, 관계와 보상 기록 |

완성됐고 목적지 인계를 기다리는 출력도 진행 상태에 포함한다. 이 기록은 재료, 보상과 결과를 한 번만 반영하고 남은 단계가 이어지게 한다.

## 취소와 파괴

작업을 취소하거나 시설이 파괴되면 현장에 도착한 재료, 이동 중인 물건, 회수 가능한 부품과 이미 들어간 작업을 구분한다. 현재 주문, 재공품, 출력과 운반자를 확인한 뒤 취소와 복구를 결정하면 회수·손실·대체 생산을 예상할 수 있다.

시설 성장이나 이전 중에는 사용 기록과 진화 특성도 진행 상태에 남는다. 원정 귀환, 치료와 생산, 사건과 계약도 이미 반영한 결과와 남은 작업을 구분해 이어진다.

## 불러오기 후 점검

:::flow
현재 진행 중인 건설·생산 주문과 운반 상태를 확인한다.
원정대, 환자와 사건의 다음 단계와 기한을 확인한다.
입력·출력, 병상, 귀환 물자와 보상 목적지를 확인한다.
취소·파괴·재배치 계획이 있다면 회수와 손실 상태를 먼저 확인한다.
변경 뒤에는 생산, 주민 생활과 방어의 공백을 다시 배치한다.
:::

저장은 각 시스템의 구역 ID, 자료 형식 버전, 처리 단계와 의존 구역을 함께 기록한다. 불러오기는 다음 순서로 진행한다.

1. 모든 저장 구역과 버전, 필수 의존 관계를 먼저 검사한다.
2. 현재 세계와 분리된 임시 상태에 전체 자료를 복원한다.
3. 재고·주민·시설·작업·원정·사건 사이의 참조와 총량을 맞춘다.
4. 모든 검사가 끝난 임시 상태를 한 번에 현재 세계로 바꾼다.
5. 화면과 조회용 자료를 새 세계에서 다시 만든다.

물건의 기준 무게는 그램으로 저장하며, 개수와 정의가 가진 단위 무게로 총량을 다시 계산한다. 이동·생산·판매처럼 이미 실행된 거래는 거래 번호, 변경 번호와 내용 지문을 남겨 같은 결과가 두 번 반영되지 않게 한다. 목록 순서가 달라져도 같은 저장은 같은 결과로 복원된다.

현재 형식에서 운반 한도를 넘긴 화물이나 목적지 용량을 초과한 물건이 발견되면, 잃어버리거나 복제하지 않고 안전한 소유 상태로 돌려놓은 뒤 새 운반·입고 작업을 만든다. 검사에 실패한 저장은 현재 세계의 일부만 바꾸지 않고 실패한 구역과 이유를 보여 준다.
