시설 성장은 세 경로로 나뉜다. **시설 합성**은 설치된 시설을 재료로 새 시설을 만들고, **계보 교체**는 방과 운영 기록을 충족해 시설 종류를 바꾸며, **개체 진화**는 같은 시설에 사용 이력 기반 특성을 더한다.

## 세 성장 경로

| 경로 | 실제 입력 | 남는 결과 |
| --- | --- | --- |
| 시설 합성 | 월드에 설치된 시설, 조합식, 연구, 결과 자리 | 선택한 시설을 소비하고 상속 등급을 가진 결과 시설을 등록한다. |
| 계보 교체 | 시설 계보, 방 프로필, 운영 기록, 연구와 물질 | 결과 시설과 최대 2개의 허용 변이를 확정한다. |
| 개체 진화 | 숙련도, 세대별 사용 이력, 방 조건, 촉매와 작업 | 시설 정의를 유지하고 이득·부담·활성 조건을 가진 노드를 더한다. |

## 시설 합성

합성은 실제 시설 개체를 선택한다. 모든 재료 시설이 같은 그리드에 있고 결과가 기준 위치에 들어갈 수 있어야 한다. 진행 중인 생산 주문, 재공품과 준비 출력이 남아 있으면 시작할 수 없다.

:::flow
재료 시설과 결과 위치를 고른다.
연구·조합식·배치 조건을 검사한다.
생산 주문, 재공품과 출력을 모두 비운다.
선택한 시설을 합성 재료로 넘긴다.
결과 시설을 등록하고 전력·배관·물류, 입출력 공간과 작업자를 다시 연결한다.
:::

합성은 결과 시설의 배치 공간과 등록 가능 여부를 먼저 확인한다. 모든 배치·연구·생산 상태 검사를 통과한 뒤 재료 시설을 소비하고 결과 시설을 등록한다.

## 계보 교체

시설은 방문, 매출, 소비, 재입고 실패, 범죄, 방어 발동, 침입 피해와 운영일 기록을 쌓는다. 방 프로필은 면적, 문, 좌석·탁자 밀도, 장식, 위생, 연구, 마나, 방어와 물류 조건을 함께 읽는다.

후보마다 연구, 현재 계보, 방 조건, 운영 기록, 물질과 허용 변이를 검사한다. 조건을 넘겨 얻는 추가 변이는 한 번에 최대 2개다. 승인 순간 결과와 변이를 고정하므로 저장·불러오기와 재시도로 다시 뽑히지 않는다.

## 개체 진화

사용 사건은 시설별 원장에 기록되고 세대가 끝나면 요약된다. 주 역할, 방 시너지와 위험 촉매 후보 가운데 하나를 승인하면 재료, 촉매와 작업량이 주문에 고정된다. 작업이 끝날 때 진화 노드가 추가된다.

진화 특성은 방과 운영 조건을 계속 검사한다. 조건이 맞으면 활성, 방 구성이 달라지면 휴면이 된다. 특성 조정은 촉매와 노동을 소비해 새 사용 방식에 맞는 조건으로 바꾼다.

## 해체·포장·재설치

이전 주문은 시설의 계보와 진화 상태를 포장물에 묶고, 월드 시설을 제거한 뒤 물리 운반을 거쳐 새 위치에 설치한다. 운반 중에는 시설이 가동하지 않는다. 재설치 뒤 방 조건이 달라지면 진화 노드의 활성 상태도 다시 계산한다.

시설별 합성식과 진화 후보는 [시설·방 도감](/category/facilities/)에서, 전력·유체와 환경 연결은 [시설과 환경](/guide/infrastructure/)에서 확인한다.
