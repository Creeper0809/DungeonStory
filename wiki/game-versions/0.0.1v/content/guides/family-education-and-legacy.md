공동체는 현재 일할 주민만으로 유지되지 않는다. 가족과 가계, 출생과 성장, 노화와 죽음, 교육과 멘토링은 인력 구성과 문화, 기록과 계승을 바꾼다. 생활 공간과 의료, 식량, 안전이 부족하면 이 과정 전체가 흔들린다.

## 가족과 번식

가족은 관계와 생활 공간, 식사·위생·의료와 안전을 사용한다. 출생과 양육은 주민 수를 늘리지만, 돌봄과 교육에 드는 시간, 침대와 식량, 의료와 보호도 함께 늘린다. 가족 관계는 기분, 사건 반응, 장례와 공동체 기억에 남는다.

생물학적 나이는 게임 하루마다 4일씩 오른다. 성인 판정 나이는 종족마다 다르며, 골렘은 제작을 마치면 바로 성인으로 취급한다.

| 종족 | 성인 판정 나이 |
| --- | ---: |
| 균사 군체 | 180일 |
| 슬라임 | 240일 |
| 코볼트 | 300일 |
| 오크·수인·조류형 | 420일 |
| 데몬·뱀파이어·인간 | 540일 |
| 골렘 | 제작 직후 |

## 노화, 죽음과 장례

노화는 역할 배치와 의료 부담을 바꾸고, 죽음은 숙련된 인력과 관계망의 공백을 남긴다. 장례와 추모는 시신 처리, 문화와 관계, 주민의 기분과 기억을 함께 다루는 일이다. 전투와 질병으로 인원이 줄어든 뒤에는 핵심 업무의 대체 인력부터 다시 확인한다.

가까운 주민이 10일 안에 3명 이상 사망하면 개인의 슬픔을 넘어 공동체 전체가 무너질 수 있다. 장례 공간, 시신 운반, 대체 인력 배치와 멘토링을 같은 복구 계획에 넣는다.

## 아동, 교육과 멘토링

아동은 성인과 같은 노동력을 바로 갖지 않는다. 보호, 생활, 교육과 안전한 활동 공간이 필요하다. 멘토링은 숙련된 주민의 시간을 쓰지만, 핵심 스킬이 한 사람에게만 묶이는 문제를 줄인다.

멘토와 학생은 한 번의 교육에 각각 30 WU를 쓴다. 하루에 전달되는 숙련 경험치는 다음 식으로 정한다.

```text
하루 전달 경험치 = min(10, 2 + 학생의 당일 연습 경험치 × 0.35) × 관계 보정
```

관계가 좋을수록 전달량이 늘고, 나쁠수록 줄어든다. 지속적인 멘토링은 숙련 인력 손실로 생기는 생산 감소를 30~50% 줄이는 운영 수단이다.

| 단계 | 정착이 준비할 것 |
| --- | --- |
| 출생·양육 | 생활 공간, 식사·위생, 의료와 보호 |
| 성장 | 안전한 동선, 교육 공간과 사회 활동 |
| 교육·멘토링 | 가르칠 주민의 시간, 연습할 시설과 장비 |
| 계승 | 경력, 관계, 문화와 기록을 다음 세대로 전달 |

## 인구가 늘어날 때 필요한 운영 규모

인구 단계마다 새로운 병목이 생긴다. 아래 수치는 장기 운영 감사를 위한 기준이다.

| 주민 수 | 먼저 확인할 것 |
| ---: | --- |
| 1명 | 생존 욕구와 단독 작업 동선 |
| 30명 | 역할 분담, 침상·식량·기본 의료 |
| 120명 | 전담 물류, 교육과 교대 근무 |
| 240명 | 구역별 생활 시설과 감염 격리 |
| 400명 | 여러 생산망의 책임자와 대체 인력 |
| 960명 | 구역 단위 자치, 기록과 계승 체계 |

첫 정착 이후 일반 영입과 용병 영입은 각각 최소 10일의 간격을 둔다. 연속 영입으로 식량·침상·의료 수요가 한꺼번에 뛰는 상황을 막는 기준이다.

## 기록과 다음 런

주민의 경력, 관계와 공동체의 선택은 기록으로 남는다. 장기 진행과 다음 런의 변화는 [연구와 성장](/guide/research/)에서, 종족·문화의 생활 조건은 [종족, 문화와 생활](/guide/species-culture-and-life/)에서 확인한다.

## 가족과 계승의 판정 기준

가족의 형성과 다음 세대의 성장은 멘토링, 번식 계획, 임신과 부화, 자녀 성장으로 이어진다. 생애가 끝난 뒤의 장례도 공동체의 계승 과정에 포함된다.

### 멘토링

멘토와 학생은 서로 다른 살아 있는 현재 던전 인물이어야 하고, 가르칠 숙련 및 파손되지 않은 멘토 학원이 필요하다. 멘토는 해당 숙련 전문가 이상이며 학생보다 최소 1등급·200 XP 높아야 한다. 양방향 관계 모두 -0.20 이상이어야 하고 한 멘토는 동시에 학생 3명까지 맡는다.

양방향 관계 중 낮은 값 사용: -0.20 미만 수업 중단, -0.20 이상 0 미만 0.8배, 0 이상 0.5 미만 1배, 0.5 이상 1.1배 학생 XP에는 멘토의 학생 경험치 보정 효과도 곱함 멘토는 30×0.08×0.25=0.6 XP를 받으며 연습 시각 갱신

### 번식 계획

현재 번식 대상은 인간·모험가·오크·악마·야수인·흡혈귀·하피·코볼트·마이코니드·슬라임·골렘의 11종이다. 임신형의 시도/임신/출산/회복 기간은 인간·모험가·오크 1/40/1/20일, 악마 1/50/1/25일, 야수인 1/32/1/15일, 흡혈귀 1/60/1/30일이다. 슬라임은 시도1일·생체량 축적15일·핵 분열5일·안정10일, 골렘은 골격 조립15일·핵 각인10일·인격 각인10일·가동5일이다. 산란형의 시도/알 형성/부화/회복은 하피 1/12/24/12일, 코볼트 1/10/20/10일이다. 마이코니드는 시도1일·포자 혼합5일·균사 확장20일·자실체 형성10일이다.

골렘 조립형과 유전적 교잡은 허용되지 않는다. 친족 제한 판정에 걸린 조합은 번식 계획을 만들 수 없다. 부모의 번식 방식이 다르면 교차 계통 배양 시설이 필요하다.

성공률=기본확률×clamp((건강+영양)/200,0.1,1)×clamp(가임계수,0,1). 임신 단계에서 건강30 미만 또는 영양20 미만이면 하루 유산 확률 0.10/임신안정도(0.5~1.5). 연령·유전 보정도 가임계수에 반영

중지·계획·허용 정책 허용 정책은 이전 평가부터10일마다 성인 후보를 검사하고 계획 가능한 첫 조합 하나를 생성 생식 역할 없음·조립자는 이 자동 평가에서 제외

### 임신과 부화

알·포자·핵분열은 온도 범위 밖에서 단계 일수 진행이 멈추며 연속 3일이면 실패한다. 정상 온도로 돌아오면 연속 위험일수가 0이 된다. 현재 일일 번식 환경 판정에는 실외 온도가 사용된다.

생식 치료제는 번식 계획을 시작할 때 1개 소비한다. 가임 계수는 1.2배(최대 1), 임신 안정도는 1.15배로 보정한다. 골렘 조립에는 이 생식 치료 보정을 적용하지 않는다.

### 자녀

부모 종족 중 결정론적 선택, 부모별 최대3개 유전 후보에서 발현 최대4·잠재 최대2, 적성=부모 적성 정수평균+결정론적 -5~5(0~100 제한)

### 장례

개별 장례는 추모 시설 자격과 고인의 문화 시설 자격을 함께 갖춘 시설에서 장례 준비 키트1개를 예약하고,해당 장례가 필요한 살아 있는 참가자를 대상으로 한다. 공동 추모는 서로 다른 고인3명 이상,가장 이른 사망일과 가장 늦은 사망일의 차이가10일 이하,모든 고인의 문화 자격을 만족하는 추모 시설을 요구한다. 준비 키트는 고인 수만큼 필요하다.
