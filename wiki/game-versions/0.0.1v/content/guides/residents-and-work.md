주민마다 종족과 신체 조건, 특성, 스킬, 생활 리듬과 현재 욕구가 다르다. 정착 운영은 주민 수와 함께 누가 어떤 환경에서 어떤 일을 오래 맡을 수 있는지 파악하고, 그 조건을 유지하는 데 달려 있다.

## 스킬과 담당 업무

주민은 허용된 작업과 현재 정책 안에서 할 일을 찾는다. 한 주민은 여러 업무를 맡고, 우선순위와 상태에 따라 다른 일로 옮겨 간다. 스킬은 작업 속도, 품질과 사고에 반영된다. 경험은 실제로 끝낸 작업에서만 쌓인다.

역할 배치에는 스킬, 부상과 피로, 식사와 수면, 이동 경로, 장비와 시설, 종족과 특성을 함께 반영한다. 경험 많은 주민은 안전한 작업과 멘토링으로 지식을 넘길 수 있으므로, 핵심 스킬은 여러 주민에게 분산해 둔다.

## 스킬 경험과 감소

아홉 스킬은 현재 XP와 평생 XP를 따로 기록한다. 현재 XP는 등급과 작업 성능을 정하며, 평생 XP는 주민이 지금까지 얻은 경험의 누적 기록이다. 감소는 현재 XP에만 적용된다.

| 등급 | 현재 XP 범위 | 작업 속도 기준 | 품질 점수 기준 | 사고 배율 기준 |
| --- | ---: | ---: | ---: | ---: |
| 견습생 | 0~99.999 | 0.85 | 25 | 1.25 |
| 숙련자 | 100~399.999 | 0.95 | 40 | 1.10 |
| 기술자 | 400~1,199.999 | 1.05 | 58 | 1.00 |
| 전문가 | 1,200~2,999.999 | 1.15 | 78 | 0.80 |
| 대가 | 3,000~3,060 | 1.25 | 95 | 0.65 |

표의 성능 수치는 각 등급 시작점의 기준이다. 실제 작업 속도, 품질 점수와 사고 배율은 현재 XP에 맞춰 다음 등급 기준까지 연속으로 변한다.

### 경험을 얻는 수식

```text
작업 경험치
= 승인 작업량(WU)
  × 0.08 XP/WU
  × 난도 배율
  × 결과 배율
  × 학습 배율
  × 반복 작업 배율
```

승인 작업량은 작업 결과에 실제로 반영된 작업량이다. 대기와 취소의 승인 작업량은 0 WU이며 획득 경험치도 0 XP다. 주 스킬과 보조 스킬을 함께 쓰는 업무는 각 스킬의 작업 비중을 먼저 적용한다.

| 조건 | 경험치 배율 |
| --- | ---: |
| 상위 난도 | 1.25 |
| 적정 난도 | 1.00 |
| 한 단계 쉬움 | 0.55 |
| 두 단계 이상 쉬움 | 0.20 |
| 성공 | 1.00 |
| 부분 성공 | 0.60 |
| 안전 실패 | 0.30 |
| 사고·강제 중단 | 0.10 |

학습 배율에는 타고난 적성, 종족, 특성 효과, 주전문과 부전문이 반영되며 최종 범위는 0.70~2.10이다. 반복 작업 배율은 0.15~1.00 범위에서 같은 작업을 계속 되풀이할수록 낮아진다.

### 현재 XP가 감소하는 조건

전문가와 대가는 마지막 연습 뒤 등급별 유예 시간이 끝나면 현재 XP가 감소한다. 일반 작업, 전투와 직접 훈련으로 같은 스킬의 경험치를 합계 1 XP 얻으면 마지막 연습 시각이 갱신된다. 멘토 수업을 마친 멘토는 수업 종료 시각에 연습한 것으로 기록된다.

```text
감소 시작 시각
= 마지막 연습 시각 + 현재 등급의 유예 시간

경과 감소 시간
= max(0, 현재 시각 - max(마지막 정산 시각, 감소 시작 시각))

감소 뒤 현재 XP
= max(강등 경계, 정산 전 현재 XP - 경과 감소 시간 × 시간당 감소량)
```

| 현재 등급 | 유예 시간 | 시간당 감소 | 하루 감소 | 강등되는 현재 XP | 다음 등급 |
| --- | ---: | ---: | ---: | ---: | --- |
| 대가 | 5일, 120시간 | 0.10 XP | 2.40 XP | 2,999.999 XP | 전문가 |
| 전문가 | 15일, 360시간 | 0.25 XP | 6.00 XP | 1,199.999 XP | 기술자 |
| 기술자 이하 | 제한 없음 | 0 | 0 | 감소 없음 | 현재 등급 유지 |

강등된 시각부터 새 등급의 유예 시간을 다시 센다. 대가가 전문가로 내려가면 15일 동안 현재 XP가 유지된 뒤 전문가 감소가 시작된다. 기술자에 도달하면 현재 XP는 기술자 하한에 고정된다.

대가 상한인 3,060 XP에서 마지막 연습을 마치면 5일 동안 XP가 유지된다. 이후 600시간 동안 0.10 XP씩 감소하여 3,000 XP가 되고, 601번째 시간에 2,999.999 XP로 정산되어 전문가로 내려간다. 마지막 연습부터 강등까지 걸리는 시간은 30일 1시간이다.

1,300 XP인 전문가는 15일 유예 뒤 400시간 동안 0.25 XP씩 감소하여 1,200 XP가 되고, 401번째 시간에 1,199.999 XP로 정산되어 기술자로 내려간다. 마지막 연습부터 강등까지 걸리는 시간은 31일 17시간이다.

게임은 스킬을 조회하거나 경험치를 더할 때 지난 시간의 감소량을 한 번에 정산한다. 현재 XP, 평생 XP, 마지막 연습 시각과 마지막 정산 시각을 함께 저장하므로 저장 후 다시 시작해도 같은 결과가 나온다. 주민 상세 화면에서 감소 시작까지 남은 시간과 강등 예상 시간을 확인할 수 있다.

## 업무 배정

플레이어는 작업 허용, 우선순위, 구역, 교대, 위험 정책, 생산 주문과 긴급 직접 명령으로 주민이 판단할 조건을 만든다.

작업은 재료가 예약된 목적지까지 도착하고, 시설과 경로가 열리며, 위험 구역과 보호구 조건이 맞을 때 시작한다. 작업이 멈췄다면 [재료가 있는데도 작업이 멈출 때](/guide/world-state/)에서 재료, 예약, 경로와 출력 공간을 먼저 확인한다.

- 긴급 구조와 치료는 장기 생산이나 연구보다 먼저 처리될 수 있다.
- 재료 부족, 대상 예약, 경로 실패, 위험 구역, 보호구 부족, 출력 포화와 정책 제한은 주민이 일을 멈추는 이유가 된다.
- 모든 잡일을 최우선으로 두면 핵심 작업이 밀린다. 작업을 너무 강하게 잠그면 주민은 식사와 휴식, 위험 대응을 놓칠 수 있다.
- 한 사람에게 중요한 역할을 몰아주면 부상, 휴식과 원정이 정착 전체의 지연으로 이어진다. 핵심 작업마다 대체 인력을 준비한다.

## 특성, 종족과 경력

주민의 능력은 스킬, 일반 특성과 유전 특성, 종족과 문화, 배경, 직책, 야망과 관계로 정해진다. 특성은 작업 방식, 이동, 학습, 안전, 기후 적응, 소비, 사교와 전투에 차이를 만든다. 종족과 문화는 생애, 식단, 환경, 방과 공동 공간의 효용을 바꾼다. 배경, 직책, 야망과 관계는 장기 역할 배치와 사건 선택에 영향을 준다.

현재 확인된 종족은 슬라임, 오크, 뱀파이어, 수인, 데몬, 코볼트, 균사인, 하피, 골렘과 원정자다. 개별 종족, 특성, 직책, 배경과 야망은 [주민·사회 도감](/category/characters/)에서 확인한다.

### 후천 특성

주민은 삶에서 의미 있는 기록을 3개, 8개, 20개 쌓을 때 후천 특성을 얻을 수 있다. 각 이정표의 선택 예산은 3, 5, 7이고 모든 특성 모듈의 비용은 2이므로, 한 번에 각각 최대 1개, 2개, 3개 모듈을 고를 수 있다. 주민 한 명이 활성화할 수 있는 후천 특성은 최대 3개다.

| 후천 특성 | 효과 | 함께 선택할 수 없는 특성 |
| --- | --- | --- |
| 전장의 담력 | 전투 성능 ×1.04 | 생존 본능 |
| 흔들림 없는 손 | 제작 품질 점수 +2 | 없음 |
| 상흔의 기억 | 부정적인 기분 효과의 지속 시간 ×0.96 | 없음 |
| 야간 경계 | 밤 작업 속도 ×1.04, 낮 작업 속도 ×0.99 | 일의 리듬 |
| 일의 리듬 | 작업 속도 ×1.03 | 야간 경계 |
| 관계의 다리 | 관계 회복 ×1.08 | 없음 |
| 생존 본능 | 위험 작업 중 사고 확률 ×0.94 | 전장의 담력 |
| 의례적 공명 | 연구 속도 ×1.04 | 없음 |

지역 보스를 처음 처치하면 그 지역에서 [망각의 인장](/entry/item/memory-erasure-seal/) 1개를 얻는다. 창고의 인장을 사용해 주민과 활성 후천 특성 하나를 선택하고 확인하면 인장 1개가 소비되고 선택한 후천 특성만 소거된다. 선천 특성, 서사 기록과 진행도는 그대로 남으며, 소거한 후천 특성은 되돌릴 수 없다.

## 욕구와 생활 상태

주민의 생활 상태는 아래 여덟 항목으로 관리한다. 항목마다 원인과 대응 조건이 다르므로, 막힌 주민은 해당 줄의 운영 조건부터 확인한다.

| 항목 | 상태가 뜻하는 것 | 먼저 확인할 운영 조건 |
| --- | --- | --- |
| [식사](/needs/meal/) | 먹을 수 있는 식량을 실제로 섭취하는 상태다. 식단 정책, 음식 품질과 문화가 함께 적용된다. | 식량 재고, 식단 정책, 보관 상태, 운반 경로, 식당 서비스와 교대 |
| [물](/needs/water/) | 생활과 위생에 필요한 물을 확보하고 사용하는 상태다. | 수원, 저장처, 급수 경로, 오염과 병원체 |
| [수면](/needs/sleep/) | 교대 사이에 휴식과 회복을 확보하는 상태다. | 침상과 휴식 공간, 교대, 안전한 접근 경로 |
| [위생](/needs/hygiene/) | 세면과 청결을 유지하는 상태다. | 물, 세면·청결 공간, 오염원과 청소 작업 |
| [배변](/needs/excretion/) | 배변 공간의 사용과 오물 처리가 유지되는 상태다. | 배변 공간, 접근 경로, 오물 공간과 처리 작업 |
| [기분](/needs/mood/) | 관계 기억, 슬픔, 트라우마, 특성과 사회 사건이 남기는 정서 상태다. | 관계와 사건 기록, 문화 활동, 휴식과 사회적 지원 |
| [건강](/needs/health/) | 부상, 질병, 면역, 신체 부위와 기관 기능을 포함하는 신체 상태다. | 환자 접근, 구조와 운반, 병상, 의료진, 약품, 격리와 환기 |
| [피로](/needs/fatigue/) | 작업, 전투와 장기 근무 뒤에 누적되는 회복 부담이다. | 교대, 휴식, 작업 강도, 대체 인력과 안전한 역할 배치 |

결핍은 작업 효율을 낮추고 절박 행동, 붕괴, 폭력이나 이탈로 이어질 수 있다. 식량·물·휴식·위생 시설을 짓는 일은 생산 시설과 같은 운영 조건이다. 부상, 질병과 치료는 [건강과 공동체](/guide/health-and-community/)에서 더 자세히 다룬다.

## 기분 관리

[기분](/needs/mood/)은 주민이 현재 얼마나 버틸 수 있는지를 보여 주는 0~100 수치다. 기본 기분은 55이며, 식사·물·수면·여가·배변·위생, 관계와 사건, 특성, 작업 피로가 함께 반영된다. 기분이 25 이하가 되면 주민은 휴무에 들어가고, 휴무를 시작한 뒤 8초가 지났을 때 기분이 45 이상이면 다시 일한다.

| 상태 | 운영 대응 |
| --- | --- |
| 생활 상태가 낮음 | 식사, 물, 수면, 위생과 배변을 함께 확인한다. 해당 욕구가 회복되면 기분을 낮추는 효과도 함께 줄어든다. |
| 장시간 근무 | 계속 일할 때마다 작업 피로 기분 -1이 쌓인다. 이 효과는 최대 8중첩이며, 새 중첩마다 90초가 다시 시작된다. 교대와 대체 인력으로 누적을 끊는다. |
| 관계·사건 충격 | 슬픔, 트라우마, 갈등과 특성 반응을 주민별 기록에서 확인한다. 휴식, 사회적 지원과 문화 활동을 배치해 회복시킨다. |
| 휴무가 계속됨 | 기분과 함께 수면, 배변, 위생 수치를 확인한다. 휴무를 시작한 뒤 8초가 지나면 기분 45, 수면 55, 배변 55, 위생 45 이상에서 업무에 돌아간다. |

### 붕괴 위험

기분이 20 미만으로 이어지면 불안정 누적치가 쌓인다. 누적치가 70에 이르면 5초마다 정신 붕괴를 판정하며, 붕괴 중에는 기분 -8이 180초 동안 남는다. 주민은 시설을 부수거나 다른 주민을 폭행할 수 있고, 폭행은 피해자 체력을 3~10 낮추며 목격자의 기분도 떨어뜨린다. [기분](/needs/mood/) 문서에서 기분 변화 수치와 붕괴 조건을 확인한다.

## 정상 운영 기준

한 주민의 하루에서 식사·물·수면·위생·배변 같은 생존 행동은 18~28%, 실제 작업은 55% 이상을 목표로 한다. 생활 결핍으로 인한 붕괴와 강제 중단은 0건, 재료·경로·시설 조건 때문에 막힌 작업은 전체 작업 시간의 5% 미만을 정상 범위로 본다.

| 항목 | 하루 운영 목표 |
| --- | ---: |
| 식사와 음료 | 1~1.5회 |
| 수면 | 0.7~1.2회 |
| 배변과 위생 | 각각 0.6~1회 |
| 생존 행동 시간 | 전체의 18~28% |
| 실제 작업 시간 | 전체의 55% 이상 |
| 조건 부족으로 막힌 시간 | 전체의 5% 미만 |

이 값은 방과 동선·업무 배치·비축이 제대로 돌아가는지 찾는 점검 기준이다. 생존 행동이 늘면 가까운 생활 시설과 교대 시간을 먼저 확인하고, 작업 시간이 낮으면 [재료가 있는데도 작업이 멈출 때](/guide/world-state/)의 대기 이유를 확인한다.

:::note
이 문서는 주민을 운영하는 기준을 정리한다. 욕구·생활 상태의 수치와 행동 전환 조건은 위 표의 개별 문서에서 확인한다.
:::

## 주민 생활과 작업의 판정 기준

주민 운영은 생활 욕구를 회복하는 일과 노동력을 배치하는 일이 맞물려 돌아간다. 생존 상태, 성장과 숙련, 시설 접근, 직접 명령, 행동 우선도를 함께 보아야 실제 작업 가능 여부를 판단할 수 있다.

### 생존과 회복

느긋함·표준·가혹함 순서로 결핍 부담 증가 배율은 0.75/1/1.25, 회복 배율은 1.15/1/0.85다. 강제 붕괴 유예는 각각 45/30/24게임초다.

수면의 응답 기준은 일상 휴식 60, 긴급 휴식 30, 회복 목표 70이다. 휴식 업무가 켜져 있으면 수면 30 이하에서 휴식 보호에 들어가고, 수면 70 이상이면서 최소 6게임초를 쉬어야 보호가 해제된다. 일반 주민은 수면 30 이하일 때 자동 휴무에 들어갈 수 있다. 복귀에는 최소 8게임초와 수면 70·기분 45·배변 55·위생 45 이상을 모두 요구한다. 사장은 일반 주민의 자동 휴무 대상에서 제외된다. 생활 욕구로 중단한 작업은 해당 욕구의 회복 목표도 충족해야 하며, 수면 회복만으로 다른 작업 제약까지 해제되지는 않는다.

일상 작업 중 기분이 최대치의 18% 이하이면 작업을 중단한다.

t=복용 전 내성/100일 때 과다복용확률은 clamp01(기본확률×(1+t))다. 내성은 작성증가량만큼 더해0~100, 중독 누적치는 기본중독값×100×(0.65+t)를 더해0~100으로 제한한다. 기존중독자 또는 누적60이상이면 중독 상태이며 별도로 기본중독값×0.2 확률도 판정한다. 기분 효과는 기본기분×(1-0.55t)다. 과다복용은 max(4,최대HP×0.12) 피해와 기본기분-12/300초를 적용한다. 중독자는 마지막 복용1게임시간 뒤부터 작성시간당금단을 누적하고 금단20이상에서는 -Lerp(3,14,금단/100)의2초 기분 요인을 갱신한다.

물리 식사 소비를 처리하는 이용은 음식 효과 경로를 사용하고 일반 시설 작성 회복을 별도로 중첩하지 않는다. 그 외 이용의 작성 욕구회복이 하나라도 있으면 작성값을 적용하고 역할별 기본 회복을 더하지 않는다. 작성 회복이 없으면 역할별 기본 회복을 사용한다. 예를 들어 휴식은 수면35·기분12, 훈련은 재미15·기분5이며 작성 회복이 있으면 이 값을 추가하지 않는다.

### 성장과 훈련

숙련 감소로 전문가에서 기술자로 강등되면 1,199.999 XP에서 감소가 멈춘다. 기술자 등급의 시작점은 400 XP이므로 이를 기술자 하한이라고 부르면 안 된다.

훈련허수아비·사격과녁·중량훈련석·대련매트는 정상 이용 완료에 일반경험치24를 지급한다. 기본기분은 각각+4/+3/+5/+4, 지속180초다. 별도 전투훈련 경로는 시설 주숙련이 근접전투 또는 원거리전투일 때 해당 숙련 경험치0.50을 훈련으로 지급한다. 사격과녁은 원거리, 나머지3시설은 근접이다. 일반경험치24와 이 숙련값은 서로 다른 보상이다.

원정 궁극기는 같은 전투에서 한 번 사용하며 명령이 수락된 뒤 사용을 기록한다. 방어 궁극기는 침입마다,운영 궁극기는 운영일마다 살아 있는 인물들을 대상으로 자동 발동을 시도한다. 해당 분야·회차의 미사용 조건을 검사하고 먼저 사용을 기록한 뒤 효과를 적용한다.

업무 시작 때 시작·완료 발동형의 작업 속도 보너스를 함께 계산해 해당 업무 동안 적용하고 업무 종료 때 해제한다. 완료 발동형 청소·수리 보너스는 각각 기본1배에 보너스/100을 더해 최대3배로 제한한다. 생산 산출은1~4배,추가 생산 수량은 음수 없이 반올림한 보너스다. 연구는 진행 시간에 비례한 추가 연구량을 받고 서비스 수익도 해당 성장 스킬 보정을 읽는다. 패시브·고유 스킬은 발동 종류에 맞게 합산하며 사용 기록이 있는 운영 궁극기의 모듈도 합산한다.

최대 성장 레벨은50이며 액티브 후보는 레벨1·5·30에 열린다. 첫 패시브는 레벨1,궁극기는 최대 레벨에서 비어 있을 때 생성된다. 두 번째 패시브는 레벨25 이상,패시브 빈 슬롯,의미 있는 서사 기록8개 이상·서사 분야3개 이상을 함께 요구한다.

액티브는 후보3개,패시브·궁극기는 후보1개를 만든다. 패시브는 해금 레벨25 미만이면 고급,25 이상이면 희귀이며 궁극기는 전설이다. 효과 조합 예산은 일반/고급/희귀/영웅/전설 순서로3/5/8/12/18이다. 허용된 효과 변형만 예산 안에서 조합하며 액티브 후보 모두가 희귀 미만이면 다음 상위 희귀도 보정이 예약된다.

주·보조 적성을 작업 비중으로 합친 뒤 0.70+0.006×가중 적성을 계산한다. 획득 경험 배율과 공통 배율(최소0.1)을 곱한 결과를0.70~1.75로 제한한 뒤 종족 강점1.10·약점0.90을 곱한다. 종족 강점 업무는 자율 후보 점수+10,약점 업무는-10을 받는다.

### 인력과 노동

업무 우선순위 버튼은 1→2→3→꺼짐 순서로 바뀐다. 자율 운반의 점수 배율은 우선순위 1/2/3에 각각 1/0.78/0.48이다. 이미 인수한 배송은 자율 운반을 꺼도 재개 대상이며 운반 가능 조건을 다시 검사한다. 이 경우 점수는 최소 0.98이다.

기본 비상 예비 목표는 max(12 WU, 생산 가능 성인 수×3 WU, 위험별 예측 필요량의 최댓값)이다. 황색 경보는 1.5배, 적색 경보는 2배를 적용한다. 예비 가용률 75% 미만은 붕괴 위험, 75~100%는 취약, 100~125%는 적정, 125% 이상은 잉여다. 회복 시에는 현재 단계별 85/110/135%를 충족해 2시간 유지해야 한 단계 개선된다.

적색 동원의 목표 인원은 max(1,ceil(현재 예비 필요 WU/인당 최대 예비 대응 WU))이며 이미 배정된 인원을 뺀 만큼 추가로 선발한다. 중단 불가 핵심 업무, 보호된 회복 업무, 이미 비상 대응 중인 업무는 일반 강제 전환 후보에서 제외한다.

시공 규모별 최대 인원은 소형 2, 중형 3, 산업 4, 대형 사업 6, 랜드마크 8명이다. 연구 규모별 기본 인원은 일반 1, 협력 2, 대규모 4명이다. 일반 프로젝트의 순번별 기여 배율은 1/0.85/0.75/0.65/0.55/0.45/0.40/0.35, 연구는 1/0.70/0.45/0.25다.

전환 가능한 산출 WU=max(0,실제 노동+공정 환산 산출-손실)이고 산출 등가 WU는 여기에 자동화 WU를 더한다. 실현 성장 WU=max(0,전환 가능 산출-필수 유지-장비·시설 유지), 보장 성장 WU=max(0,실현 성장-비상 예비 목표)다. 일별 인당 순노동 지수는 실현 성장 WU를 생산 가능 성인 수와 기준 인당 유효 WU로 나눈다. 완료된 최근 30일 이내의 기록으로 중앙값을 구하며, 짝수 개면 가운데 두 값의 평균을 쓴다.

은퇴 주민의 기본 허용 업무는 청소·연구·접객·제작·조리·공연·파종·수확·동물 돌봄9종이며 하루 안전 작업은 게임시간4시간까지다. 운영 업무라도 해당 멘토 학원에 실제 멘토 또는 학생으로 배정된 은퇴자는 예외로 허용된다.

기본 규칙은 기분50 이하의 연속 일수를 센다. 기분8 이하가 반란,15 이하 또는 기분25 이하가4일 지속되면 이탈 단계다. 그보다 심한 단계가 아니면 기분25 이하 또는 낮은 기분3일은 업무 차질,기분35 이하 또는 낮은 기분2일은 효율 저하,기분50 이하는 낮은 만족 단계다. 낮은 만족/효율 저하/업무 차질의 속도 배율은0.95/0.8/0.6이다. 업무 차질·이탈·반란 단계는 새 업무 시작을 막는다. 상담 가능한 불만 직원에게 기분+25×협상 배율을240초 적용하고 낮은 기분 연속 일수를0으로 되돌린 뒤 단계를 다시 판정한다.

### 환경과 시설 상태

냉기 노출15 이상이면 냉기 휴식 잠금이 켜지고10 미만이 되어야 풀린다.10 이상15 미만에서는 기존 잠금 상태를 유지한다. 일반 작업에서 보호가 필요하고 종료 시 냉기 노출이25 이상으로 예측되면 방한 보호복 자동 착용을 시도한 뒤 위험을 다시 예측한다. 강제 작업과 안전 예외 작업은 이 자동 착용 조건에서 제외된다. 진행 작업은1초 간격으로 환경을 다시 확인한다. 생리·시각 단계 중 높은 쪽이 기능 저하 이상이면 재배정, 위급 이상이거나 치명 환경이 예측되면 대피를 시도한다. 진행 중인 긴급수술·방어·안전 업무는 위1초 환경 중단 검사에서 제외된다.

급유할 때는 해당 시설에 정해진 연료를 정해진 수량만큼(최소1개) 시설의 납품 지점에서 소비한다. 실제 소비가 확인되면 그 시설에 정해진 연료 지속시간을 부여한다. 이미 연료가 공급 중인 시설은 급유를 요청해도 연료를 추가 소비하지 않는다.

변기·화장실 칸막이·세면대·목욕통·수건걸이·청소도구함·바닥 배수구의 청소 완료는 대상 시설과 같은 운영 방 구성품의 청결을 100으로 설정한다.

시설이 지원하지 않는 업무는 배정할 수 없으며 청결75 이상이면 청소 업무를 불필요로 거부한다. 손상 시 정지하도록 정해진 시설이 손상되면 수리를 제외한 업무 배정을 거부한다.

일반 시설의 작업 발판은 점유칸의 좌우 인접칸에서 찾으며 이동용 시설은 점유칸 자체를 사용할 수 있다. 작업자는 걷기 가능하고 도달 가능하며 시설 작업 접근이 허용된 발판이 필요하다. 방문객 서비스 출입 허용과는 별도로 작업 접근을 판단한다.

### 작업 성능과 숙련

적용 가능한 필수 신체 기능이 요구 임계치에 못 미치면 작업 성능을 사용할 수 없다. 종족·해부상 미적용인 기능은 필수 검사 전에 제외하며 실패는 적용 대상 필수 기능의 부족으로 판정한다. 기능 가중평균을 병목 기능별0.25+0.75×기능값의 최솟값으로 제한한다. 역방향 채널은1/max(0.05,기능값)을 사용한다. 최종 성능은 기본값×기능 계수×숙련 계수×효과 계수×맥락 계수다. 따라서 숙련만 높여도 신체 기능 제한을 무시하지 못한다.

업무의 속도와 사고 위험은 서로 다른 성능 공식을 선택하며 속도 평가값은 실제 초당 작업량에,위험 평가값은 사고 판정에 사용한다. 제작 속도의 기능 기여는 정신 유지 20%·시각 식별 20%·정밀 조작 40%·동력 순환 10%·생명 반응 10%다. 정신 유지는 필수, 정밀 조작은 필수·병목이고 두 기능의 필수 임계치는 0.1이다. 일반 제작은 제작 숙련을 사용한다. 룬 제작에만 제작 80%와 학술 20%를 적용한다.

승인 작업량이 양수이면 사고 확률은 1-exp(-0.001×승인 작업량×사고 성능×피로 배율×시설 손상 배율)이다. 같은 작업 행동에서 사고가 난 뒤에는 다시 판정하지 않는다. 피로 배율은1+수면 회복 목표 대비 부족 비율이고,시설 배율은1+(1-시설 내구도 비율)이다. 해당 상태가 없으면 그 배율은1이다. 사고가 나면 남아 있고 체력이 양수인 부위 중 하나를 균등 선택해 피해2·추가 출혈0을 적용하고 작업을 중단한다.

시설 운영과 건설·수리·배관·해체·대공사는 시설에 작성된 해당 숙련 조합을 우선 사용한다. 경비는 현재 원거리 무기를 쓰면 원거리 전투 숙련을, 아니면 근접 전투 숙련을 사용한다. 사냥은 식량 생산 80%와 같은 무기 기준 전투 숙련 20%를 사용한다. 포로 감시는 사교 80%와 근접·원거리 중 현재 경험치가 높은 전투 숙련 20%를 사용하며, 동률이면 근접을 고른다. 룬 제작은 제작 80%와 학술 20%를 사용한다. 휴식에는 학습 숙련 배율을 적용하지 않는다.

### 직접 명령과 재배정

강제 우선 작업에서 환경 위험 경고가 나오면 같은 시설·같은 업무를 다시 명령해야 확인으로 인정한다. 대상 평가 실패 때는 배정하지 않는다. 수락된 우선 작업은 즉시 근무 상태로 복귀시키고 대상을 배정한 뒤 AI 재계획을 요청한다.

자동 업무 선택은 직접 지정한 목표를 우선 평가하고,재사용 대기·일시 시작 불가·목적지 점유·경로 부재·평가 지연 때 명령을 유지한다. 비번 중에도 실제로 이용 가능한 긴급 업무의 긴급도60 이상을 찾으면 근무로 복귀한다. 후보 탐색이 아직 지연 중인 상태만으로 긴급 업무를 찾았다고 처리하지 않는다.

단일 작업자 재배정에서는 가능한 후보 중 쉬고 있는 인물을 먼저 고려하고, 같은 상태에서는 업무 적합 점수로 한 명을 선택한다. 선택한 작업자는 요청 업무를 600초 동안 선호하고 즉시 다시 판단한다. 강제 중단을 허용하지 않은 요청은 이미 행동 중인 작업자를 보호한다.

### 행동 우선도

생존의 가장 강한 필요도 n(0~1)에 대한 기본 점수는 n≤0.05면 0, 0.05<n<0.25면 25n, 0.25≤n<0.65면 35+30n, n≥0.65면 95+5n이다. 직원이 아니거나 휴무 중이면 당직 기본 점수는 0이다. 근무 중에는 생존 압력이 0.25 이하일 때 82이며, 압력이 1로 커질수록 선형으로 8까지 낮아진다. 여가 후보는 직원이면 휴무 중이거나 재미 필요도가 양수일 때, 비직원이면 쇼핑 능력이 있을 때 열릴 수 있다. 기본 점수는 70×clamp01(max(재미 필요도, 기분 필요도×0.75, 쇼핑 필요도)×clamp01(1−긴급 생존 필요도×0.85))이다. 이 수치는 기분과 상황 보정 전 기본 우선 점수다. 실제 행동 선택에서는 다른 후보와 보정을 함께 비교한다.

기분 72 이상에서 양수인 기본 우선도는 근무 중 업무에 +2~10, 휴무 중 여가에 +1~6을 기분이 100에 가까워질수록 더한다. 기분 38 미만이면 기분이 0에 가까워질수록 업무 루틴 점수에 1→0.55배를 적용하고, 여가 점수 하한은 18→44, 대기 점수 하한은 22→52로 올린다. 같은 저기분 구간에서 개별 업무 후보 점수는1→0.2배로 줄고, 기다리기·둘러보기 후보 점수 하한은0.48→0.9로 높아진다. 최종 실행 행동은 모든 후보 점수를 비교한 뒤 결정한다.
