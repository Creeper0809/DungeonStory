원정은 기지 밖 목표를 조사하고, 물자를 얻고, 세력과 접촉하는 활동이다. 원정대에 들어간 주민과 장비, 식량, 탄약과 의료품은 기지의 사용 가능 자원에서 빠진다. 출발은 원정대와 기지에 남는 인력, 방어선을 함께 바꾸는 결정이다.

## 출발 준비

원정대는 최대 다섯 명으로 편성한다. 목표와 이동 조건, 날씨, 돌아올 경로를 확인한 뒤 역할을 나눈다. 전투 인원만 보내면 부상·운반·야전 의료가 약해지고, 지원 인원만 보내면 조우에서 버티기 어렵다.

실제 출발은 `야전 식량학` 연구 완료 뒤 열린다. 지도 열람, 정찰, 목표 비교와 훈련은 첫날부터 할 수 있다. 던전 주인과 하수인은 원정대에 넣을 수 없다.

| 준비 항목 | 확인할 내용 |
| --- | --- |
| 목표와 경로 | 지역 조건, 접근 규칙, 이동 시간과 귀환 길 |
| 인원 | 전투, 의료, 운반, 사회·탐사 역할과 기지의 대체 인력 |
| 보급 | 식량, 물, 탄약, 약품, 수리 부품과 적재량 |
| 장비 | 역할별 무기·방어구, 탄약과 야전에서 쓸 소모품 |
| 기지 공백 | 침입 경고, 생산 주문, 병상과 필수 업무에 남는 인원 |

## 이동과 조우

이동 중에는 기후, 지형, 피로와 보급을 계속 관리한다. 조우는 전투만 뜻하지 않는다. 교섭, 수색, 구조, 우회와 후퇴도 원정의 선택이다. 선택에 필요한 물자와 인력은 실제로 원정대가 지닌 재고와 신체 상태에서 나온다.

오르데나를 향한 장기 원정은 하나의 적 국가 안에 있는 다섯 지역을 차례로 압박한다. 각 지역에는 서로 다른 전쟁 조직과 지원 거점이 있으며, 거점을 끊은 뒤 핵심 전력을 무너뜨려야 해당 전선이 붕괴한다. 다섯 지역의 위치와 목표는 [세계와 정착](/guide/world/)에서 확인한다.

| 저장되는 원정 상태 | 이어지는 내용 |
| --- | --- |
| 참가자·장비·보급 | 원정대가 책임지는 인물과 물리 물품 |
| 위치·이동 진행 | 현재 지역, 다음 경로와 남은 이동 |
| 현장 결정 | 열린 카드, 선택한 행동과 해결 결과 |
| 전략 전투 | 적 행동 의도, 명령 대기열과 해결된 명령 |
| 야전 의료 | 부상 안정화, 소모품과 귀환 우선순위 |
| 귀환 안전 | 남은 안전 이동 예산과 도착 단계 |

## 야전 의료와 전리품

부상자는 안전한 위치에서 구조하고, 출혈과 질병 위험을 먼저 다룬다. 야전에서 해결할 수 없는 상태는 귀환과 기지 병상 준비를 앞당긴다. 전리품과 포로는 무게, 운반 인원, 보관·격리 공간을 사용하므로 얻는 순간부터 귀환 부담이 된다.

출발 보급품은 기지에 있던 물건 묶음의 고유 번호, 수량과 개별 상태를 원정으로 넘긴다. 원정이 책임지는 동안에는 원정대만 그 물건을 쓴다. 소비한 물품과 돌아오는 장비·용기는 각각 인계 기록으로 처리한다.

원정 중 얻은 전리품 일부는 범주별 수량으로 기록하고 귀환할 때 물리 아이템으로 바뀐다. 이 전리품의 정확한 무게와 적재 한도는 귀환 물품을 확정할 때 계산한다. 출발 보급품과 물리 아이템으로 확보된 전리품은 품목별 기준 무게를 사용한다.

## 귀환과 결산

귀환한 뒤에는 전리품을 분류해 창고로 옮기고, 부상자와 장비를 처리하며, 포로와 세력 관계를 정리한다. 기지에 남겨 둔 주문이 밀렸을 수 있으므로 재고, 생산, 경비와 생활 상태를 함께 점검한다.

결산에는 교전 시간, 탄약·약품·식량 소비, 장비 내구도 손실, 치료 작업과 회복일, 사망·포획·탈출, 목표 성공 여부, 전리품 가치와 고유 보상을 함께 기록한다. 원정 준비 화면의 전투력 공식과 장비 상한은 [전투와 장비](/guide/combat-and-equipment/#section-%EC%A0%84%ED%88%AC%EB%A0%A5%EA%B3%BC-%EC%8B%A4%EC%A0%9C-%ED%94%BC%ED%95%B4%EB%9F%89)에서 확인한다.

[전투와 장비](/guide/combat-and-equipment/)는 전투 역할을, [의료와 수술](/guide/medical-care-and-surgery/)은 치료와 귀환 뒤 회복을, [세력, 계약과 포로](/guide/factions-contracts-and-prisoners/)는 대외 결과를 설명한다.

## 원정 운영의 판정 기준

원정에서는 목적지에 도달하는 과정과 현장 자금, 귀환 뒤 회복과 정보 정리가 하나의 흐름을 이룬다. 준비 단계에서 이 비용과 보상을 함께 확인하는 편이 좋다.

### 이동

구간 시간은2.5초×타일 경로비용×max(1,의료 이동배율)×이정표 배율(0.1~1)×시설 배율이다. 경로비용에는 저장된 경로 날씨배율과 현재 기상전선의 원정 이동배율을 곱한 값이 들어간다. 이동 구간 시작 때 비용·날씨·지속시간을 고정한다. 한 tick에 구간을 마치고 계속 이동 가능한 경우 남은 시간을 다음 구간에 쓰며 전투·결정 대기 등 계속할 수 없는 경계에서는 중지한다.

### 현장 자금

전략 원정에 배정하는 현장자금은 출발 때 중앙잔액에서 먼저 차감한다. 세계지도 원정의 현장 선택 비용은 현장자금에서 내며 부족하면 지출하지 못하고 양수 금화 효과는 현장자금에 더한다. 구형 원정 선택은 같은 금화 효과에도 중앙잔액을 사용하므로 두 경로의 자금 권위를 구분한다.

### 회복과 정보

체력회복 기본입력(최대체력비율)/부상감소/스트레스감소는 목욕통0.08/0.12/26, 간이침대0.12/0.03/12, 정식침대0.22/0.08/22, 이층침대0.18/0.05/18이다. 정상 시설 이용 완료의 회복은 원정 귀환자에게만 제한되지 않는다. 체력회복은 추가 상처회복 성능 배율을 거치며 사망자는 회복하지 않으므로 표의 비율이 최종 회복량을 보장하지 않는다.

원정 정보가 아직 해금되지 않은 원정지에서 길잡이 부적을 결제 수단으로 고르면 실제 부적 1개를 소비해 정보를 해금한다. 이미 해금된 정보에는 부적을 다시 소비하지 않는다.
