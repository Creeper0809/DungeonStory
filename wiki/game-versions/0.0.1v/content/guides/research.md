연구는 새 시설, 제작식, 장비, 서비스와 대응 방법을 연다. 연구실, 연구 인력, 공간, 재료와 운영 시간은 해금한 수단을 실제 운영 능력으로 바꾼다. 연구 선택은 현재 정착의 부족과 위험을 어떤 방식으로 풀지 정하는 일이다.

## 연구 선택

:::flow
현재 부족과 다가오는 위험을 하나 고른다.
그 문제를 바꿀 연구의 선행 조건과 해금 목록을 확인한다.
연구 시설, 인력, 작업 시간과 청사진 보관 조건을 준비한다.
완료 뒤 건설할 시설, 필요한 재료와 보급 경로를 정한다.
새 수단이 쓰는 공간, 기반 시설, 인력과 유지 부담을 다음 계획에 반영한다.
:::

## 연구 완료 후 준비

| 확인할 항목 | 연구를 시작하기 전에 볼 것 | 완료 뒤 이어지는 일 |
| --- | --- | --- |
| 선행 관계 | 먼저 필요한 지식, 제작 기술과 안전 기준 | 다음 연구 후보와 준비 경로 |
| 시설 해금 | 건설 공간, 기반 시설과 작업자 | 배치, 건설, 입력·출력과 정비 |
| 제작식·장비 해금 | 원료, 실행 시설과 보급 대상 | 생산 주문, 저장과 실제 사용처 |
| 서비스·대응 해금 | 필요한 인력, 환경과 대상 | 의료·위생·방어 등 서비스 운영 |

전력 연구는 발전 설비, 배전, 연료와 정비를 통해 생산과 자동화를 넓힌다. 의료 연구로 병상, 약품, 적합한 인력과 환경을 갖추면 새로운 치료 방법을 쓸 수 있다. 연구 목록의 해금 항목을 열어 실제 건설과 생산 조건까지 확인한다.

## 연구 작업량과 도달 시기

기준 연구원 1명의 하루 유효 연구량은 45 WU다. 실제 수행량 기록은 50 WU를 사용한다.

| 기술권 | 중앙 목표 | 허용 범위 |
| --- | ---: | ---: |
| 중세 기반 | 30일 | 25~40일 |
| 초기 산업 | 90일 | 70~120일 |
| 성숙 산업 | 220일 | 180~280일 |
| 후기 룬 산업 | 360일 | 300~480일 |
| 시간 고정 선행 | 964일 | 850~1,100일 |

연구 보상의 투자 효과는 초반 5~20일, 중반 20~60일, 후반 60~180일 안에 체감하는 것을 기준으로 한다. 날짜는 연구를 직접 잠그지 않는다. 실제 선행 연구, 시설 수용력과 작업 기여량이 완료 시점을 정한다.

## 연구 경로

| 운영 문제 | 비교할 연구·운영 방향 | 함께 드는 조건 |
| --- | --- | --- |
| 식량과 생물 원료 | 외부 농업, 실내 재배, 온실, 축산과 교역 | 면적·계절, 환경·전력, 사료와 세력 관계 |
| 물·위생과 오염 | 분산 위생, 중앙 급배수, 재이용과 정화 | 처리량, 관로·전력, 필터·소독과 고장 범위 |
| 동력과 물류 | 수공업, 중앙 동력망, 분산 설비와 자동 물류 | 연료·입지, 배전·정비, 필터·완충과 우회 경로 |
| 방어와 의료 | 방어 시설·장비, 예방·격리, 응급·수술 | 통로·보급, 청결·병상, 전문 인력과 위험 관리 |

각 방향은 연구원과 작업 시간, 전략 중간재와 시설, 방 면적과 기반 시설, 전문 인력, 비축과 세력 관계를 사용한다. 먼저 투자한 경로는 정착의 공간과 인력 배치를 바꾸며, 이후 전환과 혼합에도 준비 시간이 든다.

## 연구 항목 정보

1. 선행 연구에서 필요한 지식과 준비를 확인한다.
2. 해금 목록에서 시설, 제작식, 아이템과 규칙을 유형별로 본다.
3. 원하는 해금 항목으로 이동해 건설, 생산과 사용 조건을 확인한다.
4. 현재 병목을 바꾸는 후보와 앞으로 필요한 기반 시설을 비교한다.

[연구 도감](/category/research/)은 선행 관계와 해금을, [연구 업무](/work/scholarship/research/)는 연구를 진행하는 주민 업무를, [시설·방 도감](/category/facilities/)과 [재고·생산·물류](/guide/production/)는 해금 뒤 준비할 운영 조건을 보여 준다.

## 해금 후 준비

연구 완료 뒤에는 새 시설을 건설하고, 원료와 장비를 준비하고, 주민을 배치하고, 생활·생산·방어 구역에 보급한다. 새 설비는 처리량과 대응 수단을 넓히며 전력, 유체, 정비, 공간과 전문 인력의 부담을 함께 만든다. 연구 결과가 현재 정착의 병목을 바꾸는지는 이 운영 과정에서 확인한다.

## 이정표와 계승

이정표 조건, 장기 도달 목표, 런 종료와 다음 런의 프로필 해금은 [이정표, 런과 계승](/guide/milestones-runs-and-meta/)이 기준 문서다. 가족과 다음 세대의 생활 조건은 [가족, 교육과 계승](/guide/family-education-and-legacy/)에서 확인한다.

해금한 수단은 재료, 공간, 기반 설비와 담당 인력이 갖춰질 때 운영으로 이어진다. [시설과 환경](/guide/infrastructure/)은 시설을 키우고 바꾸는 조건을 설명한다.

## 연구와 계승의 판정 기준

연구 해금에는 선행 지식과 함께 청사진, 재료, 시설, 작업량이 필요하다. 연구와 런에서 얻은 성과는 종료 정산과 계승 강화를 거쳐 다음 진행으로 이어진다.

### 연구 조건과 청사진

연구 시설에 비전 색인철 1개가 준비되면 승인 연구 WU에 1.1배 효과를 적용하며 승인 WU당 내구도 0.01을 소비한다. 도구 공급이 준비되지 않으면 기본 연구 WU로 진행한다.

연구 시설 기능은 사용 가능한 연구 역할 방에 있고 활성·비파손 상태인 시설들에서 기능별로 정착지 전체 합산한다. 자체 완결 방은 제외하며 전력을 쓰는 시설은 가동 전력이 필요하다. 각 기능 기여는 작성 수용량의 최소 1을 더하며 연구가 요구하는 기능별 수용량과 비교한다.

필수 청사진 연구는 선행 연구 완료와 실물 청사진의 보관을 모두 요구한다. 선행 우회 청사진은 보관 중이면 선행 연구를 건너뛰지만 시설 기능 요구는 면제하지 않는다. 청사진 구매는 실물 배송이므로 구매 자체가 즉시 연구 완료를 뜻하지 않는다.

연구를 대기열에서 제거해도 이미 쌓인 연구 진척은 보존된다. 제거 후에는 남아 있는 대기열에서 다음으로 실행 가능한 연구를 다시 선택한다.

비전 기초 청사진(6104)은 구매 시 실물 청사진이 하차장에 배송된다. 이후 관련 연구의 선행·보관·시설 조건을 충족해 연구를 진행해야 해금된다.

### 위험한 연구와 재료

기억 잔재 처리의 필요 작업량은 24 WU다. 지역 정찰 결과는 해당 지역의 정보망 약화 값을 10만큼 높인다. 정보망 약화가 이미 99.999 이상인 지역은 새 정찰 작업을 받지 않는다. 같은 지역의 대기 정찰이 이미 있어도 중복 예약을 거부한다.

금단의 도약은 인물별로 같은 연구 프로젝트에서 한 번만 시도할 수 있다. 판정 확률은 돌파 10%, 퇴보 20%, 변화 없음 70%다. 시도 뒤 1일의 후유증이 남고 해당 연구 효과 배율은 0.7이다.

### 연구 작업량

연구 승인 WU를 A, 연구 보너스 모듈 합을 S라 하면 모듈 적용 후 작업량은 A×(1+S/4)다. 이는 하루 기준 연구량과 별도의 작업 기여 보정이다.

### 대형 프로젝트

대형 사업 완료에 따라 채석장 생산량은1.25배,실내 농장 재배 산출은1.2배,연금술·약제·증류 시설 산출은1.15배가 된다. 지역 교역소 사업이 완료되면 계약 보상에1.25배를 적용한다.

대협약 보상을 얻은 뒤 양수 날짜가 계절 길이의 배수인 날에 동맹 신호 지원을 사용할 수 있다. 가동 중인 보안 시설 중 동맹 신호 자격을 가진 시설의 전용 보급칸에 신호 키트 정확히1개가 준비되면 지원 활성화를 요청한다. 활성화된 당일 경비의 공격력에1.15배를 적용한다.

### 계승 강화

계승 강화는 재화가 충분하고 최대 레벨 미만일 때 가격을 지불하고 1레벨 오른다. 시작 시설 후보 +1: 가격80/최대2레벨; 사장 생성 특성 목표수·상한 +1:90/1; 첫날 기본 구매 목록 +1:100/3; 특수 조합식 기록 보존 슬롯 +1:120/3. 사장 최대체력 레벨당 +8%:110/3; 침입 경고 문턱 레벨당 -8%:90/2; 상단 보급 비용 레벨당 -4%:100/3; 방어 시설 구매가 레벨당 -5%:110/3; 연구 작업량 레벨당 +8%:110/3. 사장 특성 강화는 직원에게 적용되지 않으며, 후보 충돌·부족 때문에 실제 특성이 항상 정확히 1개 더 생긴다고 보장할 수 없다. 특수 조합식 기록 강화는 다음 런에 보존할 수 있는 슬롯을 늘린다.

### 런 종료 정산

런 종료 계승 재화는 다음 합에 난이도 배율(최소0.1)을 곱하고 정수 반올림한 뒤 최소0으로 제한한다: 생존초÷60×8 + 생존 운영일×35 + 결산 횟수×10 + 방어 성공×30 + 최대 위협단계 점수×12 + 최종 침입위협×0.25 + min(60,첫 시설발견 수×4) + min(60,첫 조합식해금 수×10) + 원정성공 수×25. 위협단계 점수는 Warning=1, Candidate/Safety=2, 그 외0이다. 각 횟수 항목은 음수를0으로 제한한다.
