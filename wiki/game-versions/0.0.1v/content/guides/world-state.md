창고에 재료가 있고 시설도 완공됐는데 작업이 멈추는 일이 있다. 이때는 목록의 총량보다 재료가 어디에 있고, 누가 어떤 일을 맡고 있으며, 시설이 무엇을 기다리는지부터 확인한다.

## 작업 중단 점검

:::flow
작업이 기다리는 재료와 대상이 어디에 있는지 확인한다.
해당 주민이 구조, 치료나 운반처럼 더 긴급한 일을 처리하는지 확인한다.
입력과 출력 공간, 길과 문, 위험 구역을 확인한다.
전력, 유체, 청결과 같은 시설 조건을 확인한다.
원인을 고친 뒤 주민과 시설이 다시 일을 찾는지 확인한다.
:::

## 재료와 인력

창고에 있는 물건이 다른 생산 주문에 예약됐거나, 운반자가 들고 있거나, 건설 현장과 의료 작업에 들어갔을 수 있다. 시설은 입력과 출력 공간, 연결된 전력·유체 설비, 작업자의 접근, 방의 상태가 갖춰질 때 가동한다.

| 보이는 문제 | 먼저 확인할 조건 | 고친 뒤 볼 곳 |
| --- | --- | --- |
| 재료가 있는데 건설·생산이 멈춤 | 재료의 예약, 운반자와 현장 위치 | 현장까지의 통로와 목적지 공간 |
| 주민이 다른 일을 함 | 구조, 치료, 운반 같은 긴급 업무와 작업 우선순위 | 핵심 업무의 대체 인력 |
| 시설 가동이 멈춤 | 입력과 출력 공간, 길과 문 | 전력, 유체, 청결과 방 상태 |
| 구역 전체가 느려짐 | 혼잡한 통로, 출입 정책과 위험 구역 | 저장 위치, 배치와 작업 순서 |

## 화면에 표시해야 할 대기 이유

주민과 시설은 멈춰 있는 이유를 다음 상태 가운데 하나로 표시한다.

| 표시 | 뜻 | 조치 |
| --- | --- | --- |
| 재료 없음 | 조건에 맞는 실제 물건이 없음 | 생산·구매·회수 경로를 만든다. |
| 다른 작업이 예약함 | 물건은 있지만 다른 주문이 점유함 | 주문 우선순위와 예약 대상을 확인한다. |
| 운반 대기 | 출발 물건과 목적지는 정해졌고 운반자가 없음 | 운반 인력·통로·적재량을 확인한다. |
| 목적지 공간 부족 | 시설 입력·출력이나 창고가 받을 수 없음 | 버퍼를 비우거나 허용 품목·무게를 조정한다. |
| 길 다시 찾는 중 | 지도나 출입 정책이 바뀌어 경로를 새로 계산함 | 문·계단·위험 구역을 확인한다. |
| 접근 금지·위험 | 신분·구역 정책 또는 위험 허용 기준에 걸림 | 담당자와 출입 정책을 바꾼다. |
| 시설 조건 부족 | 전력·물·연료·청결·환경·도구가 모자람 | 시설 상태에서 부족한 조건을 채운다. |
| 다시 시도 대기 | 같은 실패를 반복해 짧은 대기 시간이 걸림 | 마지막 실패 원인을 해결한다. |

작업 후보는 선택할 때와 실제 시작 직전에 두 번 검사한다. 그 사이 재료가 예약되거나 문이 닫히고 환자가 옮겨지면 후보를 버리고 새 일을 찾는다. 같은 원인으로 계속 실패한 대상은 잠시 제외해 주민이 한 작업 앞에서 반복해서 왕복하지 않게 한다.

## 조치 후 점검

우선순위, 배치, 출입과 보급을 바꾸면 주민과 시설은 바뀐 조건에서 다시 일을 찾는다. 생산을 멈추거나 한 구역에 자원을 몰아준 선택도 재고, 건강, 환경과 외부 관계에 남는다. 당장의 병목을 풀었더라도 다음 부족이 어디에서 생길지 확인해야 한다.

반복되는 지연은 동선, 저장, 인력 배치와 시설 문제에서 생길 수 있다. 생산 자체의 흐름은 [재고·생산·물류](/guide/production/)에서, 방과 통로 문제는 [방과 동선](/guide/spaces/)에서, 주민 업무는 [주민과 노동](/guide/residents-and-work/)에서 이어서 확인한다.

:::note
이전, 수리, 재배치와 새 생산에는 시간, 물자와 노동이 든다. 병목을 고칠 때는 그 비용으로 생활, 방어와 다른 생산에 생기는 공백도 함께 본다.
:::
