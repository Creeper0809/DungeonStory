품질은 작업자의 현재 스킬, 시설과 도구, 제작 난도와 시도마다 고정된 무작위 값으로 정해진다. 재료는 완성품의 성능·작업 난도·손실 비용을 바꾸며 품질 등급은 제작 판정이 정한다.

## 품질 공식

```text
품질 점수
= 50
 + 0.7 × (가중 스킬 - 50)
 + 시설 보정
 + 도구 보정
 - 복잡도 페널티
 + 무작위 합
```

무작위 합은 -10~10 범위의 값 세 개를 더한 결과다. 런 시드, 주문 ID, 제작 정의와 시도 번호로 정해지므로 저장·불러오기와 화면 재개방으로 다시 굴러가지 않는다.

| 점수 | 품질 |
| ---: | --- |
| 20 미만 | 형편없음 |
| 20~34 | 저급 |
| 35~54 | 보통 |
| 55~69 | 양호 |
| 70~82 | 우수 |
| 83~94 | 명품 |
| 95 이상 | 전설 |

견습·숙련자·기술자·전문가·대가의 기준 품질 점수는 각각 25·40·58·78·95다. 현재 XP는 등급 기준점 사이를 연속으로 보간한다.

## 목표 품질 반복

기본 반복 주문은 평균 2~3회 안에 도달할 품질을 목표로 잡는다. 예상 시도가 20회를 넘으면 강한 자원 경고를 표시한다. 현재 시설·도구·작업자로 성공 확률이 0이면 재료를 소비하지 않고 `현재 조건으로 목표 달성 불가` 상태에서 기다린다.

반복 생산의 숙련 XP는 1~3회 100%, 4~10회 50%, 11회부터 15%를 적용한다. 해체로 얻는 XP는 원래 제작 XP의 20%가 상한이다.

## 연료·사료와 자동화

연료는 난방, 조리, 제련과 동력에 함께 쓰이고 사료는 축산과 운반 동물을 유지한다. 생산 주문은 품목 수량과 함께 남은 가동 시간, 시간당 소비량, 다음 보급 경로를 확인한다.

| 운영 기준 | 목표 범위 |
| --- | ---: |
| 초중반 운반 노동 | 총노동의 12~20% |
| 자동화 뒤 운반 노동 | 5~10% |
| 자동화 정비·전력 노동 | 5~10% |
| 정상 발전 여유 | 평균 수요의 120% |
| 의료·방어 비상 전력 | 최소 1일분 |

전동 보조 작업의 현재 기준 배율은 1.35다. 자동 품질 상한은 시설에 따라 0.50~0.90이며, 자동 모드는 보조 모드보다 적은 전력을 쓰지 않는다. 수동 모드는 자동화 전력을 0으로 유지한다.

이 표는 밸런스 운영 목표다. 시설별 실제 소비량과 품질 상한은 해당 [시설 페이지](/category/facilities/)가 소유한다. 생산 주문과 출력 인계는 [재고, 생산과 물류](/guide/production/)에서 확인한다.
