침입은 기지의 통로, 문, 사선, 비축과 의료를 한 번에 시험한다. 경고가 보이면 전투 인원만 모으지 말고 외곽 주민의 대피, 탄약과 약품 운반, 생산 중단과 병상 확보까지 함께 준비한다.

## 위협 단계와 경고

침입 경고는 접근 방향, 남은 시간, 적의 성격과 목표를 알려 준다. 경고가 짧을수록 기존 비축과 방어선이 중요하고, 여유가 있으면 입구 보강, 인원 교대와 물자 이동을 할 수 있다. 계약 기한, 원정대 부재와 계절 작업도 같은 인력을 사용하므로 현재 공백을 먼저 확인한다.

| 절대일 | 자연 위협 기준 |
| ---: | --- |
| 1~9일 | 비적대 외부 사건만 발생 |
| 10일 | 일반 규모의 25% 예행 침입 |
| 20일 | 일반 규모의 50% 예행 침입 |
| 30일 | 일반 규모의 75% 예행 침입 |
| 40일 이후 | 첫 일반 보스 후보 등장 |

위협 상태에는 다음 침입 후보, 활성 침입, 개별 침입자와 결과가 저장된다. 경고가 실제 침입으로 바뀐 뒤 저장해도 같은 단계와 개체 ID로 이어진다.

## 방어선 구성

| 구역 | 맡는 일 | 준비할 것 |
| --- | --- | --- |
| 외곽 | 접근을 늦추고 경로를 읽는다. | 경보, 문, 함정, 후퇴 경로 |
| 전선 | 근접 경비와 원거리 화력이 버틴다. | 사선, 엄폐, 장비, 탄약, 교대 인원 |
| 후방 | 구조·치료·보급을 이어 준다. | 병상, 약품, 운반자, 예비 장비 |
| 생활권 | 전투에 들지 않는 주민과 필수 생산을 보호한다. | 대피 경로, 식량·물, 청결과 전력 |

방어선은 적을 막는 벽만 뜻하지 않는다. 탄약과 약품이 전선까지 갈 길, 부상자가 병상까지 갈 길, 주민이 후퇴할 길도 방어선의 일부다.

## 적 전술과 방어 붕괴

적은 접근 경로, 숫자, 장비와 전술에 따라 다른 압박을 준다. 정면 돌파가 강한 적은 통로와 저지선을, 원거리 공격이 강한 적은 엄폐와 사선을, 우회하는 적은 생활권의 출입과 경보를 시험한다. 전선이 무너지면 주민을 한곳에 묶기보다 다음 방어선과 대피 구역으로 물러나며 구조와 보급을 유지한다.

침입자는 이동 비용, 알려진 위험과 파괴할 수 있는 목표를 비교해 경로를 고른다. 열린 길로 가는 구간과 벽·문을 부수는 breach 구간은 따로 계산된다. 시설이 맞으면 건물의 구조 내구도가 실제로 감소하고, 길이 바뀌면 침입 경로를 다시 계산한다.

캠페인 적의 기본 능력치는 목표의 `requiredPower`로 조정한다.

```text
전투 능력치 계수 = clamp(sqrt(requiredPower ÷ 10), 0.75, 3.00)
행동·기동 계수 = clamp(sqrt(전투 능력치 계수), 0.90, 1.55)
예상 위협 계수 = 전투 능력치 계수²
```

체력·공격·힘·강인함·사격은 전투 능력치 계수, 민첩·이동은 행동·기동 계수를 쓴다.

## 전투 뒤 복구

교전 뒤에는 다음 순서로 기지를 회복한다.

1. 부상자 구조와 치료, 감염·오염 격리를 처리한다.
2. 파손된 문, 통로, 전력·유체 설비를 복구한다.
3. 탄약, 약품, 식량과 예비 장비를 다시 채운다.
4. 중단된 생산, 경비 교대와 외곽 업무를 다시 배치한다.

| 조우 난도 | 준비된 파티 승률 목표 | 중증·영구 부상 목표 |
| --- | ---: | ---: |
| 일상 | 85~95% | 5% 미만 |
| 표준 | 65~80% | 10~20% |
| 위험 | 45~65% | 20~35% |
| 보스 초견 | 25~45% | 30~50% |
| 보스 대응 준비 후 | 55~70% | 20~40% |

이 표는 동시대 장비와 합리적 진형을 갖춘 파티의 밸런스 목표다. 실제 결과는 지형, 장비, 신체 상태와 전투 판정이 정한다.

[전투와 장비](/guide/combat-and-equipment/)는 공통 전투 규칙을, [원정](/guide/expeditions/)은 기지 밖 전장을, [재료가 있는데도 작업이 멈출 때](/guide/world-state/)는 복구 주문의 병목을 설명한다.
