주민은 스킬 수치만으로 움직이지 않는다. 종족과 신체, 문화, 특성, 배경, 직책, 야망과 관계가 생활 방식과 맡을 수 있는 역할에 남는다. 같은 시설도 누가 쓰는지에 따라 필요한 환경과 만족이 달라진다.

## 종족과 신체

종족은 신체 구조, 식단, 기후 적응, 이동과 전투, 수면과 생활 공간에 영향을 준다. 특수 부위는 종족별 신체 구조 아래에서 확인한다. [신체 구조](/health/)는 공통 부위와 종족별 특수 부위를, [주민·사회 도감](/category/characters/)은 개별 종족과 특성을 정리한다.

## 문화와 생활 방식

문화는 음식, 휴식, 공동 공간, 서비스, 장례와 사회 활동의 만족 조건을 바꾼다. 새 주민이나 손님을 받으면 침대와 식사만 늘리지 말고, 그들이 쓸 수 있는 위생·휴식·문화 공간과 안전한 동선을 같이 마련한다.

| 확인할 항목 | 생활에서 드러나는 곳 |
| --- | --- |
| 식단과 소비 | 식사 정책, 식재료, 조리·보관과 서비스 |
| 환경 적응 | 방 온도, 습도, 환기, 물과 청결 |
| 사회 활동 | 공동 공간, 공연, 축제, 관계와 기분 |
| 노동과 전투 | 스킬, 특성, 장비, 위험 허용과 피로 |
| 생애 이력 | 가족, 교육, 경력, 장례와 다음 세대 |

## 특성, 배경과 관계

특성은 작업 방식, 학습, 안전, 소비와 사교에 차이를 만든다. 배경과 직책은 처음 잘하는 일과 사회적 위치에 남고, 야망과 관계는 사건·계약·공동체 갈등의 선택에 반영된다. 이를 한 주민의 수치로만 보지 말고, 어떤 역할을 오래 맡길지와 누구를 대체 인력으로 키울지에 쓴다.

일반 특성 하나가 평시 생산에 주는 영향은 보통 ±3~8%이며, 강한 특성도 단독으로 ±12%를 넘지 않는다. 특성은 같은 기능 계열에서 하나만 적용되고, 명시된 상극과 종족 조건도 함께 검사한다. 자연 생성 주민은 특성을 1~4개 가지며, 생성 가중치는 각각 15%, 40%, 35%, 10%다.

## 의복과 종족별 장비

주민 한 명에게 일상용·작업용·예비용 의복 3벌을 마련하는 것을 정상 운영 기준으로 삼는다. 세탁 처리량은 하루 사용량의 125% 이상, 젖은 의복의 건조 시간은 24시간 이내, 세탁과 수선은 전체 노동의 5% 이하를 목표로 한다.

특수 체형이나 환경에 맞춘 의복은 범용 의복보다 비싸지만 해당 신체·환경에서 15~25%의 뚜렷한 이점을 준다. 원단은 보온·통기·방수·내구와 가공 난도를 정하고, 완성 품질은 제작 숙련과 시설·도구·공정 난도로 따로 계산한다. 품질 계산은 [생산 품질, 연료와 사료](/guide/production-quality-and-supply/)에서 확인한다.

[주민과 노동](/guide/residents-and-work/)은 업무 배정을, [가족, 교육과 계승](/guide/family-education-and-legacy/)은 생애와 다음 세대를, [손님, 서비스와 공연](/guide/guests-services-and-performance/)은 대외 생활 공간을 설명한다.

## 종족과 문화의 판정 기준

종족마다 견디기 쉬운 환경과 생활 방식이 다르며, 의복과 축제, 방 선호가 그 차이를 보완하거나 강화한다. 문화적 선호와 생존 조건은 별도로 판정된다.

### 기후와 종족 상태

각 종족의 쾌적/안전/치명 온도 범위를 °C로 표기한다: 모험가15~27/0~40/-10~48, 수인10~29/-4~40/-12~48, 악마20~34/10~46/-2~56, 골렘-5~35/-20~50/-35~65, 하피7~25/-5~36/-15~44, 인간15~27/0~40/-10~48. 코볼트11~28/-2~40/-10~48, 균사인8~22/0~32/-8~40, 오크12~30/-5~42/-15~50, 슬라임16~24/5~34/0~40, 뱀파이어8~22/0~34/-10~42. 수치는 보호 보정 전 종족 기본 범위이다.

쾌적최저/안전최저 보정과 냉기노출배율은 방한작업복 -8/-8°C·0.35배, 룬방한복 -10/-10°C·0.2배, 슬라임보온패드 -4/-4°C·0.6배, 운반하네스0/0°C·1배다. 네 장비 모두 쾌적최고·안전최고 보정0, 열노출배율1이다. 이 값은 종족 기본 온도 프로필에 적용되는 보호 보정이므로 같은 작업복·8°C라도 종족별 결과가 같다고 보장하지 않는다.

얕은잠 특성은 방 소음 조건이 활성일 때 휴식으로 얻는 수면 회복에0.8배를 적용한다. 소음 조건은 같은 방의 다른 생산·제작·훈련·마나 시설에서 생긴다.

골렘은 충전량35이하에서 새 충전을 시작할 수 있다. 마력 저장조 충전은 마나 결정1개와100WU가 필요하며 완료하면 충전량을50만큼 회복하되 최대100을 넘지 않는다. 이미 진행 중인 충전은35문턱 때문에 중단되지 않는다. 충전 완료 시 예약한 마나 결정을 소비한다. 소비가 실패하면 완료 직전 작업 진척을 보존한다. 충전량은 초당0.035×종족 방전 배율만큼 감소한다.25미만이면 저충전 기분-10을5초간 갱신하고,0이면 초당 최대체력의0.25%에 해당하는 비살상 피해가 적용된다(각 갱신의 최소 피해0.1).

### 의복

의복 체형은 Any 또는 착용자의 실제 체형과 맞아야 하고 필요한 해부 부위가 모두 있어야 한다. 정사이즈형은 크기가 같아야 하며 조절형은 크기 차이1단계까지 허용한다. 봉인되는 특수 부위에 필요한 개구부는 해당 개조가 존재하고 닫히지 않은 상태여야 한다. 슬라임을 포함한 생물 주민은 기본 인간형 착용 표면을 가지며 실제 결손 부위는 착용 가능 부위에서 제외된다.

유효한 물리 의복을 중복 제거하여 세탁·건조 배치를 만든다. 동력 세탁은 배치4WU, 손세탁12WU, 건조24WU이며 품목 수를 곱하지 않는다. 손세탁 완료는 오염0·수분100, 동력 세탁 완료는 오염0·수분0, 건조 완료는 수분0으로 만들고 기존 오염은 유지한다.

내구도20 미만은 수선 주문 대상이 될 수 없다. 내구도20이상60미만은 재봉실1+수선천1과18WU가 들고 완료 내구도70이 된다. 내구도60이상은8WU이며 완료 시 기존 내구도+25, 최대100으로 회복한다.

탈의 칸막이의 짧은 작업은 이미 존재하는 개구부만 닫거나 다시 연다. 새 개구부 개조와 크기 변경은 별도 개조 작업으로 처리한다.

일반적인 예약·시설 실패로 대기 상태로 돌아가면 예약을 해제하고 해당 주문의 작업 진척을0으로 되돌린다. 재시도 간격은0.25→0.5→1게임시간으로 늘어난다. 일반 저장 주문 목록에는 완료 주문을 제외한다. 출력·최종 수선 확정 대기는 일반 실패와 구분하며 복원 시 재검증 또는 최종 확정 대기로 나뉜다.

### 축제

새싹제는 봄15일, 최소참가자8명, 황혼곡 종자12개를 요구하는 축제다. 행사장 요구는 좌석8·식탁8·서비스 수용1·행사 공간8칸이다. 결과별 기본 효과은 성공 기분+6/10일·세력호의+3, 부분성공 기분+2/5일·호의0, 실패 기분-3/4일·호의-2다. 실제 개인 기분 효과는 참석비율 보정을 거치므로 기본값을 무조건 모든 주민의 최종값으로 쓰지 않는다.

축제는 공지일부터 개최 마감시각 전까지 예약할 수 있으며, 시작 때 축제에 정해진 요구 물자를 납품 목적지에서 소비 확정한 뒤 진행 상태로 들어간다. 예약했다고 즉시 성공 효과를 받지 않는다. 계획 참석 시간이 끝난 뒤 유효 참가자가 최소참가자수 이상이면 성공, 최소참가자수의 절반을 올림한 수(최소1명) 이상이면 부분성공, 그 미만이면 실패다. 기분·슬픔전환은 유효 개인의 참석비율 보정을 거쳐 적용한다.
