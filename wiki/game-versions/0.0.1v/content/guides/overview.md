DungeonStory는 던전 주인과 주민이 함께 사는 정착지를 운영하는 경영 전략 게임이다. 플레이어는 공간과 우선순위, 생산과 거래, 사람과 위험 정책을 정한다. 주민은 스킬, 신체와 욕구, 시설 조건과 경로를 읽고 실제 일을 수행한다.

정착은 내부 운영과 외부 대응이 맞물린다. 방과 통로, 재고와 운반, 생산과 의료가 생활을 지탱한다. 손님과 세력, 침입과 원정은 이 기반을 시험하고 다음 선택을 연다.

## 세계관

게임은 아벨른의 세르카 대륙 동부, 하르나크 단층분지에서 시작한다. 이곳의 던전은 여러 종족이 삶과 일터를 함께 세운 지상 정착지다. 서쪽의 오르데나 왕국은 하나의 거대한 국가이며, 왕국 안의 다섯 지역은 지형과 산업, 생활 모습이 다르다. 하르나크 분지에는 서로 다른 여섯 도시가 자리 잡고 있다.

- [세계와 정착](/guide/world/)
- [하르나크의 여섯 도시](/guide/world-dungeons/)
