한 런은 **던전 주인 1명과 같은 종족 주민 2명**, 모두 세 명으로 시작한다. 던전 주인은 정착지에 남는 고정 인원이며 원정대에 넣을 수 없다. 준비 화면에서는 같은 종족 주민 후보 6명 가운데 2명을 고른다.

## 세 자리의 차이

| 자리 | 바뀌는 범위 | 고정되는 범위 |
| --- | --- | --- |
| 던전 주인 | 종족, 출신, 과거 이력, 나이, 특성과 숙련 조합 | 정착의 중심 인물, 원정 편성 제외 |
| 주민 2명 | 후보 가운데 선택, 주전문·부전문과 생활 조건 | 던전 주인과 같은 시작 종족 |

던전 주인이 기지에 남으므로 원정 중에도 생활·의료·방어의 핵심 업무를 맡을 수 있어야 한다. 주민 둘은 건설·운반·식량 가운데 서로 다른 주전문을 갖추면 첫날의 작업 공백이 줄어든다. 의료나 전투는 부전문과 대체 담당자까지 확인한다.

## 시작 숙련과 경력

아홉 스킬은 각각 15~45 XP에서 시작하고 출신과 과거 이력이 보너스를 더한다. 과거 이력은 주전문 하나와 부전문 하나를 정한다. 런 시작 뒤 주전문은 획득 XP ×1.50, 부전문은 ×1.20, 나머지는 ×1.00을 적용한다.

| 경력 구간 | 한 스킬의 시작 상한 |
| --- | ---: |
| 젊은 성인 | 99 XP |
| 경력 성인 | 174 XP |
| 베테랑 | 249 XP |
| 노년 | 399 XP |

시작 상한은 종족별 나이와 함께 적용된다. 노년 후보는 기존 노화성 질환을 가질 수 있다. 준비 화면에서는 숙련만 비교하지 않고 현재 건강과 특성, 식단·수면·기후 조건을 함께 본다.

## 첫 역할 점검

1. 건설과 수리를 맡을 주민을 정한다.
2. 재료를 옮기고 급수·연료를 보급할 주민을 정한다.
3. 식량 확보와 조리를 이어 갈 담당자를 정한다.
4. 구조·치료·경비가 겹칠 때 대신 맡을 사람을 확인한다.
5. 던전 주인이 원정에 빠지지 않는 구성을 전제로 원정 후보를 고른다.

첫 거처와 생산을 배치하는 순서는 [처음 정착하기](/guide/getting-started/)에서, 종족별 생활 조건은 [종족, 문화와 생활](/guide/species-culture-and-life/)에서 이어서 확인한다.
