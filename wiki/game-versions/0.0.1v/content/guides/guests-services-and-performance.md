손님은 정착의 소비자이면서 세력 관계의 창구다. 손님을 받으면 접수부터 대기, 식사, 숙박, 위생, 의료, 상점과 공연까지 하나의 이동 경로가 생긴다. 서비스 인력과 공간을 늘리면 생산과 방어에 남는 인력은 줄어든다.

## 서비스 흐름

:::flow
입구와 접수에서 손님의 목적과 요구를 확인한다.
대기·숙박·식사·위생·의료와 상점으로 갈 경로를 마련한다.
접객과 공연, 청소·보급 인력을 배정한다.
대기 시간, 청결, 안전, 음식과 문화 조건을 확인한다.
만족과 관계, 소비와 시설 사용 이력을 다음 운영에 반영한다.
:::

손님 한 명의 이용 기록은 `광고·수요 확인 → 시설 배정 → 이동·대기 → 서비스 이용 → 결제와 결과 인계 → 완료 또는 취소` 순서로 이어진다. 저장 후에도 배정된 시설, 대기 시간, 준비한 물품과 아직 받지 못한 결과가 그대로 남는다. 식사·상점·의료·공연에 쓰는 물품은 창고 수량만 줄이지 않고 실제 물건을 서비스 장소까지 옮긴 뒤 소비한다.

## 만족을 바꾸는 조건

| 조건 | 확인할 곳 |
| --- | --- |
| 접근과 대기 | 입구, 접수, 통로, 좌석과 담당 인력 |
| 숙박과 목욕 | 침대, 물, 위생, 청소와 프라이버시 |
| 식사와 상점 | 메뉴, 보관, 운반, 재고와 가격 |
| 의료와 안전 | 병상, 보호, 치안과 위험 구역 분리 |
| 공연과 문화 | 공연 인력, 공간, 시간과 문화 적합성 |

## 사고와 손님 요청

난투, 절도, 오염, 금기 음식, 의료 응급, 사절 충돌과 파괴 공작은 실제 손님·직원·시설·물건을 원인으로 기록한다. 서비스 사고마다 기계적으로 다른 대응을 정확히 3개 제시한다. 치료, 체포, 배상, 협상, 조사, 은폐와 영업 중단 가운데 사건에 맞는 세 가지가 나오며, 문구만 다르고 결과가 같은 선택지는 사용하지 않는다.

계절마다 서비스 사고의 최대 정규화 강도는 0.5~12 범위에 둔다. 비용을 지불하면 즉시 끝나는 선택, 시설을 멈추고 원인을 고치는 선택, 관계와 후속 사건을 감수하는 선택처럼 서로 다른 운영 결과가 남아야 한다.

## 영입으로 이어지는 손님

방문과 만족 조건을 채운 첫 일반 손님은 바로 영입 후보가 될 수 있다. 첫 영입 뒤에는 일반 영입과 용병 영입 모두 마지막 성공 영입일부터 최소 10일이 지나야 한다. 영입한 주민은 기존 주거·식사·임금·의복·의료 수요를 그대로 추가하며, 후발 성인은 캠페인 경험에 맞는 두 전문 숙련만 보정받는다.

## 서비스 구역의 배치

손님 구역은 내부 생활권과 구분하되, 식량·물·의료·청소의 보급 경로는 짧아야 한다. 손님이 많은 시기에는 접객·공연·상점 인력이 주민 업무에서 빠질 수 있으므로 교대와 대체 인력을 준비한다. [세력, 계약과 포로](/guide/factions-contracts-and-prisoners/)와 [경제와 거래](/guide/economy-and-trade/)에서 대외 관계와 거래를 이어서 확인한다.
