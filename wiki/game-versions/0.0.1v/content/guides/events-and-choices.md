사건은 현재 정착의 주민, 시설, 재고, 지역과 세력 상태에서 시작되는 운영 과제다. 같은 사건도 준비된 물자, 인력, 경로와 관계에 따라 비용과 결과가 달라진다.

## 사건이 시작되는 이유

사건은 계절과 지역, 시설 상태, 주민 관계와 건강, 세력 관계, 이전 선택의 흔적에서 발생한다. 먼저 어떤 조건이 사건을 불렀는지와 어느 구역·주민·물자가 대상인지 읽는다. 원인을 알면 해결 뒤 남겨야 할 예방 조치도 정할 수 있다.

## 문맥과 조건

사건 창에서는 대상, 기한, 위험, 선택 조건과 필요한 자원을 확인한다. 필요한 재료는 창고 수량만 보지 않고 예약과 운반 상태를 확인한다. 주민이나 시설이 필요하면 현재 업무, 접근 가능한 위치와 대체 인력을 함께 본다.

| 확인할 것 | 이유 |
| --- | --- |
| 원인과 대상 | 어떤 주민, 시설, 구역과 관계가 영향을 받는지 판단한다. |
| 기한과 위험 | 준비와 복구에 쓸 시간을 가늠한다. |
| 물자와 인력 | 재고, 예약, 운반과 현재 업무의 공백을 확인한다. |
| 선택 조건 | 경로, 시설, 스킬과 관계가 실제로 갖춰졌는지 확인한다. |

## 선택 뒤 진행

선택은 즉시 끝나거나, 주민 이동·물건 운반·조건 충족·기한 대응이 이어지는 작업을 만든다. 선택 뒤에는 작업 목록과 현장을 보며 대상이 사라졌는지, 경로가 막혔는지, 약속한 물자가 다른 주문에 쓰였는지 확인한다.

:::flow
원인, 대상, 기한과 조건을 읽는다.
재고, 주민, 시설과 이동 경로를 확인한다.
다른 긴급 업무, 방어와 생활에 생길 공백을 비교한다.
선택 뒤 생성된 작업과 남은 조건을 확인한다.
결과와 소모한 비축, 관계와 시설 상태를 복구 계획에 반영한다.
:::

선택을 확정하면 비용 가능 여부를 먼저 검사하고 물자와 대상 상태를 예약한다. 모든 조건이 유효할 때 재고·관계·시설·주민 효과를 함께 적용한다. 중간 단계가 실패하면 예약과 준비 결과를 되돌리고 원인을 표시한다. 물리 보상은 확정 번호와 인계 기록을 사용해 저장·불러오기 뒤에도 한 번만 지급한다.

## 결과와 흔적

사건은 재고, 시설, 건강, 관계, 지역 상태와 이후 선택에 흔적을 남긴다. 성공 여부와 함께 소모한 물자, 파손과 오염, 새 의무, 관계 변화와 이어지는 사건을 확인한다. 같은 문제가 다시 오지 않게 하려면 원인에 맞는 공간·비축·인력·정책을 남겨야 한다.

전투 문제는 [전투와 장비](/guide/combat-and-equipment/)에서, 원정은 [원정](/guide/expeditions/)에서, 세력 관계는 [세력, 계약과 포로](/guide/factions-contracts-and-prisoners/)에서 확인한다. 건강 문제는 [건강과 공동체](/guide/health-and-community/)에서, 재료와 작업 병목은 [재료가 있는데도 작업이 멈출 때](/guide/world-state/)에서 확인한다.

## 사건의 종류와 간격

사건은 생활, 환경, 경제, 세력, 원정과 전투에 걸쳐 발생한다. 한 번에 여러 사건이 겹치면 주민의 주의와 재고, 방어 준비가 분산된다. 기한이 짧은 위험을 처리한 뒤에도 장기 계약, 계절 준비와 미뤄 둔 수리 작업을 다시 확인한다.

| 사건 규모 | 비용 기준 |
| --- | ---: |
| 소형 | 0.25~0.75 WD |
| 일반 | 1~3 WD |
| 대형 | 5~15 WD와 실제 위험 |

균형 상태에서 선택지의 기대가치 차이는 15% 이내를 목표로 한다. 특정 준비를 갖춘 정착지는 맞는 선택에서 25% 이상 이점을 얻을 수 있다. 이 비용 밴드와 기대가치는 밸런스 목표이며, 실제 발생일은 매일의 후보 평가와 재발 대기 기간으로 정해진다.

### 사회 사건의 실제 발생 규칙

생애 사건·손님 요청·서비스 사고는 하루 시작 시 한 번 평가한다. 같은 날을 불러와도 이미 마친 일일 평가를 반복하지 않는다.

| 구분 | 동시에 진행할 수 있는 수 |
| --- | ---: |
| 1~30일 일반 사건 | 1개 |
| 31일 이후 일반 사건 | 2개 |
| 서비스 사고·비상으로 지정된 생애 사건 | 일반 사건과 별도로 1개 |

따라서 31일부터는 일반 2개와 비상 1개가 겹칠 수 있다. 같은 주민은 진행 중인 사건의 참가자로 중복 배정하지 않는다. 비상 여부는 사건 정의가 정한다. 화면의 경보 중요도와 별개로 일반·비상 분류에 맞춰 동시 진행 한도를 적용한다.

같은 생애 사건의 재발은 해당 정의의 대기 기간과 주민별·세대별 발생 조건을 따른다. 손님 요청과 서비스 사고의 같은 정의는 해결 후 30일, 같은 분류는 해결 후 3일을 기다린다. 다른 분류의 후보와 빈 자리가 있으면 전날 사건을 해결한 다음 날에도 새 사건이 생길 수 있다. 마감일 당일까지 선택할 수 있고, 다음 날 평가에서 미해결 사건이 만료된다.

자동 생애 사건은 하루 최대 6개이며 주민 한 명에게 하루 하나씩 배정한다. 현재는 개별 결과로 처리되며 초과 후보를 일일 요약으로 전환하는 기능은 제공하지 않는다. 화면 경보에 중요 5개·치명 2개 같은 고정 상한도 적용하지 않는다.

계절 사건은 별도 진행 규칙을 사용한다. 계절별 7개, 지속 1~6일, 영향 영역 2개 이상을 밸런스 기준으로 두며, 진행 중인 계절 사건이 끝난 뒤 다음 후보를 평가한다. 서비스 사고는 서로 다른 대응 3개를 제공한다.

## 스포일러 문서

사건과 캠페인 도감은 결과를 경고 뒤에 표시한다. 이 문서는 사건을 처리하는 공통 규칙을 설명한다. 상세 결과는 필요한 경우 개별 페이지의 경고를 열어 확인한다.

## 사건과 선택의 판정 기준

사건은 발생 조건을 충족한 후보 가운데 선택되며, 선택 결과와 처리 기록은 다음 판정에도 쓰인다. 아래 규칙은 후보가 만들어지고 결과가 확정되는 과정을 설명한다.

### 사건 효과와 발생

같은 작업 범위의 양수 지연은 기존 만료일과 오늘 중 늦은 날에 기간을 더한다. 음수 지연은 남은 기간을 줄이고 만료한 지연은 제거된다. 해당 작업에 걸리는 활성 지연 n개의 공통 속도 배율은 max(0.5, 0.8^n)이다. 홍수 범위는 파종·수확·운반·시설 재고 보충에 적용된다.

외부 사건은180초 주기에 활성 외부사건이 없을 때 발생을 검사한다. 확률은 clamp(0.18+야간위험×0.004+날씨압력×0.12-clamp(순찰준비도,0,100)×0.0025,0.08,0.72)다. 발생 판정을 통과하면 사건 간격 조건을 통과한 처리기 후보에서 종류별 가중치로 선택한다.

### 후보 선정과 기록

일일 후보 사건과 참가자는 시드·날짜·사건·참가자에 따른 고정 판정값을 관련 가중치로 나눈 순서에서 고른다. 사건은 참가자 중 가장 큰 가중치, 참가자 선정은 해당 참가자 가중치를 사용한다. 여러 관련 가중치는 곱하고0.1~10으로 제한한다. 해결 기록 중 성공 인생사건의 영수증에 연결되지 않은 일반 발생건은 최근256개를 남긴다. 영수증이 보유한 발생건은 이 삭제 대상에서 제외되므로 전체 기록 수는256을 넘을 수 있다.
