기반 시설은 여러 방에 전력, 유체, 위생, 환기와 자동 물류를 공급한다. 정착이 커질수록 연결 방식, 완충 공간과 비상 공급이 생활·생산·의료·방어의 가동 범위를 정한다.

## 기반 시설 설치

:::flow
먼저 지켜야 할 생활·의료·생산 구역과 필요한 환경을 정한다.
발전, 급수, 환기와 운반 경로를 각 소비처까지 연결한다.
입력과 출력이 머무를 지역 완충 공간을 둔다.
차단 지점, 우회 경로와 비상 공급 위치를 정한다.
가동 뒤에는 부하, 유량, 오염 상태와 저장 여유를 확인한다.
:::

## 환경 관리

온도, 공기, 조명, 청결과 외부 영향은 주민 수, 열원, 오염원, 문 개방, 날씨와 설비 가동 상태에 따라 바뀐다. 침실, 작업장, 수술 공간, 연구 공간과 재배 구역은 각기 다른 환경 조건을 사용한다.

환경을 조절하는 방식도 운영 부담이 다르다. 열원은 연료와 공기질을 함께 관리하고, 보호구와 짧은 교대는 인력 배치를 바꾸며, 구획과 환기는 공간과 배관·전력 설비를 사용한다. 부족한 조건, 유지에 드는 물자와 고장이 영향을 미치는 범위를 함께 비교한다.

## 시설별 점검 항목

| 기반 시설 | 평상시 점검 | 고장 시 점검 |
| --- | --- | --- |
| 전력 | 발전원, 연결 구간, 연료 운반과 소비 시설 | 연료, 부하, 배전 구간과 필수 시설 |
| 급수·위생 | 깨끗한 물, 공정 유체, 폐수의 상태와 저장량 | 오염 구간, 수질, 관로와 임시 급수 |
| 환기·환경 | 열원, 덕트·송풍 경로와 방의 환경 상태 | 위험 구역 격리, 공기와 온도, 수리자 접근 |
| 자동 물류 | 반입 위치, 필터, 분배 순서와 출력 여유 | 멈춘 구간, 대기 재료와 수동 운반 경로 |

전력은 발전과 소비 시설이 실제로 연결될 때 사용한다. 발전기 연료도 운반되어 소비된다. 급수와 위생은 깨끗한 물, 공정 유체와 폐수를 서로 다른 상태로 다루며, 생활·의료·생산 구역은 각기 다른 조건을 사용한다.

## 연결과 상태 갱신

전력은 생산·수요·축전·공급 결과를, 유체는 수질별 양·폐수·수동 운반을, 컨베이어는 화물 ID·현재 경로·경로 순서를 각각 저장한다. 건물 연결이 바뀌면 전력·배관·물류 연결이 갱신되고 컨베이어의 오래된 경로도 다시 계산된다.

컨베이어가 시설 버퍼에 도착해도 kg 여유가 있어야 인계된다. 수동 운반과 자동 물류는 같은 시설 버퍼의 예약량을 공유한다. 경로, 시설 용량이나 품목 질량 기준이 바뀌면 도착 시 다시 검사한다.

자동화 모드는 수동·보조·자동으로 나뉜다. 모드 전환은 살아 있는 시설 예약과 주문을 확인하며, 고장이나 유지보수 상태가 바뀌면 수리 업무 후보가 다시 계산된다.

## 용량과 노동 목표

정상 발전 용량은 평균 수요의 120%를 목표로 하고, 의료·방어 시설에 쓸 비상 전력은 최소 하루분을 따로 둔다. 자동화가 멈춰도 수동 시설과 긴급 운반으로 식사·물·의료·방어를 유지할 수 있어야 한다.

| 운영 단계 | 목표 |
| --- | ---: |
| 초중반 운반 노동 | 전체 노동의 12~20% |
| 자동화 이후 운반 노동 | 전체 노동의 5~10% |
| 자동화 정비·전력 노동 | 전체 노동의 5~10% |
| 전동 보조 작업 속도 | 수동의 1.35배 |
| 자동화 정비 소모 | 가동 1시간당 1 |
| 자동 품질 상한 | 0.50~0.90 |

자동 모드는 보조 모드보다 적은 전력을 쓰지 않으며, 수동 모드는 자동화용 전력을 0으로 유지한다. 자동화는 반복 운반을 줄이는 대신 필터, 버퍼, 우선순위, 넘침과 정비를 새 관리 항목으로 만든다.

## 중앙 설비와 분산 설비

중앙식 설비는 반복 운반을 줄이고 증설과 대규모 운영을 돕는다. 관로 파손, 오염과 정전은 연결된 구역에 함께 영향을 준다. 분산 설비와 수동 보급은 지역별 처리량을 사용하고, 고장 범위를 작은 구역에 묶는다. 현재 필요한 처리량, 고장이 퍼져도 되는 범위, 수리 인력과 공간을 기준으로 두 방식을 섞어 쓴다.

## 고장 뒤 재가동

위험 구역을 먼저 격리한다. 필수 소비처에는 임시 공급을 연결하고, 오염을 처리한 뒤 관로 압력을 낮춰 수리자가 접근할 길을 만든다. 재가동은 부하, 유량, 수질과 저장 여유를 보며 구역별로 진행한다. 이 순서가 생활 구역과 의료 구역의 공백을 줄인다.

## 시설 성장

시설 합성, 계보 교체, 개체 진화, 특성 조정과 이전은 [시설 성장과 진화](/guide/facility-growth/)가 기준 문서다. 전력·배관·물류 연결을 끊는 시설 변경은 이 문서의 점검을 다시 거친다.
