생산 주문은 재료 선택, 작업자별 기여, 품질 판정, 준비된 출력과 목적지 인계를 차례로 기록한다.

## 재고와 운반

물건의 위치와 사용 예약, 소유 책임, 부분 운반, 무게 한도와 창고·시설 입고는 [재고, 예약과 운반](/guide/inventory-and-carrying/)이 기준 문서다. 생산 주문은 승인된 입력을 넘겨받은 뒤부터 재공품과 출력의 책임을 가진다.

## 생산 주문

:::flow
제작식, 시설, 허용 재료와 작업자를 정한다.
재료를 선택하고 실제 수량과 목적지 용량을 예약한다.
작업자별 기여량과 공정 중 물질을 재공품에 기록한다.
작업이 끝나면 품질, 수율, 부산물과 손실을 한 번 확정한다.
확정 결과를 준비 출력으로 고정하고 목적지 공간을 예약한다.
물리 아이템을 발행하고 목적지 인계 영수증을 확인한다.
승인이 끝나면 주문을 완료하고 예약과 체크포인트를 정리한다.
:::

준비 출력은 생산 확정 번호와 확정된 품질을 가진다. 저장·불러오기와 재시도에도 처음 정한 품질과 재료 소비 결과가 유지된다. 출력 공간이 부족하면 품질과 결과를 유지한 채 `출력 공간 대기` 상태에 머문다.

| 증상 | 점검 항목 | 조치 |
| --- | --- | --- |
| 주문이 대기함 | 원료 예약, 연구와 실행 시설 | 생산 우선순위, 시설과 연구 조건 |
| 현장 운반이 대기함 | 운반자, 통로와 목적지 공간 | 저장 위치, 운반 업무와 접근 경로 |
| 시설이 대기함 | 입력 버퍼, 전력·유체 설비와 작업자 | 완충 공간, 설비와 스킬 배치 |
| 완성품이 쌓임 | 출력 공간과 다음 사용처 | 저장 한도, 소비 주문과 운반 경로 |

## 생산망 운영 기준

| 항목 | 기준 |
| --- | ---: |
| 원료 뒤 연속 제작 깊이 | 최대 4단계 |
| 공용 중간재의 실제 소비처 | 2개 이상 |
| 전략 재료의 실제 소비처 | 3개 이상 |
| 일반 가역 순환의 회수 가치 | 투입 EWU의 95% 미만 |
| 해체·재건·품질 재굴림 회수 가치 | 투입 EWU의 85% 미만 |
| 정상 상태의 출력 포화 정지 | 전체 생산 시간의 5% 미만 |

이 표는 제작식과 생산망의 밸런스 검사 기준이다. 개별 제작식의 입력·출력·WU와 손실은 [제작식 도감](/category/recipes/)이 소유한다. 품질 공식과 연료·사료 운영은 [생산 품질, 연료와 사료](/guide/production-quality-and-supply/)에서 확인한다.

## 제작식과 관계 확인

1. 필요한 결과물의 페이지를 연다.
2. 제작식에서 입력, 실행 시설, 출력과 연구 조건을 확인한다.
3. 관계 표나 그래프에서 상위 재료와 하위 사용처를 한 단계씩 따라간다.
4. 주문이 멈췄다면 재료 상태, 운반, 입력 공간, 출력 공간과 작업자 순서로 원인을 좁힌다.

[아이템·자원 도감](/category/items/), [시설·방 도감](/category/facilities/), [제작식 도감](/category/recipes/)은 생산에 쓰는 항목을 각각의 기준으로 정리한다. 공간과 설비 조건은 [방과 동선](/guide/spaces/)과 [시설과 환경](/guide/infrastructure/)에서, 농업·축산의 식재료와 사료는 [식량과 생태](/guide/food-and-ecology/)에서 이어서 확인한다.
