# 0.0.1v 문서 기준선

이 기록은 DungeonStory 0.0.1v 공개 위키의 최초 문서 기준선이다. 실제 공개 전환 전까지는 준비 중 상태이며, 게임 내용의 변경 기록을 대신하지 않는다.

## 문서 범위

- 현재 구현과 작성 자산에서 확인된 플레이어용 항목을 정리한다.
- 확인되지 않았거나 참조가 해소되지 않은 항목은 공개 투영에서 제외한다.
- 결말·사건 등 스포일러가 될 수 있는 항목은 경고 뒤에만 상세 내용을 표시한다.

## 알려진 제한

- 이 기준선은 NAS release candidate와 공개 HTTPS 전환 검증을 아직 통과하지 않았다.
